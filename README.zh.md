## 摘要

LAE 允许单个文件同时承载高解析度母带（最高 24 位、352.8/384 kHz）和 16 位 CD 层。所有现有 WAV 播放器都能逐位重现 CD 层。

- **44.1 kHz 系列。**计划采用 CD-Extra 套装：CD 层原样放在光盘的音频会话中，扩展数据放在数据会话中，因此所有 CD 播放器都能播放 CD 层。
- **48 kHz 系列（96/192/384 kHz 母带）。**这些母带具有 48 kHz 基础层，面向 DVD、蓝光和文件分发。
- **FLAC。**也计划支持在 FLAC 中封装。

高解析度信息完全存储在 PCM 信号之外，作为单独的扩展。扩展采用三级金字塔组织：

- **CD 层**：由母带确定性地生成，或独立提供；
- **位深层**：在基础采样率下，将 CD 频带从 16 位细化到约 18 位有效精度（默认值）；
- **频率层**：将 CD 截止频率以上的全部内容编码为每个倍频程一个 MDCT 流。

解码完全通过时域加法完成。共有四种解码路径：

- 仅 CD；
- CD 加频率层；
- CD 加位深层；
- 三层全部解码。

扩展主要使用三种工具编码：

- 形状自适应时频分区；
- 显式精度等级，其量化步长绝不会粗于一个 16 位 LSB；
- 自适应二进制范围编码器。

解码器在不同平台上具有确定性。重采样滤波器使用整数运算；逆 MDCT 则在严格的 IEEE-754 binary64 算术下按固定顺序计算。启动自检会对此进行检查。

在默认工作点下，真实录音中完整 24 位路径的 CD 频带误差中位数约为 −111 dBFS。可选的 20 位位深层（`keep20`）可将误差降至约 −124 dBFS。

扩展大小是在开发期间（2026-10-16）使用 v5 候选发布版测得的（第 11.2 节）。对于真实录音，在模式 3 下，扩展大小中位数约为未压缩 CD 层大小的 0.24 至 1.23 倍，具体取决于采样率和方案。

作者尚未、也不会就 LAE 提交任何专利申请，并承诺不对本规范的实现主张专利权（第 15 节）。

## 1 引言

### 1.1 问题

越来越多的录音以 24 位和 88.2 至 384 kHz 的采样率制作母带。尽管如此，CD（16 位、44.1 kHz）仍然是可在各种设备上播放的格式：旧式播放器、汽车音响、所有软件播放器以及实体产品。

如今，想要同时提供两者的发行方有两个选择：

- 分发两种独立产品；
- 采用一种旧设备无法读取其高解析度内容的格式。

一些现有方案会修改 PCM 信号本身，以便承载附加数据。

LAE 在以下约束下解决这一问题：**CD 层必须是未经改动的普通 CD。**其他所有内容均作为附加信息存储在其旁边。

### 1.2 目标

1. **逐位精确的 CD 层。**16 位 CD 层按原样存储。
   - 在 44.1 kHz 系列中，该层的采样率为 44.1 kHz，可由任何 CD、WAV 或 FLAC 播放器播放。
   - 48 kHz 系列具有 48 kHz 基础层（CD 频带为 0–24 kHz），面向 DVD、蓝光和文件分发。
   - CD-Extra 仅适用于 44.1 kHz 系列。

2. **扩展数据位于 PCM 之外。**扩展可恢复至 24 位，以及最高 352.8 kHz（44.1 kHz 系列）或 384 kHz（48 kHz 系列）。扩展量随母带中真实信息的多少而变化，因此信息越多的母带会生成越大的文件。

3. **降低精度，不丢弃内容（LAE Lossy）。**LAE Lossy 可以降低内容的表示精度，但不得丢弃有意义的内容。
   - 持续音、瞬态、乐音、谐波和混响尾音都会保留。
   - 母带中的噪声被视为音乐的一部分，并像其他内容一样编码。这包括噪声底、不可闻的随机噪声和有意添加的噪声。
   - 只有可以确定不承载信息的内容才会自动置零：数字静音，以及低于一个 24 位 LSB 的舍入级残留。

   计划中的导出界面将允许用户标记要移除的噪声区域（第 17.2 节）。

4. **支持两种采样率系列。**同一算法适用于 44.1 kHz 和 48 kHz 系列。只有倍频程采样率等级固定（88.2/176.4/352.8 kHz 和 96/192/384 kHz）；其他内容均自适应。

5. **确定性解码。**所有符合规范的解码器在任何平台上都生成逐字节相同的输出。

6. **开放性。**该格式依据开放许可证发布（第 16 节）。作者作出不主张专利权的承诺（第 15 节）。

**非目标。**

- 对可听频带进行感知编码。可听频带由 CD 层和以波形编码的细化层组成。
- 由编码器规划光盘容量。编码器只负责压缩。发行方选择方案、模式和输出范围，并负责判断结果是否适合目标介质。

### 1.3 主要特性

- **金字塔分解。**信号被分解为 CD、位深和频率目标，再通过普通时域加法重新组合。CD 层可以由母带生成，也可以独立提供。
- **按录音确定频率层起点。**频率层从实际 CD 检测出的截止频率开始，而不是从 CD 奈奎斯特频率的固定比例处开始。
- **仅由编码器进行泄漏补偿。**频率层的量化噪声可能经 MDCT 窗泄漏到 CD 频带。位深层会抵消这种泄漏，解码器无需为此作任何改动。
- **精度规则及 16 位下限保障。**显式精度等级（B/C/D）根据每个叶节点的指数定义，并受三条精度规则约束。在这三条规则下，量化步长都不会粗于一个 16 位 LSB。
- **全局码率—精度搜索。**针对整条音轨的搜索会选择形状自适应二进制时频分区，并在满足最高精度内容保留比例的前提下，使总字节数最小。
- **确定性与一致性。**解码过程在严格 IEEE-754 算术下具有确定性。启动自检指纹和 16 个一致性向量用于检查这一点。
- **开放许可证和不主张专利权的承诺。**规范、参考解码器和参考编码器均依据第 16 节所列许可证发布。

## 2 相关工作

**FLAC** [1] 是一种无损音频格式。

- LAE 的 CD 层是普通 PCM 信号，因此可以装入普通 FLAC 流。FLAC 封装 LAE 属于未来工作（第 17.1 节）。
- LAE 编码器有两个方面受到 FLAC 启发：
  - 工作模式像压缩等级一样编号；
  - 分区搜索依据实际编码大小选择分区，借鉴了 FLAC 的二次幂分区方式。

**MPEG-4 Audio BSAC 和可扩展无损编码（SLS）** [2] 是较早的分层音频编码实例。

**CD-Extra** [4]（1995 年的 Blue Book）定义了多会话光盘：先是音频会话（Red Book [3]），再是数据会话。

- LAE 计划将 CD-Extra 用作 44.1 kHz 系列的实体光盘容器。
- CD 层原样放在音频会话中，扩展文件放在数据会话中。
- 使用“CD EXTRA”标志需要许可证。

## 3 系统概述

### 3.1 符号说明

全文使用以下符号。

| 符号 | 含义 |
|---|---|
| $R_0$ | 基础采样率，44.1 kHz 或 48 kHz。$B = R_0/2$ 为基础奈奎斯特频率。 |
| $R = R_0 \cdot 2^n$ | 母带采样率，$n \in \lbrace 1, 2, 3 \rbrace$（88.2/176.4/352.8 kHz 或 96/192/384 kHz）。 |
| $x$ | 采样率为 $R$ 的母带信号，以 24 位整数单位表示。 |
| $\mathcal{D}$、$\mathcal{U}$ | 抽取器和插值器：使用相同系数表的 $n$ 级级联半带处理级。 |
| $b = \mathcal{D}(x)$ | 采样率为 $R_0$ 的 24 位基础信号。该信号*不会*被削波至满量程。 |
| $c$ | 16 位 CD 信号（CD16）。 |
| $d$ | 再生成的 TPDF 抖动。仅在设置了抖动标志的块中非零。 |
| $v = 256 c - d$ | 以 24 位单位表示的 CD 路径。任何解码器都可以仅根据 CD 层和抖动标志计算它。 |
| $f_c$ | 检测出的 CD 截止频率。 |

输入母带必须是立体声整数 PCM WAV 文件，每个采样为 16、24 或 32 位。对于 32 位输入，使用高 24 位。

### 3.2 金字塔

编码器会形成两个目标：

$$T = \mathrm{LP}_{f_c}\left(b - v\right) \qquad \text{(位深目标，基础采样率)}$$

$$F = x - \mathcal{U}\left(v + T\right) \qquad \text{(频率目标，母带采样率)}$$

$T$ 和 $F$ 仅存在于编码器中。

- 位深层承载 $T$ 的编码近似值 $\hat T$。在 v5 中，$\hat T$ 还包含第 6.5 节所述的泄漏补偿项。
- 频率层承载 $F$ 的编码近似值 $\hat F$。

按构造可知，$x = \mathcal{U}(v + T) + F$：这三部分通过时域加法即可还原母带。

```
                                master x  (rate R = R0 * 2^n, 24 bit)
                                   |
                     +-------------+----------------------------+
                     |                                          |
            half-band decimation D (n stages)                   |
                     |                                          |
            24-bit base b (rate R0, unclipped)                  |
                     |                                          |
     +---------------+------------------+                       |
     |                                  |                       |
  TPDF dither (flagged blocks only),    |                       |
  round, clip to 16 bit                 |                       |
     |                                  |                       |
  CD16 c ------> v = 256c - d           |                       |
     |               |                  |                       |
     |               +----> T = LP_fc(b - v) ---> depth layer   |
     |               |                  (L/R, base rate, MDCT)  |
     |               |                                          |
     |               +--> U(v + T) -----------> F = x - U(v+T) -+
     |                                               |
     |                                       frequency layer
     |                               (M/S, master rate, MDCT,
     |                                one stream per octave)
     v
  WAV "data" chunk (playable everywhere)    "LAE " chunk (extension)
```

### 3.3 分层

| 层 | 内容 | 频带 | 采样率 | 精度（高电平块） | 播放设备 |
|---|---|---|---|---|---|
| CD | WAV `data` 块中的 16 位 PCM | 0–22.05 kHz（48 kHz 系列：0–24 kHz） | 44.1 / 48 kHz | 16 位；仅在需要时使用 TPDF 抖动，数字静音绝不加抖动 | 任意播放器 |
| 位深 | 相对于 CD 路径的 24 位基础残差；每个声道（L、R）各一条流 | 0–22.05 kHz（48 kHz 系列：0–24 kHz） | 44.1 / 48 kHz | 默认 B18/C20/D24；`keep20` 为 B20/C22/D24 | LAE 解码器 |
| 频率 | CD 截止频率以上的所有内容；M/S 声道；每个声道、每个倍频程片段一条流 | 从 $f_c$ 以下 1 kHz 到母带奈奎斯特频率 | 母带采样率 | 方案 1：B18/C20/D24；方案 2：B16/C20/D24 | LAE 解码器 |

位深层和频率层彼此独立。二者共同构成完整的高解析度信号。输出分辨率取决于解码了其中哪些层。

### 3.4 解码路径

| 路径（`lae_dec` 选项） | 使用的层 | 输出 | 重建结果 |
|---|---|---|---|
| CD（任意播放器） | CD | 44.1/48 kHz，16 位 | $c$ |
| `16` | CD + 频率 | 母带采样率或较低倍频程；CD 频带为 16 位精度 | $\mathcal{U}(v) + \hat F$ |
| `cd24` | CD + 位深 | 44.1/48 kHz，24 位 | $v + \hat T$ |
| `full`（默认） | CD + 位深 + 频率 | 母带采样率或较低倍频程，24 位 | $\mathcal{U}(v + \hat T) + \hat F$ |

```
           CD (16 bit, R0) ............................ any player
            |
            +--- + depth layer ----------------------> cd24 (24 bit, R0)
            |
            +--- + frequency layer ------------------> 16-bit route (R0*2^k)
            |
            +--- + depth layer + frequency layer ----> full (24 bit, R0*2^k)
```

输出分辨率沿两个互相独立的轴选择：

- 输出倍频程：88.2/176.4/352.8 kHz 或 96/192/384 kHz；
- 位深：16 或 24 位。

三种解码路径都会写入 24 位 PCM 文件。16 位路径在精度上不同，文件格式则相同（[SPEC.md](spec/lossy/SPEC.md)，第 11.8 节）。

工作模式在编码时固定；解码器在播放时不提供模式选择。

选择较低输出倍频程时，解码器会：

- 不读取也不解码该倍频程以上的频率层数据流；
- 使用生成 CD 层时所用的相同半带滤波器，将结果降至所选采样率。

最终输出中超出 24 位范围的采样会被硬限幅（第 12.4 节）。

## 4 CD 层

### 4.1 生成的 CD

默认情况下，编码器通过以下四个步骤从母带确定性地生成 CD 层。

1. **抽取。**通过 $n$ 级级联的二倍抽取半带处理级，将母带从 $R$ 降至 $R_0$。
   - 滤波器是整数 FIR 滤波器，具有固定系数表，存储在参考源码（`src/halfband.h`）中。
   - 滤波器为对称、奇数长度（零相位）半带滤波器，系数采用 Q31 格式。只存储奇数抽头。
   - 中心抽头为 $2^{30}$，每张表中的已存储抽头之和恰为 $2^{29}$，因此直流增益恰为 1。
   - 累加使用 64 位整数，每个输出采样舍入一次（[SPEC.md](spec/lossy/SPEC.md)，第 10 节）。
   - 抽取后的输出采样 $m$ 以输入采样 $2m$ 为中心。信号范围之外的输入索引围绕端点采样镜像扩展（[SPEC.md](spec/lossy/SPEC.md)，第 10.2 和 10.4 节）。
   - 插值器 $\mathcal{U}$ 使用相同的系数表。
   - 开发期间的测量显示，半带级联在 0 至 19.8 kHz 通带内的偏差低于 −120 dB。

2. **不进行中间削波。**任何处理级都不会将 24 位基础信号 $b$ 削波至满量程。高于满量程的带限过冲（例如方波和强瞬态产生的过冲）会保留在 $b$ 中，并由位深目标 $T$ 承载。

3. **自适应 TPDF 抖动。**仅在录音自身噪声低于 0.5 LSB16 的块中添加抖动。
   - 抖动采用 TPDF，由两个 xorshift32 生成器产生，每个声道一个。左声道生成器的种子为 `0x12345678`，右声道为 `0xB06BD031`。这些种子是格式常量，不会传输。
   - 每个生成器针对每个基础采样率采样前进两次，包括未加抖动块中的采样。
   - 两次抽取的高 12 位 $u_1$ 和 $u_2$ 产生抖动值 $u_1 + u_2 - 4096$，单位为 1/16 LSB24，约为 ±1 LSB16（[SPEC.md](spec/lossy/SPEC.md)，第 11.2 节）。
   - 不使用噪声整形。
   - 完全为零的块（数字静音）绝不添加抖动，因此母带中的数字静音在 CD 层中仍然是精确的零。

4. **舍入和削波。**将加过抖动的基础信号舍入为 16 位，并削波至 16 位范围。这是 CD 路径中唯一发生削波的位置。

### 4.2 抖动标志与再生成的抖动

容器针对每 4096 个基础采样率采样，为每个声道存储一个标志字节。解码器按以下步骤处理：

1. 根据固定种子重新生成抖动序列；
2. 在带有标志的块中应用抖动；
3. 计算 $v = 256 c - d$。

因此，所有解码器都能仅依据 CD 层和标志精确得知 CD 路径。抖动值本身不会传输。

### 4.3 独立 CD

使用编码器选项 `cd=<file>` 时，现有 CD 母带会逐位成为 CD 层。

- **格式。**必须提供 16 位立体声 WAV，采样率与母带所属系列的基础采样率一致：44.1 kHz 系列为 44.1 kHz，48 kHz 系列为 48 kHz。
- **编码。**扩展对母带减去 CD 路径的差值进行编码。第 3.2 节的金字塔保持不变；唯一变化是 $c$ 不再由编码器生成。
- **抖动。**编码器不会对提供的 CD 添加抖动，因此此模式下所有抖动标志均为 0。
- **对齐。**所提供的 CD 必须与母带按采样对齐，且长度相同。编码器既不会对 CD 做均衡，也不会补偿其增益。检测错位属于未来工作（第 17.2 节）。
- **大小。**CD 越接近母带，扩展越小。单独进行过限幅、均衡或电平调整的 CD 会导致扩展显著增大。
- **截止频率检测。**在此模式下，根据母带与 CD 之间的相干性检测截止频率，因此检测不受电平差异影响（第 6.3 节）。

由发行方决定将哪一版 CD 与哪一版母带组合。

48 kHz 系列的母带只有经过重采样后才能与 44.1 kHz CD 组合。这属于母带制作工作：编码器不执行有理数比例重采样。

### 4.4 逐位精确性

CD 层就是输出 WAV 文件的音频内容。因此，它与生成的 CD 或提供的 CD 逐字节相同。

在写入任何文件之前，编码器会重新解码每一层和每个片段，并验证所有系数平面都匹配。

如果 CD 音频长度与扩展块不一致（第 10.4 节），解码器会拒绝该文件。若 CD 音频被修改但长度不变，则不会检测到这种更改（[SPEC.md](spec/lossy/SPEC.md)，第 3.2 节）。

## 5 位深层

### 5.1 内容

位深层以基础采样率对 $T$ 编码。$T$ 是未削波的 24 位基础信号与 CD 路径之差经过低通滤波后的结果。该层为左、右声道各设一条流。在 v5 中，编码目标为 $T$ 减去第 6.5 节的泄漏补偿项。

即使 $T$ 在 $f_c$ 处经过低通滤波，位深层仍始终覆盖整个基础频带，即 0–22.05 kHz（48 kHz 系列为 0–24 kHz）。截止频率以上的单元大多属于 A 类，几乎不占空间。

### 5.2 用途与原理

CD 频带承载大部分音乐内容，而位深层是提升该频带质量最划算的方式。

默认情况下，其精度由精度规则 1 控制；在 `keep20` 模式下由规则 3 控制（第 8 节）：

- 在安静块中，系数以比块峰值低 2、4 或 8 位的精度表示，从而保留波形形状；
- 在高电平块中，规则 1 下的步长对应 18/20/24 位分辨率；规则 3 下则对应 20/22/24 位分辨率。

### 5.3 过冲

基础信号 $b$ 不会削波，但 CD 路径会削波。因此，所有超过满量程的带限过冲都会出现在 $T$ 中。

因此，24 位路径可以恢复 CD 必须削掉的内容；只有最终输出会进行硬限幅。16 位路径不包含 $T$，无法恢复这类内容（第 12.3 节）。

### 5.4 keep20 位深层

`keep20` 模式使用精度规则 3 对位深层编码（高电平块为 B20/C22/D24）。选择 keep20 时，编码器会提示其影响和开销。测量结果如下：

- **CD 频带误差。**误差由约 −111 dBFS 改善至约 −124 dBFS（表 12.2）。
- **大小。**44.1 kHz 系列中，每小时音乐的位深层约增加 84 MB；48 kHz 系列中约增加 94 MB。
- **光盘时长。**在 CD-Extra 光盘上，这一额外大小相当于每小时音乐约占用 9 分钟光盘时间。
- **播放时长。**根据表 11.5 的测量，80 分钟光盘的 24 位路径中位播放时长减少了 2.0 至 4.8 分钟。

## 6 频率层

### 6.1 变换与倍频程数据流

频率目标 $F$ 在母带采样率下，通过对整个信号执行一次 MDCT 变换得到（第 7.1 节）。

频谱线被划分为若干片段，每个片段对应基础频带以上的一个倍频程。例如，对于 352.8 kHz 母带，这些片段名义上为 22.05–44.1、44.1–88.2 和 88.2–176.4 kHz。每个片段都作为独立数据流存储。

在这种组织方式中，每个倍频程都是一段频谱线。无需使用频带分割滤波器，其任何部分也都不会进入 PCM。

输出较低倍频程的解码器会跳过其以上的数据流。

### 6.2 中/侧

频率层采用中/侧（M/S）形式编码，每个片段分别设有 M 和 S 数据流。位深层则采用左/右（L/R）形式编码。

M/S 通过整数提升计算。这里的 $\lfloor\cdot\rfloor$ 以算术右移实现。编码器计算：

$$S = L - R, \qquad M = R + \lfloor S/2 \rfloor ;$$

解码器执行逆变换（[SPEC.md](spec/lossy/SPEC.md)，第 11.4 节）：

$$R = M - \lfloor S/2 \rfloor, \qquad L = R + S .$$

该逆变换可以从 $M$ 和 $S$ 精确还原 $L$ 和 $R$。

### 6.3 截止频率检测与起始谱线

不同制作的 CD 带宽各不相同。因此，频率层从当前 CD 实际截止频率稍低处开始，而不是从基础奈奎斯特频率的固定比例处开始。

- **生成的 CD。**编码器从基础奈奎斯特频率开始向下搜索，寻找 CD 仍能在 0.1 dB 以内跟随母带的最高频率。母带能量极低的频率箱会跳过。
- **独立 CD。**根据母带与 CD 之间的相干性检测截止频率，不受电平影响。

频率层从**检测截止频率以下 1 kHz**处开始。

- 起始和结束谱线会写入每个数据流头部。
- 检测到的截止频率也会存储在容器头部，仅用于显示。

### 6.4 精度

| 方案 | 频率层规则 | 高电平块 | 安静块 |
|---|---|---|---|
| 方案 1（高质量，`s1`，默认） | 规则 1 | B18 / C20 / D24 | 比块峰值低 2/4/8 位 |
| 方案 2（高压缩，`s2`） | 规则 2 | B16 / C20 / D24 | 同规则 1 |

两种方案都使用相同的位深层规则：规则 1，或 keep20 下的规则 3。因此它们的 CD 频带相同，差异仅在超声波区域。

### 6.5 泄漏补偿（仅编码器端）

频率层中的量化噪声会通过正弦窗的旁瓣泄漏到 CD 频带。超声内容越强，这种影响越明显：在合成材料上影响突出，在少数真实录音中也会出现。

开发期间的测量表明，CD 频带误差来自频率层：

- 不解码频率层时，CD 频带误差回到 −111 dBFS；
- 误差频谱随频率升高，从低频处的 −119 dBFS 上升到 18 kHz 处的 −100 dBFS；
- 半带滤波器的通带偏差低于 −120 dB。

v5 编码器执行以下流程：

1. 频率层定稿后，将其解码并计算其量化误差。
2. 将该误差降至基础采样率。
3. 使用 2047 抽头低通滤波器提取频率层起始频率以下的部分；该滤波器的截止频率比起始频率低 150 Hz。
4. 从位深目标中减去该部分，然后对位深层编码。

起始频率以上的内容由频率层本身编码，不会再次补偿。此流程既不改变解码器，也不改变格式。

补偿的效果取决于解码路径：

- **`full`。**两层都会解码，因此补偿有效。
- **`16`。**此路径没有位深层，因此补偿不起作用。
- **`cd24`。**位深层及其补偿项会被解码，但产生被抵消泄漏的频率层并未解码。该项对 `cd24` 输出的影响尚未测量；这项测量属于未来工作（第 17.3 节）。

开发期间的测量结果：

- 对合成 `electronic` 片段，CD 频带误差由 −96 改善至 −109 dBFS；
- 真实录音没有变化；
- 扩展大小增加 0–1%。

第 12.5 节报告了 12 个来源的平均影响。

## 7 时频分区与分类


### 7.1 变换

两个编码层都使用相同的 MDCT 结构，并按教科书式顺序实现。

| 方向 | 步骤 |
|---|---|
| 正向 | 加窗 → 折叠（相加）→ DCT-IV，通过带前、后旋转因子的复数 FFT 计算 |
| 逆向 | DCT-IV → 展开 → 加窗 → 重叠相加 |

**窗函数。**使用正弦窗。

**大小。**每个数据流头部都携带变换大小 $N$。在容器 v5 中，$N$ 必须为 512。

**旋转因子。**前、后旋转因子为：

$$w_n = \exp\left(-i \frac{2\pi (n + 1/8)}{2N}\right), \qquad n = 0, \dots, N/2 - 1.$$

这是 FFmpeg `libavcodec/mdct.c` [6] 使用的旋转因子形式。FFT 的位反转置换使用生成的 `BITREV` 表。

**边界扩展。**信号两端均采用镜像扩展。扩展长度记录在头部中（第 10 节）。

### 7.2 单元、根块和叶节点

解码器所需的几何布局由 `src/partition_format.h` 定义。编码器的搜索实现位于 `src/partition.h`。

**单元。**一个数据流的一个声道的系数平面被划分为若干单元。单元是某一帧中一组相邻频谱线。数据流头部会指明单元宽度；在容器 v5 中，该宽度始终为 8 条频谱线。

**根块。**单元按 16 个单元 × 8 帧组成根块。根块构成固定规则网格，并按时间优先顺序处理。所有模式下的根块几何布局相同。

**分区树。**每个根块通过二叉树进行分区。

- 一个节点要么是叶节点，要么通过一条频率或时间切分线分成两个子节点。
- 最小块大小为 1 个单元 × 1 帧。

**切分位置。**有两种切分位置方案。编码器标志 `equal` 用于选择方案，头部会记录选择结果。

- **等分切分（Equal cuts）：**仅能对半切分；无需传输位置。
- **不等分切分（默认）：**切分位置可以位于最小网格上的任意位置。位置以固定长度的旁路编码整数（以网格单位表示）传输。

**叶节点参数。**所有编码参数都在叶节点中携带：类别、指数、零级别索引和系数。中间节点只携带切分信息。

### 7.3 类别

每个叶节点会分配四种类别之一。

| 类别 | 含义 | 编码内容 |
|---|---|---|
| A | 确定不承载信息：数字静音，以及低于一个 24 位 LSB 的舍入级残留。计划支持：由用户显式移除的噪声。 | 不编码任何内容；重建为精确的零 |
| B | 需要最低精度等级的内容 | 指数 + 系数，TB = 2 |
| C | 中等精度 | TB = 4 |
| D | 需要最高精度的内容 | TB = 8 |

类别分配遵循以下规则。

- **噪声也要编码。**母带中的噪声不属于 A 类。噪声与其他内容一样编码，大多为 B 类，有时为 C 类。
- **先确定 A 类。**第一次压缩之前就固定 A 类，之后不再更改。
- **混合块。**只有所有单元均为 A 类时，块才能归为 A 类。任何包含保留内容的块至少为 B 类。将 A 类单元混入 B 类叶节点会增加 B 类字节开销，因此分区搜索会自行把 A 类与保留内容分开。
- **跨组单元。**跨越两个分析组的单元，只有在两个组都为 A 类时才属于 A 类。在此情况下，采用两者中较低的噪声底。
- **噪声底估计。**单元组的噪声底取以下两个值中较小者：时间方向的第 10 百分位数，以及该组单元之间的频谱中位数。因此，持续音不会被误判为噪声底。

### 7.4 标记与闭环（编码器）

编码器首先扫描整条音轨，并为每个非 A 类单元标记所需的位深：

- 需要最高位深的单元标为 D；
- 其次标为 C；
- 其余非 A 类单元标为 B。

持续音检测器和瞬态检测器这两个检测器会确保检测到的结构至少标记为 B 类。

随后通过闭环细化这些标记：

1. 编码器根据每个单元自身的标记进行编码；
2. 解码该结果；
3. 在误差上运行检测器；
4. 仅提升在其自身等级下仍受损的单元。

持续音检测器（`src/tone_scan.cpp`）没有灵敏度设置。其阈值根据平均周期图的噪声统计确定：

- **周期图。**周期图由汉宁窗长 FFT 计算，重叠率为 50%。FFT 长度取不短于 0.09 s 的最小二次幂。
- **时间尺度。**周期图分别在 1、2、4、8 和 16 个长 FFT 帧上取平均，因此会在五种时间尺度下检测结构。
- **阈值。**每种尺度的阈值都是伽马分布分位数，对应每次检测约 $10^{-9}$ 的固定虚警率。
- **噪声底。**局部噪声底取自相邻 32 箱分块的中位数。在闭环误差检查中，也可以根据参考信号的周期图计算。
- **检测结果。**每个尺度至少需要连续两个窗口满足条件，允许 ±1 箱的漂移。时间上重叠且相隔不超过 3 箱的检测结果会合并。

瞬态检测器的统计描述属于未来工作（第 17.2 节）。

v5 的结构保留结果尚未发布。使用注入的真实目标（音调和点击声）对 v5 重新验证也属于未来工作（第 17.2 节）。

### 7.5 模式驱动的全局选择（编码器）

工作模式不会规定块大小，而是规定：在整条音轨范围内，D 类和 C 类内容必须有多少比例保持在自身等级。其余 C 类和 D 类内容可以降级。

对于每种模式，编码器都会在整条音轨范围内选择分区和叶节点类别，使编码总字节数最小，同时满足这些保留比例。

- **降级代价。**使用拉格朗日乘数 λ 表示降级代价。通过二分法找到该乘数，先处理 C 类，再处理 D 类，一次遍历即可完成。
- **根块内搜索。**动态规划会评估所有子矩形和每个允许的切分位置。一个由 16 个单元 × 8 帧组成的根块包含 136 × 36 = 4,896 个子矩形，每个矩形最多尝试 22 个切分位置。
- **大小评估。**大小评估使用与实际范围编码器相同的概率模型。最后再用实际编码器编码。

搜索只受精度约束，不对片段或数据包的字节数设上限。乘数 λ 和比例目标仅存在于编码器中；解码器只读取分区树。

默认按单元数量测量比例：

- 选项 `energy` 按能量测量；
- 模式 `max` 始终按能量测量；
- 模式 `keep` 和 `keep20` 同时按单元数量和能量测量。

根块搜索以并行方式运行。线程数不会影响输出：16 线程和 1 线程编码所得文件逐字节相同。

## 8 量化

### 8.1 步长

每个非 A 类叶节点都携带指数 $E$ 和等级 $t \in \lbrace B, C, D \rbrace$：

- $E$ 是该叶节点中最大系数绝对值（以 24 位单位表示）的位长度；
- 各等级的位数为 $\mathrm{TB}(B) = 2$、$\mathrm{TB}(C) = 4$、$\mathrm{TB}(D) = 8$。

量化步长 $\Delta = 2^s$，以 24 位单位表示。指数 $s$ 根据三条**精度规则**之一计算。每个数据流头部都会记录规则编号。

| 规则 | 用途 | 公式 | 高电平块 | 安静块 |
|---|---|---|---|---|
| 1 | 方案 1（两层）；方案 2 的位深层 | $s = \max(0, \min(E, 8) - \mathrm{TB})$ | B18 / C20 / D24 | 比块峰值低 TB 位 |
| 2 | 方案 2 的频率层 | $s = \max(0, \min(E - \mathrm{TB}, 8 - \lbrace 0, 4, 8 \rbrace))$ | B16 / C20 / D24 | 同规则 1 |
| 3 | keep20 的位深层 | $s = \max(0, \min(E, 6) - \mathrm{TB})$ | B20 / C22 / D24 | 比块峰值低 TB 位 |

规则 2 中，第二项对 B、C、D 分别为 8、4 和 0。

- **安静叶节点**（$E$ 低于上限）。步长根据叶节点峰值设定。随后系数会保留固定数量的有效位，因此无论绝对电平如何，都能保持波形相似度。
- **高电平叶节点。**上限确定绝对位深分辨率。例如，规则 1 使 B 类叶节点达到 16 + 2 = 18 位。

**16 位下限保障。**所有规则均满足 $s \le 8$，因此步长不会粗于一个 16 位 LSB（以 24 位单位计为 256），也就是 CD 层的分辨率。因此，所有高于 16 位等级的内容均采用波形编码。

上限是固定的格式常量。

**动态范围。**该格式理论上限为 144 dB，即 24 位采样的范围。主要内容的设计目标为 120 dB。

### 8.2 死区

编码器使用参数为 θ = 0.30 的标量死区量化器：

$$|q| = \left\lfloor \frac{|X|}{\Delta} + 0.5 - 0.30 \right\rfloor ,$$

其中 $q$ 的符号与系数 $X$ 相同。死区是编码器参数；解码器只需要使用下文的重建规则。

开发期间还评估了更小的死区（0.15 和 0）。这使误差改善约 2–3 dB，但总大小分别增加 +3% 和 +6%（表 12.5），因此未采用。

### 8.3 重建偏移

非零量化索引 $q$ 按以下方式重建：

$$\hat X = \operatorname{sign}(q)\left(|q| + 0.20\right)\Delta .$$

偏移量 0.20 是格式常量。在表 12.5 的开发测量中，与仅使用泄漏补偿相比，该偏移：

- 未改变扩展大小；
- 使平均超声误差改善 1.8 dB；
- 使用 18 位位深层时使平均峰值误差改善 2.0 dB，使用 20 位位深层时改善 2.8 dB。

### 8.4 零系数与可选零级别

**零系数。**默认情况下，零量化索引会重建为精确的零。此规则影响较小：

- 在 CD 频带中，扩展下方有 CD 层，因此不会产生频谱缺口；
- 在超声频带中，仅缺失低于步长 0.5–0.8 倍的成分；
- 开发测量显示，解码信号的超声电平比母带低 0.3–1.4 dB。

**可选零级别（`zs`，默认关闭）。**启用 `zs` 后，编码器会传输每个量化为零的系数的真实符号。随后该系数将重建为“符号 × 叶节点级别 × 步长”。

- 每个叶节点携带一个 3 位索引 $k$。
- 当 $k = 0$ 时，零系数重建为零。
- 当 $k > 0$ 时，叶节点中的每个零系数后跟一个旁路编码位，用于表示其真实符号。该系数重建为 $\pm \mathrm{ZC}[k] \Delta$。

级别表为：

$$\mathrm{ZC} = \lbrace 0, 1/32, 1/16, 3/32, 1/8, 3/16, 1/4, 3/8 \rbrace .$$

编码器根据叶节点自身的统计量为每个叶节点选择 $k$。未启用此选项时，编码器会为每个叶节点写入 $k = 0$。

开发期间测得 `zs` 的影响如下（10 秒片段，模式 3）。

| 数值 | 影响 |
|---|---|
| CD 频带误差（24 位路径） | 从约 −111.5 改善至约 −115 dBFS（约改善 3.5 dB） |
| 超声误差 | 改善 1–5 dB |
| 峰值误差 | 改善 1–7 dB |
| 位深层大小 | +23–28% |
| 频率层大小 | +4% 至 +67%；超声内容越弱，增幅越大 |
| CD-Extra 播放时长，方案 2，超声内容较弱的 DXD 录音 | 可能从约 45 分钟降至约 36 分钟 |
| 确定性 | O2 和 Od 解码结果逐字节相同 |

该选项默认仍为关闭状态。

### 8.5 A 类

A 类叶节点不携带系数。其所有系数都重建为精确的零。

## 9 熵编码

所有叶节点数据都使用自适应二进制范围编码器编码。完整的二值化定义见 [SPEC.md](spec/lossy/SPEC.md) 第 6–8 节。本节概述其结构。

**概率自适应。**每个自适应二进制模型都使用固定移位量 5 更新。

**二值化。**多值符号通过固定二叉树二值化：

- 系数位长度使用固定的 5 位树；
- 叶节点零级别索引使用 3 位树。

**系数上下文。**系数上下文根据其叶节点类别和叶节点指数确定。

**边信息上下文。**

- **类别符号。**使用比特流中前一个叶节点的类别作为上下文进行编码。
- **指数。**编码为与前一个非空叶节点指数的差值。
- **零级别索引。**使用类别符号作为上下文进行编码。

**树比特。**

- 切分和方向标志位采用旁路位编码。
- 切分位置采用固定长度旁路编码整数。
- `zs` 下传输的符号采用旁路位编码。

**模型状态。**每个数据流均从默认模型状态开始。版本 5 未定义随机访问点（[SPEC.md](spec/lossy/SPEC.md)，第 6.8 节）。

## 10 容器（v5）

本节为摘要。规范性描述见 [SPEC.md](spec/lossy/SPEC.md) 第 3–5 节。

### 10.1 封装

在容器 v5 中，LAE 文件为 RIFF/WAV 文件：

- 其 `data` 块是 CD 层；
- 扩展位于单独的块中，块 ID 为 `LAE `（末尾带一个空格）。

播放器会忽略未知块并播放 CD 层。文件以 `.wav` 扩展名分发。`.lae` 是该格式专用扩展名；容器 v5 尚未规定 `.lae` 文件布局。

以下封装功能尚未实现：

- 在 FLAC 中封装（以 `.flac` 分发）；
- 封装到 CD-Extra（44.1 kHz 系列），其中音频会话承载 CD 层，数据会话承载扩展。

### 10.2 扩展块布局

所有头部整数字段均为小端 32 位整数。边界采样为小端 16 位整数。

| 字段组 | 内容 |
|---|---|
| 标识 | 魔数 `LAE1`；容器版本 5 |
| 采样率和长度 | 母带采样率；基础采样率；倍频程级数；母带长度；母带采样率下每侧的填充长度 P |
| 信息字段 | CD 截止频率；模式索引（0 max、1 “1”、2 “3”、3 “5”、4 keep、5 keep20）；等分切分标志；比例度量。这些字段仅用于显示，不影响解码；但模式索引仍必须在 0–5 范围内。 |
| 边界 | 扩展基础层长度 nb；两端各有的扩展采样数 pb；每端的 pb 个立体声 CD 采样 |
| 抖动标志 | 标志字节数；随后为每个声道、每 4096 个基础采样率采样的 1 字节标志，先存放所有左声道标志 |
| 位深层 | L 流、R 流 |
| 频率层 | 片段数 n；n 个 M 流；n 个 S 流 |
| 完整性 | 对此前所有内容计算的 CRC-32 [9] |

### 10.3 数据流布局

每个数据流由字节数、十个头部字段和范围编码数据组成。头部字段为：

- K；
- N；
- 起始谱线；
- 结束谱线；
- 采样率；
- 长度；
- 单元宽度 + 256 × 精度规则编号；
- 模式；
- 等分切分标志；
- 范围编码字节数。

精度规则编号如下：

- 1：B18/C20/D24；
- 2：B16/C20/D24；
- 3：keep20 位深层，B20/C22/D24。

K 是平面中的 MDCT 帧数，必须为正数，且应等于 $\lceil L_s/512 \rceil + 1$。其中 $L_s$ 对位深流来说是填充后的基础层长度 nb；对频率流来说是填充后的母带长度。若 K 较小，缺少的帧会解码为零（[SPEC.md](spec/lossy/SPEC.md)，第 5.3 节）。

### 10.4 验证

发生以下任一情况时，解码器会拒绝该文件：

- 扩展块的 CRC 不匹配；
- 头部字段彼此不一致；
- CD 音频长度与扩展块不匹配；
- 任一编码值超出范围；
- 容器版本不为 5。

所有头部字段都会在使用前进行验证。参考解码器还提供以下保护：

- 读取边界检查；
- 防止恶意文件造成循环不终止；
- 采样率参数检查，包括拒绝负输出采样率；
- 支持 64 位文件大小；
- 防止输出大于 4 GB；
- 溢出保护。

## 11 模式与码率

### 11.1 方案与模式

两种方案和六种模式共组成十二种组合。两种方案为：

- 方案 1（`s1`，高质量，默认）；
- 方案 2（`s2`，高压缩）。

| 模式（`lae_enc` 参数） | D 类保留比例 | C 类保留比例 | 位深层 | 比例度量 |
|---|---|---|---|---|
| `max`（最大压缩） | 10% | 30% | 18 位（规则 1） | 能量 |
| `1` | 30% | 50% | 18 位（规则 1） | 单元数 |
| `3`（默认） | 50% | 70% | 18 位（规则 1） | 单元数 |
| `5` | 70% | 90% | 18 位（规则 1） | 单元数 |
| `keep` | 90% | 100% | 18 位（规则 1） | 单元数 + 能量 |
| `keep20` | 90% | 100% | 20 位（规则 3） | 单元数 + 能量 |

以噪声为主的录音中，各模式的文件大小必然相近：模式仅调整 C 类和 D 类内容，而这类录音中此类内容很少。相邻模式之间测得的大小差异见第 11.4 节。

### 11.5 CD-Extra 播放时长

CD-Extra 仅适用于 44.1 kHz 系列。在 CD-Extra 光盘上，CD 层是第一会话中的普通 Red Book 音频，扩展则占用第二会话中的 Mode 1 数据扇区。以下为计算所用常数。

| 常数 | 数值 |
|---|---|
| 80 分钟光盘 | 360,000 个扇区，每秒 75 个扇区 |
| Mode 1 数据扇区 | 2048 字节，因此每分钟光盘空间可存放 9.22 MB 数据 |
| 多会话开销（第一会话 lead-out ≈ 6,750 个扇区，第二会话 lead-in ≈ 4,500 个扇区） | ≈ 11,250 个扇区 ≈ 2.5 分钟。这些是 Blue Book 常用数值；使用刻录软件确认属于未来工作（第 17.3 节）。 |
| ISO 9660 文件系统 [5] | 约 1–2 MB（≈ 0.2 分钟），为估算值；每个文件均按 2048 字节对齐 |
| 安全余量 | 容量的 1.5% 或 4% |

令 $r$ 为每分钟音乐的扩展大小（单位 MB）除以 9.22。专辑时长 $L$ 必须满足：

$$L(1 + r) + 2.5 + 0.2 \le C$$

单位为光盘分钟，其中 $C$ 是扣除安全余量后的容量。

**上限。**若超声内容全部为 A 类，频率层几乎为空。此时播放时长约为：

| 352.8 kHz (U) | 1 | 3 | −111 | −102 | −119 | −93.8 | −107.4 |
| 352.8 kHz (U) | 2 | 3 | −111 | −102 | −109.5 | −85.6 | −98.9 |
| 352.8 kHz (U) | 1 | keep20 | −124.5 | −102 | −119 | −94.9 | −109.8 |

真实录音的结果总结如下。

- **CD 频带，24 位路径。**
  - 默认误差约为 −111 dBFS。按每位 6.02 dB 计算，这相当于约 18.5 位，比 16 位路径好 9 dB。
  - keep20 可达到约 −124 至 −125 dBFS。
  - 按设计，两种方案的 CD 频带相同。
  - 开发期间对 40 秒片段的测量（2026-10-17）得到相同数值。
- **超声频带。**第一超声倍频程的误差中位数：方案 1 为 −114 至 −119 dBFS，方案 2 为 −103 至 −109.5 dBFS，具体取决于采样率。
- **方案差异。**
  - 第一倍频程超声误差的方案间差异为 4.5 至 13 dB，具体取决于采样率。
  - 在表 11.3a 中，两种方案的频率层大小相差约 1.3 至 2 倍，扩展大小相差约 1.2 至 1.8 倍。

在模式 3 下，DSD 转换材料的第一超声倍频程测量结果（方案 1 / 方案 2）为：

- 88.2 kHz：−115 / −103 dBFS；
- 176.4 kHz：−118 / −106 dBFS；
- 352.8 kHz (U)：−121 / −109 dBFS。

该类材料在 24 位路径中的 CD 频带误差为 −111 dBFS，在 16 位路径中为 −101 至 −102 dBFS。

### 12.3 合成材料与固有限制

**合成套件。**在候选发布轮次中，生成的合成套件（60 个信号）在 24 位路径下的 CD 频带误差中位数为：

- 在不同采样率及 `max` 至 `keep` 模式下为 −111 至 −115 dBFS；
- 使用 keep20 时为 −121 至 −125 dBFS。

**Synth，16 位路径。**合成压力测试信号 “Synth” 包含方波，其带限形式会超过满量程。CD 层必须对这些信号削波，而 16 位路径没有位深层可用于恢复。因此，对于这类信号，该路径的 CD 频带误差属于固有限制：

- 在 40 秒片段上为 −42 dBFS，这是开发期间测得的（2026-10-17）；
- 在候选发布轮次的 10 秒片段上为 −35 至 −36 dBFS。

**Synth，24 位路径。**

- 在一项 40 秒开发对比中，泄漏补偿将 Synth 的 24 位路径 CD 频带误差从 −79 改善至 −112 dBFS。
- 在候选发布轮次中，Synth 在 `max` 至 `keep` 模式下的 24 位路径 CD 频带误差，在 88.2、96、176.4 和 352.8 kHz 下依次为 −101、−113、−96 和 −82 dBFS。
- 使用 keep20 时，96 kHz 下的数值为 −125 dBFS；其余三项不变。
- 176.4 和 352.8 kHz 下的数值尚未分析（第 17.4 节）。

### 12.4 输出限幅

解码器的最终输出会被硬限幅至 24 位范围。

- **过冲受限。**16 位下限保障（第 8.1 节）将任何超过满量程的过冲限制在编码误差范围内。开发测量中，对 +12 dB 硬削波母带进行测试，峰值误差最高为 −76.6 dBFS。硬限幅器会将这类采样恢复至满量程，也就是母带在这些采样位置上的值。
- **限幅器触发情况。**候选发布轮次中，没有任何一次编码会触发解码器的硬限幅器（已发布数据的 `limiter_samples` 列）。
- **编码器报告。**编码器会执行诊断解码，并报告将被硬限幅的采样数量，供参考。

### 12.5 v5 常量的开发测量

开发期间进行了一项变体研究，比较以下因素：

- 泄漏补偿；
- 重建偏移；
- 位深层精度；
- 保护带；
- 更小的死区。

研究使用了 12 个来源的立体声片段。除合成 `electronic` 和 `transients` 片段为 20 秒外，其余片段均为 40 秒。来源包括 96–352.8 kHz 的真实录音和合成压力测试信号。

研究使用的是一个 v5 之前的开发构建，其零系数重建方式与 v5 不同。因此绝对数值已被后续结果取代；此处仅列出相对影响。

**表 12.5 — 相对于不使用泄漏补偿的基线的平均变化（方案 1、模式 3；12 个来源；v5 前构建）。**

| 变体 | 扩展大小 | CD 频带（dB） | 超声 1（dB） | 峰值误差（dB） |
|---|---|---|---|---|
| 泄漏补偿 | +0.2% | −5.1 | 0 | −3.5 |
| 补偿 + 重建偏移 0.20 | +0.2% | −5.8 | −1.8 | −5.5 |
| 补偿 + 19 位位深层 | +6.6% | −11.0 | 0 | −3.9 |
| 补偿 + 20 位位深层 | +12.6% | −16.8 | 0 | −4.1 |
| 补偿 + 20 位位深层 + 偏移 0.20 | +12.6% | −18.6 | −1.8 | −6.9 |
| 保护带（起始频率以上 2 kHz 固定为 D 类） | +2.6% | 0 | +0.1 | −0.2 |
| 补偿 + 死区 0.15 | +3.2% | −7.1 | −2.0 | −5.9 |
| 补偿 + 死区 0 | +5.6% | −8.1 | −2.9 | −6.5 |

合成来源主导了 CD 频带平均值。在真实录音中，单独使用泄漏补偿后，CD 频带误差仍为 −111 dBFS；只有一个 DSD 转换来源从 −109 改善至 −111 dBFS。

这些变体中，版本 5 使用：

- 所有模式均启用泄漏补偿和 0.20 重建偏移；
- `keep20` 模式使用 20 位位深层。

针对差异敏感材料的听音测试属于未来工作（第 17.3 节）。候选流程包括 ABX 和 webMUSHRA [11]。

## 13 确定性与一致性

### 13.1 算术

插值和抽取使用整数滤波器表。

系数重建和逆 MDCT 使用 IEEE-754 binary64 算术 [7]，并严格按照参考源码中的运算顺序计算。所有 MDCT 常量均来自 `src/mdct_tables.h` 中的精确十六进制字面值。在这些条件下，所有平台都会生成逐位相同的输出。

禁止使用以下构建选项：

- `-ffast-math`；
- `/fp:fast`；
- 任何允许融合乘加收缩的选项。

在使用 GCC 或 Clang 的 32 位 x86 上，必须使用 `-msse2 -mfpmath=sse`。不支持 x87 构建，解码器的启动自检会拒绝此类构建。

### 13.2 启动自检

每次启动时，解码器都会将固定数据集送入逆 MDCT，并对结果计算 64 位指纹。

- 指纹采用 FNV-1a 风格哈希 [8]，但初始值为非标准值，详见 [SPEC.md](spec/lossy/SPEC.md) 第 13 节。
- 指纹必须等于 `0x729b547fbdbfe203`，即 `src/mdct_tb.h` 中的 `SELFTEST_REF` 值。
- 若不相同，说明构建改变了浮点求值过程。解码器将拒绝运行（退出代码 4），而不会生成与其他平台不同的输出。

工具 `tools/selftest_ref.cpp` 会打印当前构建的指纹。

### 13.3 已验证的配置

已验证的构建列在 [docs/BUILD.md](docs/BUILD.md) 第 3 节。

- **Windows，MSVC 2022。**解码器的 x64 `/O2`、x64 `/Od` 和 x86 SSE2 构建结果完全一致。MSVC 编码器生成了参考向量文件。
- **Linux，解码器。**解码器使用 GCC 13 x86-64（`-O2` 和 `-O0`）、Clang 18 x86-64（`-O2`）以及 GCC 13 x86 32 位（SSE2）构建。256 项解码结果全部与参考结果一致。
- **Linux，编码器。**使用 GCC 13 x86-64（`-O2` 和 `-O0`）构建的编码器逐字节重现了全部 16 个一致性向量文件。
- **尚未覆盖。**ARM 尚未测试。不支持 x87 构建（第 13.1 节）。

开发期间还测得以下结果：

- 使用 `zs` 选项时，优化和未优化的解码结果逐字节相同；
- 在候选发布轮次中，83 项优化与未优化解码器的对比结果逐字节相同（已发布数据中的 `o2_equals_od` 列；该数据不包括 352.8 kHz 录音）。

### 13.4 其他不变量

- **编码器线程。**编码器线程数不会影响比特流。
- **编码器自检。**编码器会重新解码每一层和片段；如有任何系数平面不匹配，则拒绝写入文件。
- **开发运行。**开发期间的测量（2026-10-17）显示，331 次编码—解码运行均顺利完成。
- **候选发布轮次。**v5 候选发布版成功完成 996 次编码，且每次编码均通过编码器自检。

### 13.5 一致性测试向量

一致性测试向量及其哈希值列于 [tests/vectors/MANIFEST.md](tests/vectors/MANIFEST.md)。

**材料。**测试向量取自自动生成的合成套件：每种信号从第 5 s 开始取 2 s。未使用第三方录音。

**信号。**使用四种信号：`sweep`（88.2 kHz）、`transients`（176.4 kHz）、`imd`（96 kHz）和 `electronic`（352.8 kHz）。每种信号均采用以下四种配置编码：

- 模式 3，方案 1；
- max 模式，方案 2；
- keep20，方案 1；
- 模式 3、方案 1，并启用 `zs`。

**哈希。**每个向量都是编码器输出文件。清单列出编码文件的 SHA-256 [10]，以及以下四种路径所生成 WAV 解码文件的 SHA-256：

- `full`；
- `16`；
- `cd24`；
- 以母带一半的采样率运行的 `full`。

对于 88.2 和 96 kHz 向量，母带采样率的一半等于基础采样率，因此不支持半采样率 `full` 路径（第 14.3 节）。

清单目前仅列出每个哈希的前 16 个十六进制数字。公开完整哈希值是 [SPEC.md](spec/lossy/SPEC.md) 附录 C 的待办事项。

符合规范的解码器必须针对每个向量和路径重现所列哈希值。

## 14 使用
### 14.1 构建

代码为标准 C++17，不使用第三方库。编码器由 `src/lae_enc.cpp` 构建，解码器由 `src/lae_dec.cpp` 构建。

- **解码器源文件。**解码器使用 `src/lae_dec.cpp`、`src/part_stream.h`、`src/partition_format.h`、`src/mdct_tb.h`、`src/mdct_tables.h`、`src/halfband.h` 和 `src/wavio.h`（[SPEC.md](spec/lossy/SPEC.md)）。
- **编码器源文件。**编码器会将解码器编译到同一可执行文件中。此外还使用 `src/partition.h`、`src/fft.h`、`src/pad_mirror.cpp`、`src/base_layer.cpp`、`src/routes.cpp`、`src/lossy_v2.cpp`（其中包含 `src/tone_scan.cpp`）以及 `src/part_coder.cpp`。

两个程序均可在 Windows 上使用 MSVC 构建，也可在 Linux 上使用 GCC 和 Clang 构建。示例命令：

```
cl /O2 /EHsc /std:c++17 /D_USE_MATH_DEFINES src\lae_dec.cpp
g++ -O2 -std=c++17 -ffp-contract=off -D_USE_MATH_DEFINES -pthread -o lae_dec src/lae_dec.cpp
g++ -O2 -std=c++17 -ffp-contract=off -D_USE_MATH_DEFINES -pthread -o lae_enc src/lae_enc.cpp
```

其他构建说明：

- 使用 MSVC 构建编码器时，添加 `/bigobj`。
- 使用 GCC 或 Clang 构建 32 位 x86 时，添加 `-msse2 -mfpmath=sse`。
- 不要使用 `-ffast-math`、`/fp:fast` 或任何允许 FMA 收缩的选项（第 13.1 节）。

所有选项、已验证的构建和检查脚本见 [docs/BUILD.md](docs/BUILD.md)。

### 14.2 编码

```
lae_enc <master.wav> <output.wav> [mode] [s1 | s2] [zs] [cd=<cd.wav>] [energy] [equal]
```

| 参数 | 含义 |
|---|---|
| `master.wav` | 立体声整数 PCM WAV，16/24/32 位（32 位输入使用高 24 位）。采样率为 88.2/176.4/352.8 kHz（44.1 kHz 系列）或 96/192/384 kHz（48 kHz 系列）。 |
| `mode` | `max`、`1`、`3`（默认）、`5`、`keep`、`keep20`（第 11.1 节）。模式为位置参数：只要使用任何后续参数，就必须提供模式。 |
| `s1` / `s2` | 方案 1，高质量（默认）/方案 2，高压缩。两者的 CD 频带相同，差异仅在频率层。 |
| `zs` | 可选零级别（第 8.4 节）；默认关闭 |
| `cd=<file>` | 独立 CD：母带所属系列基础采样率（44.1/48 kHz）的 16 位立体声 WAV；须与母带按采样对齐且长度相同；将逐位写入 CD 层 |
| `energy` | 按能量衡量保留比例（模式 `max`、`keep` 和 `keep20` 使用各自的度量方式） |
| `equal` | 只使用等分（对半）切分 |

编码器说明：

- 输出 WAV 的音频就是 CD 层；扩展位于 `LAE ` 块中。
- 编码器使用与逻辑核心数相同数量的线程。环境变量 `PARTTHREADS` 可覆盖此值。线程数不会影响结果。
- 编码器会将整条音轨载入内存处理。

开发期间测得的编码性能：

- **单个任务（2026-10-16；[docs/BUILD.md](docs/BUILD.md)，第 5 节）。**在 Windows x64 上，以 16 线程对 352.8 kHz、40 s 的立体声母带进行模式 3 编码，用时 113 s（约为实时速度的 0.35 倍）。峰值内存为 1.35 GB。
- **三个并行任务，每个任务使用 8 个线程（2026-10-17）。**编码 40 s 音频用时：
  - 352.8 kHz：160–260 s；
  - 176.4/192 kHz：90–140 s；
  - 96 kHz：45–65 s。

  单个任务的速度约快一倍。

### 14.3 解码

```
lae_dec <input.wav> <output.wav> [full | 16 | cd24] [output rate]
```

| 路径 | 使用的层 | 输出 |
|---|---|---|
| `full`（默认） | CD + 位深 + 频率 | 母带采样率或所选较低倍频程，24 位 |
| `16` | CD + 频率 | 同上；CD 频带为 16 位精度 |
| `cd24` | CD + 位深 | 44.1/48 kHz，24 位 |

在 `full` 和 `16` 路径中，输出采样率可以是母带采样率，或低至基础采样率两倍的任意较低倍频程；其他采样率会被拒绝。所选倍频程以上的频率数据流不会读取或解码。

解码器采用单线程流式处理：

- 每次解码一行根块（8 帧），并逐帧执行重叠相加；
- 重采样级通过短滑动窗口提取采样；
- 除输入数据外，其内存占用不会随音轨长度增长。目前会将 CD 层和扩展块整体读入内存。

开发期间测得的解码性能：

- **单个任务（2026-10-16；[docs/BUILD.md](docs/BUILD.md)，第 5 节）。**在 Windows x64 上，以 24 位路径解码 352.8 kHz、40 s 的文件，用时 2.8 s（约为实时速度的 14 倍）。峰值内存为 38 MB。
- **三个并行任务（2026-10-17）。**以 24 位路径解码 40 s 音频用时：
  - 352.8 kHz：3–5 s；
  - 176.4/192 kHz：2–3 s；
  - 96 kHz：约 2 s。

### 14.4 示例

```
lae_enc master_352k.wav track_352k.wav                     # mode 3, scheme 1
lae_enc master_352k.wav track_352k_max.wav max s2          # smallest extension
lae_enc master_192k.wav track_192k.wav keep20 s1           # 20-bit depth layer
lae_enc master_96k.wav track_96k.wav 3 s1 cd=cd_48k.wav    # independent 48 kHz CD
lae_dec track_352k.wav out_full.wav                        # 24 bit, 352.8 kHz
lae_dec track_352k.wav out_176k.wav full 176400            # 24 bit, one octave down
lae_dec track_352k.wav out_cd24.wav cd24                   # 24 bit, 44.1 kHz
```

## 17 局限与未来工作

### 17.1 格式与等级

- **LAE Lossless（LAES）。**设计文档已发布（[spec/lossless/DESIGN.md](spec/lossless/DESIGN.md)）；规范性规范尚未编写。存在全部层时，无损等级将逐位精确地重建母带。
- **容器。**目前仅实现 WAV 容器。FLAC 封装、CD-Extra 封装以及 `.lae` 文件布局属于封装阶段的工作。
- **声道。**目前仅支持立体声。

### 17.2 编码器

- **流式编码器。**由于模式比例属于整条音轨范围的统计值，编码器目前会处理整条音轨。内存随长度线性增长：352.8 kHz、40 s 音频约需 1.35 GB。后续将设计分段流式编码器。
- **CD 对齐。**独立 CD 模式要求 CD 与母带按采样对齐且长度相同。计划在封装阶段自动检测错位；届时若 CD 错位，将报告错误而非尝试补偿。
- **噪声移除导出界面。**该界面尚未实现。该界面计划：
  - 显示波形和频谱视图；
  - 提供试听；
  - 允许用户移除选定的噪声区域（A 类）。

  在该功能实现之前，母带中的所有噪声都会保留。
- **闭环重新验证。**使用注入音调和点击声，对标记闭环的结构保留测试将在 v5 上重新进行。
- **检测器文档。**瞬态检测器的统计特性将补充文档说明（第 7.4 节）。

### 17.3 工具与验证

- **CD-Extra。**目前尚无 CD-Extra 刻录工具。以下事项待完成：
  - 使用实际刻录软件确认第 11.5 节的多会话开销数值；
  - 进行 CD-Extra 刻录和刻录测试；
  - 使用真实 CD-Extra 播放器进行兼容性测试。
- **待完成的测量和测试。**
  - 为规范编制半带滤波器特性说明；
  - 在 ARM 上构建并检查自检指纹；
  - 测量泄漏补偿项对 `cd24` 路径的影响（第 6.5 节）；
  - 分析 176.4 和 352.8 kHz 下 Synth 的 CD 频带数值（第 12.3 节）；
  - 播放器兼容性测试；
  - 听音测试。
- **音质估算器。**第 12.1 节所用音质指标的精确定义将写入测试文档。
- **规范性文本。**SPEC.md 规定了 M/S 提升变换、抖动生成器及其种子、熵编码器的二值化、数据流头部字段 K 和滤波器表。其待办事项（[SPEC.md](spec/lossy/SPEC.md)，附录 C）包括：
  - 测试向量的完整 SHA-256 数值；
  - 将 `src/mdct_tables.h` 作为规范性附录；
  - 解码器是否必须拒绝采样率与基础采样率不同的 `fmt `；
  - 数据流头部字段 `rate` 和 `L` 的取值，以及最后一个数据流之后是否允许有字节；
  - 半带累加器的 64 位溢出保证上界；
  - 是否必须检查整个数据流的损坏情况，还是只需检查所选路径需要的部分；
  - `.lae` 文件布局和 FLAC 封装；
  - 编码器的边界填充方式及其叶节点指数定义。

### 17.4 已知工作限制

- **模式间隔。**真实录音中，从 `max` 到 `keep` 的相邻模式大小变化中位数仅约为 0.3–3.6%（第 11.4 节）。
- **最差播放时长。**在候选发布轮次中，352.8 kHz、方案 2、max 模式、24 位路径的最差结果在 4% 余量下比 40 分钟目标少 0.8 分钟。该结果基于未包含在已发布数据中的录音（第 11.5 节）。
- **被削波的 CD 内容。**16 位路径无法恢复 CD 层必须削波的内容（第 12.3 节）。
- **`full` 路径之外的泄漏。**频率层向 CD 频带的泄漏仅在 `full` 路径中得到补偿（第 6.5 节）。
- **高采样率下的 Synth。**Synth 信号在 176.4 和 352.8 kHz 下的 24 位路径 CD 频带误差（−96 和 −82 dBFS）明显差于 88.2 和 96 kHz。原因尚未分析（第 12.3 节）。
- **采样率系列。**编码器不执行有理数比例重采样。
  - 48 kHz 系列母带与 48 kHz 基础层组合。若要与 44.1 kHz CD 组合，仍需在母带制作阶段处理。
  - 48 kHz 基础层面向 DVD、蓝光和文件分发；CD-Extra 仅适用于 44.1 kHz 系列。
