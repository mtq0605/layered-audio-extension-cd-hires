# Measurement data

## Contents

- [SIZES.md](SIZES.md): readable size tables (MB per minute) for every mode, scheme and sample rate, generated from the CSV below.

`loop10_v5_release_candidate.csv` holds the results of the test round of the LAE Lossy v5 release candidate. This round is named "loop10" in the file name and is called the "release-candidate round" in the [README](../README.md). It was measured during development on 2026-10-16.

The procedure was:

1. 10-second stereo excerpts were encoded with both schemes (`s1`, `s2`) and all six modes;
2. each encoded file was decoded;
3. each decoded file was compared with its excerpt.

## Build

The release candidate differs from the published v5 codec in the reconstruction of zero coefficients. On the same excerpts, the published v5 encoder gives frequency-layer sizes 0.01–0.3 % smaller and an SNR 0–0.6 dB better.

## Coverage

- **Recordings.** Recordings at 88.2–192 kHz are included in anonymised form. They are third-party recordings and are not distributed.
- **Synthetic signals.** These are generated by `src/gen_suite.cpp`.
- **352.8 and 384 kHz.** At these rates, the data contain synthetic signals only. The README figures for recordings at 352.8 kHz are therefore not part of these data.
- **Classes.** The `type` column distinguishes only recordings and synthetic signals. The README classes "DSD-converted" and "Synth" are not marked separately.

## Columns

- `item`, `type`: recordings are anonymised (`rec01`, `rec02`, …) and have type `recording`. Synthetic test signals keep their names and have type `synthetic`.
- `rate`: master sample rate in Hz.
- `scheme`, `mode`: encoder settings ([README](../README.md), Section 11).
- `cd_bytes`, `depth_bytes`, `frequency_bytes`: size of the CD layer PCM and of the two extension layers.
- `encode_s`, `encode_MB`, `decode_s`: encoder time, encoder peak memory and decoder time. The encoder ran three jobs in parallel, with 8 threads each.
- `cdband_err_24bit_dB`, `cdband_err_16bit_dB`: error level in the CD band on the 24-bit and 16-bit routes.
- `hf1_err_dB` … `hf3_err_dB`: error level in the ultrasonic octave bands. A cell is empty where the master has no such band.
- All error levels are relative to full scale and are the mean of both channels. They are computed by `src/cmp_wav.cpp`.
- `snr_dB`, `peak_err_dBFS`, `worst10ms_err_dBFS`: waveform match of the decoded output against the excerpt.
- `limiter_samples`: number of samples on which the decoder's final hard limiter acted.
- `o2_equals_od`: whether optimised and unoptimised decoder builds gave byte-identical output. This was checked for scheme `s1`, mode `3`.

## Note on the ultrasonic bands of the 48 kHz family

In this round, `src/cmp_wav.cpp` placed the ultrasonic band edges at multiples of 44.1 kHz for every master. For 96 kHz and 192 kHz
masters the columns `hf1_err_dB` to `hf3_err_dB` therefore cover 24-44.1, 44.1-88.2 and 88.2-176.4 kHz rather than the octaves of the
48 kHz family. The tool has since been corrected; the measured values are otherwise unaffected.
