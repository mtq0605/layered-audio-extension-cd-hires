# 测量数据

[English](README.md)（以英文版为准）

## 内容

- [SIZES.md](SIZES.zh.md)：针对每种模式、方案和采样率的可读大小表（单位为 MB/分钟），由下文所述的 CSV 文件生成。

`loop10_v5_release_candidate.csv` 包含容器版本 5 的 LAE Lossy 编解码器发布候选版（"v5 发布候选版"）测试轮次的结果。该轮次在文件名中称为"loop10"，在 [README](../README.zh.md) 中称为"发布候选轮次"。测量于开发期间的 2026-10-16 进行。

测试步骤如下：

1. 以两种方案（`s1`、`s2`）及全部六种模式对 10 秒立体声片段进行编码；
2. 对每个编码文件进行解码；
3. 将每个解码文件与其源片段进行比较。

## 构建

该发布候选版与已发布的容器版本 5 编解码器的区别在于零系数的重建方式。由于编码器在编码过程中会解码其自身的各层，这一区别也会改变编码后的大小：在相同片段上，已发布的 v5 编码器产生的频率层大小小 0.01–0.3 %，SNR 高 0–0.6 dB。

## 覆盖范围

- **录音。** 包含对 88.2–192 kHz 录音的测量结果，已作匿名化处理。录音本身为第三方录音，不予分发。
- **合成信号。** 这些信号由 `src/gen_suite.cpp` 生成。
- **352.8 kHz 和 384 kHz。** 在这两种采样率下，数据仅包含合成信号。因此，README 中关于 352.8 kHz 录音的数据不属于本数据集。
- **类别。** `type` 列仅区分录音和合成信号。README 中的类别"DSD 转换"（录音）和"Synth"（一种合成压力测试信号）在这两种类型中未单独标注。

## 列

- `item`、`type`：录音已作匿名化处理（`rec01`、`rec02`、…），类型为 `recording`。合成测试信号保留其名称，类型为 `synthetic`。
- `rate`：母带的采样率，单位为 Hz。
- `scheme`、`mode`：编码器设置（[README](../README.zh.md)，第 11 节）。
- `cd_bytes`、`depth_bytes`、`frequency_bytes`：CD 层 PCM 的大小以及两个扩展层（位深层和频率层）的大小。
- `encode_s`、`encode_MB`、`decode_s`：编码时间、编码器峰值内存和解码时间。编码器以三个作业并行运行，每个作业 8 个线程。`decode_s` 为在 24 位路径上进行一次解码（`lae_dec`，单线程）的时间，该解码在同一作业内运行，因此同时最多有另外两个作业在运行。
- `cdband_err_24bit_dB`、`cdband_err_16bit_dB`：24 位和 16 位解码路径上 CD 频带内的误差电平（[README](../README.zh.md)，第 3.4 节：分别为含位深层和不含位深层）。
- `hf1_err_dB` … `hf3_err_dB`：超声频带内的误差电平（按采样率族的倍频程划分；关于 48 kHz 族，见下文说明）。母带不含相应频带时，该单元格为空。
- 所有误差电平均相对于满量程，并取两个声道的平均值。它们由 `src/cmp_wav.cpp` 计算。
- `snr_dB`、`peak_err_dBFS`、`worst10ms_err_dBFS`：解码输出与源片段的波形匹配程度。
- `limiter_samples`：解码器末级硬限幅器起作用的样本数。
- `o2_equals_od`：优化与未优化的解码器构建是否产生逐字节相同的输出。此项针对方案 `s1`、模式 `3` 进行检查；对于其他方案和模式，该列为空。

## 关于 48 kHz 族超声频带的说明

在本轮次中，`src/cmp_wav.cpp` 对所有母带均将超声频带的上边界置于 44.1、88.2 和 176.4 kHz。因此，对于 96 kHz 和 192 kHz
母带，`hf1_err_dB` … `hf3_err_dB` 列覆盖的是 24–44.1、44.1–88.2 和 88.2–176.4 kHz，而非 48 kHz 族的倍频程；若母带的奈奎斯特频率更低，则频带止于该奈奎斯特频率（例如，96 kHz 母带的 `hf2_err_dB` 覆盖
44.1–48 kHz）。该工具此后已得到修正；CSV 保留本轮次的数值，其他列不受影响。
