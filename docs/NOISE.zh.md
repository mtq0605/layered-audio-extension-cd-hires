# 噪声标定、`noise=` 和 `g`

[English](NOISE.md)

LAEY 可以去掉你在母带超声频带里标定的噪声。分三步，每一步用各自的工具：

1. **对齐。** `lae_enc plan` 把母带和 CD 层对齐，结果由你确认。所有标定都做在对齐后的母带上。
2. **标定。** LAE 噪声标定（`lae_noise`、`tools/noise_panel.html`，见 `plugins/lae_noise_marker/`）列出平稳噪声和固定窄线，由你选择。
   - 结果写成标定文件（`.laenoise`）。
   - 它从不删除声音，也不导出声音。
3. **编码。** `lae_enc <母带.wav> <out.wav> [mode] noise=<标定.laenoise> [g | g=b | g=c | g=d]`。

不加 `noise=` 和 `g` 时，编码器写出的文件和以前逐字节相同。

## `noise=`

- 编码器先核对标定文件属于这个母带：SHA-256、长度、采样率。
  - 如果对齐时移动了母带，编码器停下，什么都不写。请在对齐后的母带上标定。
- 在**频率层**里，标定格子中的母带按零处理。一个格子的 8 个系数都被标定时，这个格子归为 A 类（编成静音）。
- 加 `noise=` 时，频率层的起点（CD 截止频率 − 1 kHz）向下取到 8 个系数的整数倍（最多低 7 个系数），这样格子和标定的列正好对齐。
- **低于这个起点的标定在 CD 层里。** 编码器把它们列出来，不改动。CD 层和深度层都不变。

## G：静音格子里剩下的东西

**G = Ground Noise of Imaging（升采样镜像底噪）。** Ground 是"底板"的意思：垫在高解析声音最底下的一层极弱的底噪。
学术上叫插值镜像（interpolation images）或镜像分量（image components）。

- 解码器播放高解析版本时，先把 CD 层升采样到母带的采样率，再加上频率层。
- 升采样保留原来的样本，0–20 kHz 的内容不变；中间的新样本由滤波器算出，滤波器负责去掉 CD 频带的频谱副本。
  - 滤波器的止带衰减是 120 dB，所以每份副本剩下大约是音乐的 −120 dB。
  - 剩下的这一点就是 G。
- 平常频率层存的是"母带 − 升采样的 CD"，里面带着 −G，解码时两者正好抵消。
- 在 A 类格子里频率层是零，G 就留在了解码里。有两种格子会这样：
  - 你用 `noise=` 标定删除的格子；
  - 母带本身就静音的格子，例如合成音之间的数字零。

在一个 352.8 kHz 母带上实测，单位是 dBFS 每列：
- 删掉的噪声：−109.5；
- 删除后剩下的 G：−131.5；
- 24 bit 输出的取整底噪：−164.4。

也就是说，删除后的格子远低于原来的噪声，但还不是数字上的静音。

有的母带，超声频带本身*就是*升采样的 CD。在这样的母带上，只用 `noise=` 量不出变化，因为剩下的 G 就是原来的内容。要在那里删掉，需要 `g`。

## `g`

`g` 只为 G 而设。编码器把频率层**编码两次**：

1. 第一遍照常编码：A / B / C / D 分类，和不开 `g` 时完全一样。
2. 第二遍只编 −G，而且只在第一遍判成 A 的、下面两种格子里：
   - 你删除的（整格被标定的）格子；
   - 母带本身在这一格里也静音的格子（不高于 24 bit 取整底噪）。

   G 低于 24 bit 底噪的格子不做。母带不静音的 A 格子原样不动：那里的 G 就是母带自己的内容。

第二遍的流加在同一个频率层里。每个解码器都把它们和第一遍的流逐系数相加（规范第 9.5 节），G 就抵消了。现有的解码器不用任何改动就能播放这样的文件。

### 三档强度

| 写法 | 第二遍的步长 | 开 `g` 后标定格子里剩下的（演示母带，dBFS 每列） |
|---|---|---|
| `g=b` | 块峰值往下 2 bit | −126.4 |
| `g=c` | 块峰值往下 4 bit | −139.0 |
| `g=d`（或 `g`） | 1 | −156.2 |

只用 `noise=` 时，同样的格子是 −104.0（在那个母带上，那里只有 G）。

### `g` 的代价

在 LAE 演示母带上实测：352.8 kHz，mode 3，90 秒，标定一个 10 秒 × 2.76 kHz 的矩形。

| | 整个文件 | 只算扩展层（深度层 + 频率层） |
|---|---|---|
| `noise=` | 22.85 MB | 6.98 MB |
| `noise= g=b` | +0.8 % | +2.7 % |
| `noise= g=c` | +1.0 % | +3.2 % |
| `noise= g=d` | +1.2 % | +3.9 % |
| 只开 `g`（75 秒合成音，音与音之间静音） | +5.2 % | +15.7 % |

- 代价随标定的面积和母带里静音的多少增加，不随曲目长度增加。
- 只开 `g` 时，在那一段上和母带相比没有可量的变化。我们建议只在有标定时开 `g`。
- 每次开 `g` 编码后，编码器会打印 G 流占了多少 MB，也就是不开 `g` 能省下的量。
- 既没删除、也不静音的格子：不变。CD 层：不变。编码时间基本不变（90 秒节选，开不开 `g` 都是 73–79 秒）。

## 编码时的磁盘空间

编码器把中间文件放在 `<out>.tmp` 里，编完自动删除。
- 352.8 kHz 时每分钟音乐约占 0.8 GB，开 `g` 约多 15 %。
- 开始前编码器会核对剩余空间（已算进 `g` 多出的部分），不够就停下，什么都不写。
- 结束时会打印工作文件夹达到的最大占用。

## 不变的

- 文件格式和解码器。
- CD 层。
- 不加 `noise=` 和 `g` 编出的文件。
