# 噪声标定、`noise=` 和 `g`

[English](NOISE.md)（以英文版为准）

LAEY 可以省略用户在母带超声频带中标定的噪声。这需要三个独立的步骤，每个步骤使用各自的工具：

1. **对齐。** `lae_enc plan` 将母带与 CD 层对齐，结果由用户确认。所有标定均须在对齐后的母带上进行。
2. **标定。** LAE Noise Marker（`lae_noise`、`tools/noise_panel.html`；见 `plugins/lae_noise_marker/`）列出平稳噪声和固定窄线，并由用户选择对哪些进行标定。
   它写出标定文件（`.laenoise`）。它从不删除声音，也不导出声音。
3. **编码。** `lae_enc <master.wav> <out.wav> [mode] noise=<marks.laenoise> [g | g=b | g=c | g=d]`。

不使用 `noise=` 和 `g` 时，编码器写出的文件与加入这些选项之前（2026-11-04）的编码器写出的文件逐字节完全相同。

## `noise=`

- 编码器通过比较 SHA-256、长度和采样率，核对标定文件是否属于该母带。如果母带在对齐时被移动，编码器停止，不写出任何内容；此时应在对齐后的母带上进行标定。
- 在**频率层**中，标定格子内的母带按零处理。一个格子的全部 8 个系数均被标定时，该格子归为 A 类（编码为静音）。
- 使用 `noise=` 时，频率层的起点为 CD 截止频率 − 1 kHz，并向下取整到 8 个系数的整数倍（最多比不使用 `noise=` 时低 7 个系数），使其格子与标定的列对齐。
- **低于该起点的标定位于 CD 层中。** 编码器将其列出，并保持其不变。CD 层和位深层均不变。

## G：静音格子中留下的内容

**G = Ground Noise of Imaging。** “Ground”指底层：位于高解析声音最底部的一层极弱的成分。
通常的术语是*插值镜像*或*镜像分量*。

- 解码器播放高解析版本时，将 CD 层升采样到母带的采样率，再加上频率层。
- 升采样保持原有样本和 0–20 kHz 的内容不变。其间的新样本由一个滤波器计算得出，该滤波器去除 CD 频带的频谱副本。滤波器的止带衰减为 120 dB，因此每份副本保留约 −120 dB 的音乐。
  这一残余即为 G。
- 通常情况下，频率层存储的是“母带 − 升采样的 CD”，因此其中含有 −G，二者在解码时相互抵消。
- 在 A 类格子中，频率层为零，因此 G 留在解码输出中。`g` 处理两种此类格子：
  - 用户通过 `noise=` 标定并删除的格子；
  - 母带本身为静音的格子，例如合成音符之间的数字静音。

  在其余 A 类格子中，母带并非静音：其在该处的内容与 G 一样微弱（例如，超声频带为升采样 CD 的母带），因此留下的内容与母带一致。

在一个 352.8 kHz 母带上实测，单位为每列格子的 dBFS：被删除的噪声为 −109.5，删除后留下的 G 为 −131.5，输出的 24 bit 取整底噪为 −164.4。因此，被删除的格子远低于其所替代的噪声，但尚未达到数字静音。

在某些母带上，超声频带*就是*升采样的 CD。在此类母带上，仅使用 `noise=` 不会产生可测量的变化，因为留下的内容（G）恰好就是原有的内容。在此类母带上将其删除需要使用 `g`。

## `g`

`g` 仅为 G 而设。编码器对频率层进行**两次**编码：

1. 第一遍为常规编码：A、B、C、D 类与不使用 `g` 时完全相同。
2. 第二遍仅编码 −G，且仅针对第一遍中归为 A 类的以下两种格子：
   - 用户删除的格子（被完整标定）；
   - 母带本身为静音的格子（不高于 24 bit 取整底噪）。

   G 低于 24 bit 底噪的格子被跳过。母带并非静音的 A 类格子保持不变：在这些格子中，母带本身含有与 G 同等电平的内容（例如，超声频带为升采样 CD 的母带），编码 −G 将会将其去除。

第二遍的流加入同一频率层。每个解码器均将其与第一遍逐系数相加（规范第 9.5 节），从而使 G 抵消。现有解码器无需任何改动即可播放此类文件。

### 三档强度

| 选项 | 第二遍的步长 | 使用 `g` 后的标定格子（演示母带，每列 dBFS） |
|---|---|---|
| `g=b` | 块峰值 − 2 bit | −126.4 |
| `g=c` | 块峰值 − 4 bit | −139.0 |
| `g=d`（或 `g`） | 1 | −156.2 |

仅使用 `noise=` 时，相同格子的测量值为 −104.0（在该母带上，这些格子中仅含 G）。

### `g` 的代价

在 LAE 演示母带上实测：352.8 kHz，mode 3，90 s，标定一个 10 s × 2.76 kHz 的矩形：

| | 整个文件 | 仅扩展层（位深层 + 频率层） |
|---|---|---|
| `noise=` | 22.85 MB | 6.98 MB |
| `noise= g=b` | +0.8 % | +2.7 % |
| `noise= g=c` | +1.0 % | +3.2 % |
| `noise= g=d` | +1.2 % | +3.9 % |
| 仅使用 `g`（75 s 合成音符，音符之间为静音） | +5.2 % | +15.7 % |

- 代价随标定面积和母带中静音的多少而增加，而不随曲目长度增加。
- 在 75 s 的合成音符节选上（仅使用 `g`），`g` 相对于母带未产生可测量的变化。建议在存在标定格子时使用 `g`。
- 每次使用 `g` 编码后，编码器打印 G 流的大小（单位 MB）。这即是不使用 `g` 时可节省的量。
- 既未被删除也非静音的格子保持不变。CD 层保持不变。编码时间基本相同（90 s 节选为 73–79 s，无论是否使用 `g`）。

## 编码时的磁盘空间

编码器将其中间文件存放在 `<out>.tmp` 中，并在结束时将其删除。在 352.8 kHz 时，中间文件每分钟音乐约占 0.8 GB，使用 `g` 时约多 15 %。开始之前，编码器检查剩余空间（包括 `g` 所增加的空间），若空间不足则停止，不写出任何内容。结束时，编码器打印工作文件夹达到的最大占用。

## 不变的内容

- 文件格式和解码器。
- CD 层。
- 不使用 `noise=` 和 `g` 编码的文件。
