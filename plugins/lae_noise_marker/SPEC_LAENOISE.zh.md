# LAENOISE 1：LAE 噪声标定的标定文件

第 1 版，2026-11-06。[English](SPEC_LAENOISE.md)

标定文件在一个母带里标出若干个时间 × 频率的矩形。文件里只有几何信息：不记检测方法、原因、类别，也不含任何声音。
- 写它的是 LAE 噪声标定。扫描器写出的候选也用这个格式，用户从中留下一部分。
- LAE 编码器用 `noise=<文件>` 读它，把标定的格子编成静音。
- 其他程序也可以按同样的规则读它。

## 1. 文件

- 纯文本，ASCII，每行以 LF 结束（LF 前的 CR 忽略）。
- 扩展名 `.laenoise`。
- `#` 之后到行尾是注释，只给人看，读取时不能从中取任何数值。
- 可以有空行。第一个词不是 `LAENOISE`、`master`、`grid`、`pos` 的行一律忽略（第 4 节）。

## 2. 行

各行按这个顺序：

```
LAENOISE 1
master sha256 <64 位十六进制> frames <L> rate <fs>
grid mdct 512 cell 8
pos <m0> <m1> <c0> <c1>
pos ...
```

| 行 | 含义 |
|---|---|
| `LAENOISE 1` | 文件标识和版本。没有这一行就不是标定文件。 |
| `master sha256 … frames … rate …` | 标定属于哪个母带。三项依次是：WAV 文件 `data` 块全部字节的 SHA-256（采样原样，不含别的）；长度 `L`（采样帧数）；采样率 `fs`（Hz）。 |
| `grid mdct 512 cell 8` | 网格。第 1 版只有这一种，其他值一律拒绝。 |
| `pos m0 m1 c0 c1` | 一个矩形：帧 `m0` ≤ m < `m1`，列 `c0` ≤ c < `c1`。可以没有，也可以有多行。 |

## 3. 网格

网格就是 LAE 编码器频率层的网格，用母带本身的采样率。

- **平面**：M = r + ((l − r) >> 1)，S = l − r。l、r 是左右声道按 24 bit 整数取的采样。一个矩形同时覆盖 M 和 S。
- **帧**：N = 512 的 MDCT，正弦窗。
  - 第 m 帧覆盖采样 [mN − N, mN + N)。
  - 它自己的那一跳是 [mN − N/2, mN + N/2)，起点时间是 (mN − N/2) / fs。
  - 共 K = ⌊(L + N − 1) / N⌋ + 1 帧，m = 0 … K − 1。
- **列**：8 个 MDCT 系数为一列。
  - 第 c 列含系数 8c … 8c + 7，频率从 c · 8 · fs / (2N) Hz 到 (c + 1) · 8 · fs / (2N) Hz。
  - 共 64 列，c = 0 … 63。
- **格子**：一帧 × 一列。352.8 kHz 时一格是 2 756.25 Hz × 1.45 ms；44.1 kHz 时是 344.5 Hz × 11.6 ms。

## 4. 有效文件的条件

读取方先去掉注释、CR 和空行，然后只有下面几条全部成立，才接受这个文件：

1. 第一行正好是 `LAENOISE 1`：只有 `LAENOISE` 和 `1` 两个词，没有别的。第一行是别的内容（例如 `LAENOISE 12`），就不是第 1 版的标定文件。
2. `master` 行和 `grid` 行各有且只有一行，而且都在第一个 `pos` 行之前。出现第二个 `LAENOISE`、`master` 或 `grid` 行，就是错误。
3. 第一个词是 `master`、`grid`、`pos` 的行，词必须和第 2 节完全一样。SHA-256 是 64 位小写十六进制数字。`L`、`fs`、`m0`、`m1`、`c0`、`c1` 只能写十进制数字，不带正负号、小数点或指数。
4. 网格是 `mdct 512 cell 8`。
5. `frames` 等于母带的长度，`rate` 等于母带的采样率。
6. SHA-256 等于母带 `data` 块的 SHA-256。
7. 每个 `pos` 都满足 0 ≤ m0 < m1 ≤ K，0 ≤ c0 < c1 ≤ 64。

第一个词是别的内容的行一律忽略，以后的版本可能会用到这样的行。任何一条不成立，整个文件都不用。矩形可以重叠，标定的范围是它们的并集。

## 5. 时间和频率怎样换成格子

LAE 噪声标定一律**向内**取整，矩形不会超出用户选的范围：

- **时间** [t0, t1) 秒：取跳完全落在其中的帧。
  - m0 = ⌈(t0 · fs + N/2) / N⌉，不小于 0；
  - m1 = ⌊(t1 · fs − N/2) / N⌋ + 1，不大于 K。
- **频率** [f0, f1) Hz：取 8 个系数都落在其中的列。
  - c0 = ⌈f0 / w⌉，c1 = ⌊f1 / w⌋，其中 w = 8 · fs / (2N)；
  - c1 不大于 64。

## 6. 例子

```
LAENOISE 1
master sha256 de8b7ca98ccaa8331093c708a7777eacde569b41808487671b33dbec59b136e7 frames 5292000 rate 352800
grid mdct 512 cell 8   # frame m = samples [mN-N, mN+N), its hop [mN-N/2, mN+N/2); column c = bins 8c..8c+7
pos 1999 9027 10 11   # 1: 2.900-13.100 s (10.20 s), 27562.5-30318.8 Hz
```

一个 15 秒、352.8 kHz 的母带里的一个矩形：2.900–13.100 秒，27 562.5–30 318.8 Hz。

## 7. 这个格式不做什么

- 不含声音，也不改声音。要把标定的部分去掉，由读它的程序去做。在 LAE 里做这件事的是编码器：它把频率层里标定的格子编成静音。
- 不说明为什么标定这个矩形。
