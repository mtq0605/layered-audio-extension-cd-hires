# LAENOISE 1：LAE Noise Marker 的标定文件

第 1 版，2026-11-06。[English](SPEC_LAENOISE.md)（以英文版为准）

标定文件在一个母带中标出若干时间与频率的矩形。文件只包含几何信息：不包含检测器、原因、类别或音频。注释可以描述某个位置上有什么，例如电平或窄线的频率；注释从不说明为什么选这个位置。标定文件由 LAE Noise Marker 写出。扫描器以同一格式写出候选，用户保留其中的一部分。LAE Lossy (LAEY) 编码器在给定 `noise=<file>` 时读取该文件，并将标定的格子编码为静音。任何其他程序均可按相同规则读取该文件。

## 1. 文件

- 文件为纯 ASCII 文本。各行以 LF 结束；LF 之前的 CR 予以忽略。只有 LF 和 CR LF 结束一行：各行只以 CR 结束的文件会读成一行，被拒绝（第 4 节第 1 条）。
- 文件扩展名为 `.laenoise`。
- `#` 开始一条注释，注释延续至行尾。注释仅供人阅读：读取方不得从注释中取得任何会影响其处理该文件的数值。程序可以显示注释里的描述（面板显示扫描器注释中的电平和窄线频率）。
- 允许出现空行。第一个词不是 `LAENOISE`、`master`、`grid` 或 `pos` 的行予以忽略（第 4 节）。

## 2. 行

LAE Noise Marker 按以下顺序写出各行：

```
LAENOISE 1
master sha256 <64 hex digits> frames <L> rate <fs>
grid mdct 512 cell 8
pos <m0> <m1> <c0> <c1>
pos ...
```

| 行 | 含义 |
|---|---|
| `LAENOISE 1` | 标识行和版本。不含这一行的文件不是标定文件。 |
| `master sha256 … frames … rate …` | 标定所属的母带：其 WAV `data` 块字节的 SHA-256（即按存储原样的 PCM 采样，不含其他任何内容）、以采样帧计的长度 `L`，以及以 Hz 计的采样率 `fs`。 |
| `grid mdct 512 cell 8` | 网格。第 1 版只定义这一种网格；读取方拒绝任何其他值。 |
| `pos m0 m1 c0 c1` | 一个矩形：帧 `m0` ≤ m < `m1`，列 `c0` ≤ c < `c1`。文件包含零行或多行这样的行。 |

## 3. 网格

网格即 LAE Lossy (LAEY) 编码器频率层的网格，采用母带本身的采样率。

- **平面。** M = r + ((l − r) >> 1)，S = l − r，其中 l 和 r 为以 24 位整数表示的左、右声道采样（母带为立体声；其他字长的采样缩放至 24 位）。一个矩形同时覆盖 M 和 S。
- **帧。** 变换为 N = 512、采用正弦窗的 MDCT。第 m 帧覆盖采样 [mN − N, mN + N)。该帧自身的跳为 [mN − N/2, mN + N/2)，起始时间为 (mN − N/2) / fs。共有 K = ⌊(L + N − 1) / N⌋ + 1 帧，m = 0 … K − 1。
- **列。** 一列由 8 个 MDCT 系数组成：第 c 列包含系数 8c … 8c + 7，即频率从 c · 8 · fs / (2N) Hz 至 (c + 1) · 8 · fs / (2N) Hz。共有 64 列，c = 0 … 63。
- **格子。** 一个格子为一帧 × 一列。352.8 kHz 时一个格子为 2 756.25 Hz × 1.45 ms；44.1 kHz 时为 344.5 Hz × 11.6 ms。

## 4. 有效文件的条件

读取方首先去除注释、CR 和空行，然后仅当以下各条全部成立时才接受该文件：

1. 第一行恰好为 `LAENOISE 1`：只有 `LAENOISE` 和 `1` 两个词，别无其他内容。第一行为其他任何内容（例如 `LAENOISE 12`）的文件不是第 1 版的标定文件。
2. 文件恰有一个 `master` 行和恰有一个 `grid` 行，且二者均位于第一个 `pos` 行之前。出现第二个 `LAENOISE`、`master` 或 `grid` 行即为错误。
3. 第一个词为 `master`、`grid` 或 `pos` 的行，其各词与第 2 节完全一致。SHA-256 为 64 位小写十六进制数字。`L`、`fs`、`m0`、`m1`、`c0` 和 `c1` 只以十进制数字书写，不带正负号、小数点或指数。
4. 网格为 `mdct 512 cell 8`。
5. `frames` 等于母带的长度，`rate` 等于母带的采样率。
6. SHA-256 等于母带 `data` 块的 SHA-256。
7. 每个 `pos` 行均满足 0 ≤ m0 < m1 ≤ K 且 0 ≤ c0 < c1 ≤ 64。

第一个词为其他任何内容的行予以忽略；以后的版本可能使用这样的行。任何一条不成立时，读取方不使用该文件的任何部分。矩形可以重叠；标定范围为各矩形的并集。

## 5. 时间和频率换算为格子

LAE Noise Marker 将范围**向内**取整，使矩形不会超出用户所选的范围：

- 时间 [t0, t1) s → 跳完全落在该范围内的帧：m0 = ⌈(t0 · fs + N/2) / N⌉（不小于 0），m1 = ⌊(t1 · fs − N/2) / N⌋ + 1（不大于 K）。
- 频率 [f0, f1) Hz → 8 个系数全部落在该范围内的列：c0 = ⌈f0 / w⌉（不小于 0），c1 = ⌊f1 / w⌋（不大于 64），其中 w = 8 · fs / (2N)。
- 不包含任何完整格子的范围（m0 ≥ m1 或 c0 ≥ c1）不产生矩形：LAE Noise Marker 跳过该范围。

## 6. 示例

```
LAENOISE 1
master sha256 de8b7ca98ccaa8331093c708a7777eacde569b41808487671b33dbec59b136e7 frames 5292000 rate 352800
grid mdct 512 cell 8   # frame m = samples [mN-N, mN+N), its hop [mN-N/2, mN+N/2); column c = bins 8c..8c+7
pos 1999 9027 10 11   # 1: 2.900-13.100 s (10.20 s), 27562.5-30318.8 Hz
```

该文件在一个 15 s、352.8 kHz 的母带中标出一个矩形：2.900–13.100 s，27 562.5–30 318.8 Hz。

## 7. 本格式不做的事

- 本格式不包含音频，也不改变音频。去除其所标定的部分是读取该文件的程序的任务。在 LAE 中，该程序为编码器，它将其频率层中标定的格子编码为静音。
- 本格式不记录标定某一矩形的原因。
