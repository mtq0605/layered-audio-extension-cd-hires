## 1 范围与状态

### 1.1 目的

本文档描述 **LAE 无损**（简称 **LAES**）。LAES 是格式系列 **LAE**（Layered Audio Extension，分层音频扩展）的无损等级。

本文说明：

- 分层结构；
- 位位置；
- 采样率；
- 候选编码方法及其测量结果；
- 正在考虑的变体。

### 1.2 在格式系列中的位置

LAE 有两个等级。二者共享一种分层模型和一套容器原则。

| 等级 | 简称 | 特性 |
|---|---|---|
| LAE Lossy | LAEY | 扩展层采用量化编码。误差受解码器已知的量化步长限制。 |
| LAE Lossless | LAES | 每一层均精确编码。拥有全部层的解码器可逐位重现母带。 |

LAE 无损保留 LAE 有损的以下要素，不作改动：

- CD 层；
- 基础采样率下的位深层以及更高采样率下的倍频程层这一分层方式；
- 容器原则；
- 编码器的分析工具。

扩展层的编码方式有所变化：由量化改为精确编码。

此处不再重复 LAE 有损共用的部分，而是引用 LAE 有损规范 [SPEC.md](../lossy/SPEC.md)。尤其包括：

- 半带滤波器系数表及其算术（[SPEC.md](../lossy/SPEC.md) 第 10 节）；
- 抖动生成器及其种子（[SPEC.md](../lossy/SPEC.md) 第 11.2 节）；
- 整数 M/S 提升变换（[SPEC.md](../lossy/SPEC.md) 第 11.4 节）。

### 1.3 范围

**范围内：**

- 最多含 24 个有效位的立体声整数 PCM 母带；
- 母带采样率 $R = R_0 \cdot 2^n$，其中 $R_0 \in \lbrace 44.1, 48 \rbrace$ kHz，且 $n \in \lbrace 1, 2, 3 \rbrace$。即 88.2、176.4 和 352.8 kHz，或 96、192 和 384 kHz。

**不在范围内：**

- 有效位数超过 24 位的母带；
- 两个采样率系列之间的有理数比例采样率转换。

与 LAE 有损相同，48 kHz 系列母带使用 48 kHz 基础层。

### 1.4 符号说明

符号说明遵循 [SPEC.md](../lossy/SPEC.md) 和 LAE 有损工作论文（[README.md](../../README.md)）。

| 符号 | 含义 |
|---|---|
| $R_0$ | 基础采样率，44.1 kHz 或 48 kHz。$B = R_0/2$ 为基础奈奎斯特频率。 |
| $R = R_0 2^n$ | 母带采样率。 |
| $x$ | 采样率为 $R$ 的母带信号，以 24 位整数表示。 |
| $\mathcal{D}$、$\mathcal{U}$ | 以整数半带滤波器执行抽取，以及执行 $2^n$ 倍插值（[SPEC.md](../lossy/SPEC.md) 第 10 节）。 |
| $b = \mathcal{D}(x)$ | 采样率为 $R_0$ 的未限幅 24 位基础字。 |
| $c$ | 16 位 CD 样本（CD16，Level 0）。 |
| $d$ | 再生成的 TPDF 抖动；仅在带标志的块中非零。 |
| $v$ | 以 24 位单位表示的 CD 路径，定义见 [SPEC.md](../lossy/SPEC.md)。每个解码器仅凭 $c$ 和抖动标志即可计算该值。 |
| $w$ | 母带未使用的低位数，即所有样本共有的尾随零位数。 |
| $\lfloor\cdot\rfloor$ | 向下取整。对整数而言，通过算术右移实现。 |

位位置均指 24 位字。第 23 位为最高有效位，第 0 位为最低有效位。CD LSB 是第 8 位，其权重为 256。

## 2 目标

### 2.1 逐位精确的分层

LAES 的每一层都精确。各层为：

- CD 层（CD16）；
- 位深层，在基础采样率下将位深从 16 位扩展至 24 位；
- 倍频程层，将采样率扩展至基础采样率的 ×2、×4 和 ×8。

拥有所有层的解码器可逐样本重现母带。

任何层都不会被部分解码：该层要么完整存在，要么不存在。因此，无损等级不需要在层内使用可截断位平面。

### 2.2 旧式播放器兼容性

基础层是 44.1 kHz 或 48 kHz 系列中的 16 位 PCM CD 层（Level 0），所有播放器均可播放。CD 层是未修改的 PCM。

所有扩展层都存放在 PCM 之外。旧式播放器只播放 CD 层。

### 2.3 一个文件替代多个版本

若发行方要提供多个音质等级，通常必须分别存储每个版本，例如：

- CD 16 位；
- 基础采样率下的 24 位；
- 88.2 或 96 kHz 下的 24 位；
- 完整母带。

一个分层无损文件即可逐位精确地保存所有这些版本。这是该等级的主要价值。

### 2.4 对文件大小的现实预期

**LAES 不可能比 FLAC 小很多。**分层带来的母带压缩效果不会显著优于 FLAC：

- 在已测量的母带上，可实现的无损码率频谱下界仅比压缩等级 8 的 FLAC 低约 4–9%（第 10.2 节）；
- FLAC 已会剥除未使用的低位。

**预期文件大小。**以下数据为作者估算（第 10.2 节）。

| 存储方式 | 大小占母带 FLAC 文件的百分比 |
|---|---|
| 一个包含所有音质等级的分层文件 | 约 96–100% |
| 将相同音质等级分别存为多个版本 | 约 175% |

目前测得的原型尚未达到此估算（第 10.6 节）。

**存储介质。**完整的无损高解析度文件无法放入 CD：其大小约为 CD 音频原始数据量的 3.7 倍。目标介质为蓝光数据光盘和文件。

### 2.5 标记

有损文件始终标记为有损，绝不称为无损。只有所有层都精确的文件才能称为 LAE 无损。

## 3 分层模型

### 3.1 两个轴

扩展构成一个二维网格。沿采样率轴，每一步的采样率翻倍。沿位深轴，字长从 16 位增加到 18、20 和 24 位。

**位深轴（基础采样率）。**该轴始于 16 位 CD 层，即 16 位级别。CD LSB 以下固定位置的位平面组可逐步细化该层：

- P1 = 位平面 1–2（18 位级别）；
- P2 = 位平面 3–4（20 位级别）；
- P3 = 位平面 5–8（24 位级别）。

**采样率轴。**基础频带 $0 \ldots B$ 以上包含以下倍频程层：

- O1 = $B \ldots 2B$（采样率 ×2）；
- O2 = $2B \ldots 4B$（采样率 ×4）；
- O3 = $4B \ldots 8B$（采样率 ×8）。

倍频程按采样率比定义，因此两个采样率系列使用相同算法。

### 3.2 网格

```
                              base band     octave O1     octave O2     octave O3
                              0 .. B        B .. 2B       2B .. 4B      4B .. 8B
                              (rate R0)     (rate 2*R0)   (rate 4*R0)   (rate 8*R0)

  P3 (planes 5-8, -> 24 bit)  [0,P3]
  P2 (planes 3-4, -> 20 bit)  [0,P2]
  P1 (planes 1-2, -> 18 bit)  [0,P1]
  CD (16 bit, Level 0)        [0,CD]
  octave layers (full depth)                [O1]          [O2]          [O3]
```

基础频带列 $[0,\cdot]$ 由 CD 层和位深层构成，定义见第 4、5 节。

在本设计概要中，每个倍频程列是一个完整位深的单元。倍频程列定义见第 6 节。是否将这些列细分为位深行，属于倍频程层分帧的待定事项（第 11 节 O3 项）。

### 3.3 嵌套关系

各层沿两个轴分别嵌套。

- **位深。**某个位平面组依赖所有精度较粗的位平面组和 CD 层。P1 细化 CD 级别，P2 细化 P1 级别，P3 细化 P2 级别。
- **采样率。**倍频程层 $O_k$ 依赖 $O_1, \ldots, O_{k-1}$ 和 CD 层。

### 3.4 子集

用户或发行方可以保留网格中任意满足嵌套关系的子集。例如：

- CD + 基础采样率下的 24 位（CD、P1、P2、P3）；
- CD + 88.2 kHz（44.1 kHz 系列）或 96 kHz（48 kHz 系列）（CD、O1）；
- 完整网格。

从文件中移除层只会删除数据，不会重新编码。

“CD + 88.2/96 kHz”示例假定两个轴可以独立保留。也就是说，倍频程层必须能够在没有位深平面组的情况下解码。第 6.2 节说明了此属性；倍频程层分帧必须保留该属性（O3 项）。

### 3.5 精确性保证

以下保证成立：

1. **完整网格。**所有层均存在时，每个样本的输出都等于 $x$。
2. **基础采样率前缀级别。**存在 CD 层以及截至 $P_k$ 的位平面组时，输出等于相应级别的基础字 $b$、$b_{18}$、$b_{20}$ 或 $b$（第 5.2 节）。
3. **其他子集。**所有存在的层均精确解码。中间采样率级别（例如 88.2 kHz / 24 位）的参考信号尚待确定（O2 项）。自然的候选方案是按 [SPEC.md](../lossy/SPEC.md) 中的整数半带滤波链降采样后的母带。

编码器没有会影响解码结果的精度、噪声或模式选择。编码器的选择只影响：

- 文件大小；
- 输出哪些层。

## 4 CD 层

### 4.1 生成的 CD（与 LAE Lossy 共用）

默认情况下，CD 层完全按照 LAE 有损的方式通过以下四个步骤确定性生成：

1. 通过 $n$ 级级联整数半带抽取，将信号降至未限幅的基础字 $b$。滤波器使用 Q31 系数表、64 位累加、镜像边界，并对每个输出样本舍入一次。
2. 添加带种子的 TPDF 抖动，但仅限录音自身噪声低于 0.5 LSB16 的块。数字静音绝不添加抖动。
3. 舍入到 16 位。
4. 限幅到 16 位范围。

**规范性引用。**滤波器系数表、算术、抖动生成器、种子和逐块抖动标志均遵循 [SPEC.md](../lossy/SPEC.md)（第 10 节和第 11.2 节）。

**抖动再生成。**解码器根据固定种子和标志重新生成抖动。不传送抖动值。因此每个解码器都能精确知道 CD 路径 $v$。

### 4.2 独立 CD

也可以提供现有 CD 母带作为替代。其内容逐位成为 CD 层。与 LAE 有损相同，须满足以下条件：

- **格式。**CD 的采样率必须属于母带的基础采样率系列。
- **对齐。**CD 必须与母带逐样本对齐，且长度相同。
- **抖动。**不添加抖动，因此所有抖动标志均为 0。

随后，无损扩展会精确编码母带与 CD 路径之差。选择何种 CD 不影响无损性，但会影响位深层大小：所提供的 CD 与 $b$ 相差越大，位深层越大。差异可能来自分别进行的限幅、均衡和电平调整。

倍频程层仅承载各自的倍频程（第 6 节），因此不受 CD 选择影响。

### 4.3 未限幅的基础字

基础字 $b$ 未限幅，而 CD 路径经过限幅。因此，位深层会精确承载满量程以上、经过带限的过冲。

由于 $b$ 可能超出 24 位范围，将基础采样率的 24 位级别写为 24 位 PCM 时必须限幅。LAE 有损会为此应用最终硬限幅。LAES 是否也应在该级别采用相同处理，尚待决定（D3 项）。

完整母带的内部重建始终使用未限幅的 $b$。

## 5 位深层

### 5.1 精确位位置的位平面组

位深层在基础采样率下细化 CD 层。它由 24 位基础字中固定位置的三个嵌套位平面组组成。

| 位平面组 | CD LSB 以下的位平面 | 24 位字中的位位置 | 生成的级别 |
|---|---|---|---|
| CD（Level 0） | — | （舍入、加抖动后的 16 位值；见第 5.3 节） | 16 位 |
| P1 | 1–2 | 第 7、6 位 | 18 位 |
| P2 | 3–4 | 第 5、4 位 | 20 位 |
| P3 | 5–8 | 第 3、2、1、0 位 | 24 位 |

### 5.2 各级别

在本设计概要中，中间级别通过清除边界以下的位平面定义：

$$
b_{18} = 2^{6}\left\lfloor b / 2^{6} \right\rfloor, \qquad b_{20} = 2^{4}\left\lfloor b / 2^{4} \right\rfloor, \qquad b_{24} = b .
$$

规范性规范对 18 位和 20 位级别采用截断还是舍入约定，尚待决定（D1 项）。无论采用何种约定，位位置和精确性均不变。

### 5.3 精确重建

CD 级别并非 $b$ 的截断值，因为 CD 值经过舍入、加抖动和限幅。因此，第一个位平面组负责将 CD 路径关联到 18 位级别，后两个位平面组则按位位置逐步扩展字长。

**各组承载的内容。**

- **P1** 承载精确整数增量 $e_1 = b_{18}/64 - p(c, d)$。其中 $p$ 是根据 CD 样本以及带标志块中的再生成抖动计算得到的 $\lfloor b/64 \rfloor$ 的整数预测值。
  - 除削波、过冲（第 4.3 节）或使用独立 CD 的情况外，$e_1$ 很小。
  - $p$ 的确切形式（是否补偿抖动及其舍入方式）尚待决定（D2 项）。
  - 基线为 $p = 4c$，对应于第 10.6 节原型中使用的残差 $b - 256c$。
- **P2** 承载 $e_2 = (b_{20} - b_{18})/16 \in \lbrace 0, 1, 2, 3 \rbrace$。
- **P3** 承载 $e_3 = b - b_{20} \in \lbrace 0, \ldots, 15 \rbrace$。

**解码。**解码器按如下方式重建各级别：

$$
b_{18} = 64 (p + e_1), \qquad b_{20} = b_{18} + 16 e_2, \qquad b = b_{20} + e_3 .
$$

每一步都是精确整数运算。因此，各位平面组的内容完全由母带和 CD 路径决定；只有其熵编码方式属于设计选择。

在录音素材中，P2 和 P3 接近随机。除以下因素外，其编码没有可利用的结构：

- 低位的一般统计特征；
- 存在时的未使用低位。

### 5.4 与 LAE Lossy 位深层的区别

| 方面 | LAE Lossy | LAE Lossless |
|---|---|---|
| 目标 | $T = \mathrm{LP}_{f_c}(b - v)$，减去泄漏补偿项 | 精确表示 $b$，不使用低通滤波 |
| 精度 | 精度规则（B18/C20/D24，keep20 为 B20/C22/D24） | 固定的 P1/P2/P3 位平面组，每组均精确 |
| 部分精度 | 安静块按照块峰值进行编码 | 无；位平面组要么完整存在，要么不存在 |
| 泄漏补偿 | 必需，因为量化噪声会泄漏到 CD 频带 | 不适用；不存在量化噪声 |

### 5.5 测得的开销

在已测量集合的一条音轨上（第 10 节），完整的 16 位至 24 位位深层开销约为 0.68 Mb/s。同一音轨的 CD16 层开销约为 0.52 Mb/s。

## 6 倍频程层

### 6.1 频带和比例

| 层 | 频带 | 添加该层后的采样率 | 44.1 kHz 系列 | 48 kHz 系列 | 每秒、每声道编码值数 |
|---|---|---|---|---|---|
| 基础层（CD + 位深） | $0 \ldots B$ | $R_0$ | 0–22.05 kHz，44.1 kHz | 0–24 kHz，48 kHz | $R_0$ |
| O1 | $B \ldots 2B$ | $2R_0$ | 22.05–44.1 kHz，88.2 kHz | 24–48 kHz，96 kHz | $R_0$ |
| O2 | $2B \ldots 4B$ | $4R_0$ | 44.1–88.2 kHz，176.4 kHz | 48–96 kHz，192 kHz | $2R_0$ |
| O3 | $4B \ldots 8B$ | $8R_0$ | 88.2–176.4 kHz，352.8 kHz | 96–192 kHz，384 kHz | $4R_0$ |

采样率为 $R_0 2^n$ 的母带具有倍频程层 $O_1, \ldots, O_n$。频带边界由采样率比固定，两个系列采用相同算法。

### 6.2 临界采样

倍频程层采用临界采样。每个倍频程层仅承载自身的倍频程：第 $k$ 个倍频程每个声道每秒承载 $R_0 2^{k-1}$ 个值。

在每个采样率级别，基础层和倍频程层承载的每秒值数之和恰好等于相应采样率。对于 352.8 kHz 母带：

$$
44.1 + 44.1 + 88.2 + 176.4 = 352.8 \text{ kHz.}
$$

倍频程层**不是**“全采样率信号减去插值后的基础层”这种残差。此类残差会在 $R_0$ 个基础值之外，再次承载完整采样率 $R$ 的数据。对于 ×8 母带，这会比母带本身多承载八分之一的值，而且还会在基础频带中承载插值残差。

第 6.6 节介绍这种替代方案及其测量结果。逐位精确原型使用了该方案。

**独立于位深细化。**倍频程层从母带本身计算，仅承载其自身的倍频程。因此，它不依赖基础频带的位深细化。正是这种独立性使“CD + 88.2/96 kHz”之类的子集成为可能（第 3.4 节）。

### 6.3 倍频程层的内容

测得的 352.8 kHz 母带超声波倍频程具有以下特征：

- **从不为空。**88.2 kHz 以上的频带从不为空，其中包含录音中的实际噪声，占完整无损文件比特数的约 35%。
- **测得的开销。**一条音轨的超声波层总开销约为 4.0 Mb/s。

由于采用精确编码，这些噪声与其他内容一样编码。无损等级没有噪声选项。

### 6.4 未使用的低位

母带的有效位数通常少于其字长。七个已测母带均有 22 个有效位，因此 $w = 2$。FLAC 会剥除此类位。无损分层也必须这样做，否则会为不承载信息的零值付出编码开销。

原型（第 10.6 节）采用以下机制：

1. **检测。**将 $w$ 检测为整条音轨所有样本共有的尾随零位数。
2. **网格舍入。**将从较低层预测得到的值舍入至母带的 $2^w$ 倍数网格，恰好位于中点时向上舍入：

   $$
   u' = 2^w \left\lfloor \left(u + 2^{w-1}\right) / 2^w \right\rfloor .
   $$

3. **移位。**残差 $x - u'$ 是 $2^w$ 的倍数；编码前将其右移 $w$ 位。
4. **重建。**解码器加回 $u' + 2^w \cdot (\text{decoded residual})$。

$w$ 的信令方式以及按音轨还是按块设置，属于倍频程层分帧待定事项（O3 项）。

### 6.5 立体声

[SPEC.md](../lossy/SPEC.md) 第 11.4 节中的整数 M/S 提升变换可用于每一层：

$$
S = L - R, \qquad M = R + \lfloor S/2 \rfloor ;
$$

$$
R = M - \lfloor S/2 \rfloor, \qquad L = R + S .
$$

此映射完全可逆。原型将其应用于全采样率差分层。立体声去相关方式是按层固定（M/S 或 L/R），还是按块自适应选择，尚待决定（C4 项）。

### 6.6 已测替代方案：差分模型

逐位精确原型使用全采样率差分层替代临界采样倍频程层。步骤如下：

1. **基础字。**根据 CD16 和精确位深残差 $r = b - 256c$ 精确重建基础字。
2. **升采样。**使用整数半带插值器将基础字升采样至母带采样率。插值器使用 [SPEC.md](../lossy/SPEC.md) 中的 Q31 系数表，并对信号边缘进行镜像处理。
   - 每一级中，偶数位置的输出样本直接复制输入：$y[2i] = x[i]$。
   - 奇数位置的输出样本为：

     $$
     y[2i+1] = \left\lfloor \left( \sum_t h_t \left(x[i-t] + x[i+1+t]\right) + 2^{29} \right) / 2^{30} \right\rfloor ,
     $$

     其中 $h_t$ 是存储的奇数抽头系数。除数 $2^{30}$ 实现了 2 倍插值增益。
   - 信号范围以外的索引按镜像方式处理：$i < 0$ 时取 $-i$；$i \ge L$ 时取 $2(L-1) - i$。
3. **差分。**在母带网格上计算与母带的差分，并移除未使用的位（第 6.4 节）。
4. **立体声。**将差分映射为整数 M/S。
5. **编码。**对差分进行精确编码。

解码输出的每个样本均与母带相同。大小数据见第 10.6 节。

原型验证了整条整数运算链的精确性。这条确定性运算链包括插值、网格舍入、移位和整数 M/S；编码器和解码器执行的操作完全相同。设计中改用第 6.2 节的临界采样倍频程层替代此模型。

### 6.7 实现与分帧（待定）

倍频程层的以下问题尚待解决：

- **O1** —— 如何用整数实现倍频程划分，使每个倍频程层采用临界采样且每种部分重建均精确；
- **O2** —— 中间采样率级别的参考信号（第 3.5 节）；
- **O3** —— 倍频程层分帧：时间分段、$w$ 的信令（第 6.4 节）、倍频程列按位深细分（第 3.2 节），以及保持第 6.2 节所述的独立性。

O1 的候选实现见第 7 节：

- 可逆整数变换的谱线分段，类似 LAE Lossy 中“倍频程 = 谱线片段”的组织方式；
- 时域编码；
- 整数小波倍频程分解，该方案因测得的编码增益较差而被否决。

## 7 编码选项

### 7.1 所有选项的共同要求

每个编码选项都必须满足以下五项要求：

1. **可逆。**对于该层值域中的所有输入（包括满量程极值信号），都能精确还原。
2. **整数算术。**仅使用整数算术。已研究的所有候选方案均为整数方案：32 位数值配合 64 位累加器。因此，LAE 无损解码无需浮点运算。这一点不同于 LAE 有损的 binary64 逆 MDCT。
3. **确定性。**具有确定性：编码器与解码器按相同顺序执行相同操作。
4. **无损熵编码。**与无损熵编码器组合使用。
5. **不依赖分类。**正确性不依赖任何分类（第 8 节）。

### 7.2 选项 (a)：整数 MDCT

**结构。**

| 参数 | 值 |
|---|---|
| 每块（步长）的系数数 | $N = 512$ |
| 窗 | 长度为 $2N$ 的正弦窗 |
| 构建模块 | 仅使用完全可逆的整数提升步骤 |

**正变换。**正变换分为两个阶段。

1. **时域混叠折叠。**在每个重叠中心 $C$，对每个 $j = 0, \ldots, N/2 - 1$，将样本对 $(y[C-1-j], y[C+j])$ 旋转 $\alpha_j + \pi/2$，其中：

   $$
   \alpha_j = \frac{\pi}{4} + \frac{\pi (j + 1/2)}{2N} .
   $$

   该旋转通过一次精确的四分之一周旋转，再加一次角度为 $\alpha_j$ 的提升旋转实现。相应的实数映射为：

   $$
   (l, r) \mapsto \left(-l \sin\alpha_j - r \cos\alpha_j, \quad l \cos\alpha_j - r \sin\alpha_j\right).
   $$

2. **每块执行 DCT-IV。**将一个块的 $N$ 个折叠样本排列为 $u[n] = y[C + N - 1 - n]$ 和 $u[N/2 + n] = y[C + N/2 - 1 - n]$。然后通过基于酉 FFT 分解构建的整数 DCT-IV 进行变换（图 7.1）。

**图 7.1 —— 整数 DCT-IV 程序（酉 FFT 分解）。**

1. **打包。**构造复数对 $z_n = (u[2n], u[N-1-2n])$，其中 $n = 0, \ldots, N/2 - 1$。
2. **前置旋转。**将每个 $z_n$ 旋转 $-\pi(4n+1)/(4N)$。
3. **置换。**执行位反转置换（交换复数对）。
4. **蝶形运算。**执行基 2 蝶形运算。对于每个长度为 `len` 的阶段：
   - 将第二个操作数旋转 $-2\pi k/\mathrm{len}$；
   - 然后对实部和虚部分别计算 $\left((a+b)/\sqrt{2}, (a-b)/\sqrt{2}\right)$，实现方式为对 $b$ 取反，再旋转 $\pi/4$。
5. **后置旋转。**将每个输出对旋转 $-\pi k/N$。
6. **取反。**将虚部取反。
7. **解包。**写入 $X[2k] = \mathrm{Re}$ 和 $X[N-1-2k] = \mathrm{Im}$。

**通过提升步骤实现旋转。**对于 $|\theta| \le \pi/2$ 的旋转，使用 Q30 系数 $c_1 = \tan(\theta/2)$ 和 $c_2 = \sin\theta$，分为三个提升步骤：

$$
x \leftarrow x - r(c_1 y), \qquad y \leftarrow y + r(c_2 x), \qquad x \leftarrow x - r(c_1 y),
$$

其中舍入函数为：

$$
r(v) = \left\lfloor (v + 2^{29}) / 2^{30} \right\rfloor .
$$

超出 $\pm\pi/2$ 的旋转先通过精确的四分之一周旋转 $(A, B) \mapsto (-B, A)$ 或 $(B, -A)$ 化简。

完整的 DCT-IV 程序对每个含 512 个系数的块执行 6193 个基本操作，包括提升三步组、四分之一周旋转、取反和交换。

**逆变换。**逆变换按相反顺序执行同一程序，并反转每个步骤。因此，对所有输入都能逐位精确还原。

**测量结果**（第 10.4 节）：

- **可逆性。**在六种满量程 24 位极端测试信号和真实音频上均逐位精确，样本不匹配数为 0。
- **精度。**与浮点正交 MDCT 的差异来自提升步骤的舍入噪声：

  | 母带采样率 | RMS 偏差 | 最大偏差 |
  |---|---|---|
  | 352.8 kHz | 1.32 LSB | 6.1 LSB |
  | 176.4 kHz | 1.31 LSB | 6.5 LSB |

- **率失真。**与浮点 MDCT 相同。
- **速度。**对 40 秒、352.8 kHz 立体声进行正变换耗时 0.7 秒，逆变换耗时 0.6 秒，约为实时速度的 60 倍。
- **无损开销估算。**估算采用对 16 个系数组进行自适应 Rice 编码，未进行上下文建模（第 10.5 节）。

  | 母带采样率 | 整数 MDCT（bit/sample） | FLAC 等级 8（bit/sample） |
  |---|---|---|
  | 352.8 kHz | 9.67 | 9.24（整数 MDCT 高 4.7%） |
  | 176.4 kHz | 10.24 | 9.91 |

- **逐位精确原型。**采用精确整数 MDCT 系数编码的全采样率差分层，大小达到第 10.6 节 FLAC 参考文件的 110.3%。

**评估。**整数 MDCT 精确且速度快，并在频谱着色内容上保留 MDCT 的编码增益。其舍入噪声约为每个系数 1.3 LSB，会进入编码系数。在已测母带上，这种舍入噪声与母带极低的超声波噪声底处于相近量级。对于无损编码，这会增加明显的比特开销。

### 7.3 选项 (b)：时域无损残差编码

**结构。**每一层都按照 FLAC 的方式编码：

- 线性预测器使用量化后的整数系数，根据先前样本预测每个样本；
- 整数残差（样本减预测值）通过熵编码，例如分区 Rice 编码；
- 解码器将残差加回完全相同的整数预测值。

预测循环除确定性的整数预测器计算外不涉及舍入。残差中不会引入变换舍入噪声。

**测量结果**（估算；第 10.6 节）。对逐位精确原型的全采样率差分层应用了 32 阶时域线性预测器。通过每个分区的拉普拉斯熵估算残差开销，未计入边信息。估算结果约为第 10.6 节 FLAC 参考文件大小的 103.7%；同一层采用选项 (a) 时为 110.3%。

**评估。**这是最简单的选项，也最接近 FLAC。可以采用与 FLAC 相同的子帧和残差编码结构实现。

### 7.4 选项 (c)：整数提升小波

**结构。**在倍频程分解中评估了 5/3 和 13/7 整数提升小波。两者都完全可逆。

**测量结果**（第 10.4 节）：

- **可逆性。**对六种满量程 24 位极端信号，以及 352.8 和 176.4 kHz 的真实音频，均能完美重建，样本不匹配数为 0。
- **率失真。**在有损等级的量化器下，对 22.05 kHz 以上的高频层进行比较，用以衡量编码增益（表 10.4a 和 10.4b）。在所有量化器设置下，两种小波的 MSE 均高于 512 线浮点 MDCT：
  - 5/3：MSE 约为 MDCT 的 10 至 12 倍，且码率更高；
  - 13/7：在 352.8 kHz 录音上，MSE 约为 1.6 至 1.9 倍，码率相近或更低；在 176.4 kHz 录音上，MSE 约为 2.4 至 3.4 倍，且码率更高。

**评估。**已否决。

### 7.5 汇总

| 选项 | 精确 | 整数 | 测得的无损开销 | 编码增益 | 状态 |
|---|---|---|---|---|---|
| (a) 整数 MDCT，N = 512 | 是 | 是 | 第 10.6 节 FLAC 参考大小的 110.3%（原型）；Rice 估算比 FLAC 等级 8 高 4.7% | 与浮点 MDCT 相同 | 候选方案 |
| (b) 时域 LPC 残差 | 是 | 是 | 第 10.6 节 FLAC 参考大小的约 103.7%（估算，未计入边信息） | — | 候选方案；最简单 |
| (c) 5/3、13/7 整数提升小波 | 是 | 是 | — | 所有测试设置下 MSE 均高于 MDCT（第 10.4 节） | 已否决 |

### 7.6 选择标准与状态

最终编码选项尚**待定**（C1 项）。选择标准如下：

1. **大小。**将大小与 FLAC 母带文件比较，计算时包括边信息，并明确指定一个 FLAC 参考（编码器、版本和压缩等级）。
2. **简单性。**实现简单且接近 FLAC。选项 (b) 最简单。
3. **倍频程层。**与临界采样倍频程层及其分帧兼容（O1 和 O3 项）。
4. **解码速度。**

更强的预测属于单独的研究事项（C3 项），目标是比 FLAC 小 3–6%。

无损等级可以在同一容器内采用不同于有损等级的编码路径。一种候选组合是对不同层采用不同选项，例如：

- 位深平面组采用时域编码；
- 倍频程层采用变换编码。

## 8 块类别及其约束

### 8.1 类别代码

每个层的频带块可以带有一个 2 位类别。频带块指一个频带在一个时间片段内的块。

| 类别 | 含义 | 编码数据 |
|---|---|---|
| A | 0 位：数字静音；块内每个值都精确为零 | 无 |
| B | 最低样本位深等级 | 数值，使用 B 的模型集编码 |
| C | 中间样本位深等级 | 数值，使用 C 的模型集编码 |
| D | 最高样本位深等级 | 数值，使用 D 的模型集编码 |

B、C、D 对应的具体位深范围尚待决定（K1 项）。

### 8.2 作用

类别可以用于引导：

- 将一层分割成多个块；
- 将数值分组进行熵编码，即选择模型或参数集。

编码器可以使用 LAE Lossy 的分析工具来建议类别。这些工具包括噪声底估计、持续音检测器和瞬态检测器。

### 8.3 约束

1. **分类绝不影响无损性。**类别只选择精确数值的编码方式，绝不决定重建哪些数值。每种类别都会解码为精确数值。
2. **每种类别编码器均为全定义。**B、C、D 类编码器都接受该层中可能出现的所有数值，并保证所有这类数值均能往返精确还原。超出其位深等级典型范围的值会消耗更多比特，但不会损失精度。具体机制（例如转义编码）尚待决定（K2 项）。
3. **仅当值精确为零时才允许使用 A 类。**只有当块内所有值都精确为零时，编码器才能将其指定为 A 类。
4. **通过试编码选择。**编码器通过试编码选择块的类别，采用开销最低的类别。因此，类别判断错误最多只会增加字节数。

### 8.4 与 LAE Lossy 的比较

在 LAE Lossy 中，A、B、C、D 类是**精度**等级。类别决定量化步长，因此决定解码结果。

在 LAE Lossless 中，类别仅是**编码**等级。任何符合条件的类别分配都不会改变解码结果。

## 9 容器

### 9.1 原则（与 LAE Lossy 共用）

两个等级共享以下容器原则：

- CD 层作为文件音频存储，不作任何更改；
- 所有扩展数据均位于 PCM 之外，存放在旧式播放器会忽略的结构中；
- 一个文件承载所有保留的层。移除层意味着删除相应数据。

### 9.2 FLAC

FLAC 数据流的音频帧以普通 16 位 FLAC 数据流承载 CD 层。扩展存放在 FLAC APPLICATION 元数据块中。相关 FLAC 规则如下：

- **块布局。**APPLICATION 块由 32 位应用程序 ID 和其后的数据组成。
- **块大小。**元数据块的 24 位长度字段将每个块限制为最多 $2^{24} - 1$ 字节。因此，大型扩展必须拆分到多个块中。
- **位置。**元数据块位于音频帧之前。因此，文件中的所有扩展数据都在 CD 音频之前。
- **音频 MD5。**STREAMINFO 中的音频 MD5 仅覆盖解码后的 CD 音频，不受扩展影响。

块布局和应用程序 ID 尚待决定（F1 项），包括如何将各层拆分并排序到各块，以及是否使用索引以便仅读取所需层。第 10.7 节给出了实测封装结果。

### 9.3 RIFF/WAV

`data` 块以 16 位 PCM 承载 CD 层。扩展位于独立的 RIFF 块中，播放器会忽略未知块。

LAE Lossy v5 使用块 ID `LAE `，魔数为 `LAE1`（[SPEC.md](../lossy/SPEC.md) 第 3–5 节）。LAES 是使用相同块并通过等级和容器版本区分，还是使用单独的块 ID，尚待决定（F2 项）。

### 9.4 旧式播放器行为

旧式播放器的行为如下：

- FLAC 解码器跳过未知的 APPLICATION 块；
- WAV 播放器忽略未知块；
- 两者都逐位播放 CD 层。

LAE Lossy v5 解码器会拒绝任何非 5 的容器版本（[SPEC.md](../lossy/SPEC.md) 第 4.3 节）。因此，不会将未来的 LAES 容器版本误读为有损格式。

### 9.5 完整性

通过**对整条音轨计算一个哈希**来保护完整性。哈希算法尚待决定（F3 项），其覆盖范围也尚待决定：可以是解码后的母带 PCM、每个保留的采样率和位深级别，也可以是扩展字节。

一个候选方案是对解码后的全解析度母带计算哈希，类似 FLAC 音频 MD5。采用该方案，解码器可端到端确认逐位精确性。

### 9.6 等级识别

每个文件都会声明其等级。

- 有损扩展始终标记为有损；
- 只有当文件所含的每一层都精确时，文件才会被标识为 LAE Lossless。

承载等级信息的字段尚待决定（F2 项）。

### 9.7 介质

完整无损网格约为 CD 音频原始大小的 3.7 倍，因此无法放入 CD。目标载体为蓝光数据光盘和文件。

是否为网格的小型子集提供 CD-Extra 封装尚待决定（F4 项）。此类子集的一个示例是 CD + 位深层：CD 层位于音频会话中，扩展位于数据会话中。

## 10 测量

除非标明为估算，本节所有数据均在开发期间测得。表 10.1 的录音和本节的测量结果均不属于 [data/](../../data/) 中发布的测量数据。

**FLAC 参考。**文件大小相对于母带的 FLAC 编码结果给出。使用了两个参考值：

- 压缩等级 8 的 FLAC（第 10.2 节的频谱下界和第 10.5 节的估算使用此值）；
- 第 10.6 节中的一个 FLAC 文件，大小为 21,996,137 字节，记录为压缩等级 12。参考 FLAC 编码器仅提供 0 至 8 级压缩；此文件所用编码器及其版本未在本文档中记录。

相对于这两个参考值的百分比不能直接比较。凡是未注明压缩等级的百分比（第 2.4 和 10.2 节），均未记录等级。

### 10.1 材料

### 10.2 采样率和位深级别的大小

下表给出七段 DXD 录音的文件大小，占母带 FLAC 文件大小的百分比。

| 版本 | 大小 |
|---|---|
| CD 44.1 kHz / 16 位（带抖动） | 约 10% |
| 44.1 kHz / 24 位 | 约 23–28% |
| 88.2 kHz / 24 位 | 约 40–46% |
| 96 kHz / 24 位（仅作比较） | 约 42–48% |
| 完整母带，352.8 kHz / 24 位 | 100% |

96 kHz 一行是单独存储版本的比较值，不属于 44.1 kHz 系列 LAES 文件中的级别，因为 LAE 不执行有理数比例转换。

分别存储这些版本约占母带 FLAC 文件的 175%。估算一个包含所有版本的分层文件约占 96–100%。

可实现的无损码率频谱下界仅比压缩等级 8 的 FLAC 低约 4–9%。FLAC 已剥除这些母带中未使用的两个低位。

### 10.3 分层开销

七段录音中一条音轨的分层开销如下：

| 层 | 开销 |
|---|---|
| CD16 | 约 0.52 Mb/s |
| 16 → 24 位位深层 | 约 0.68 Mb/s |
| 超声波倍频程层 | 约 4.0 Mb/s |

总计约 5.2 Mb/s，与完整无损文件约为 CD 音频原始码率 1.41 Mb/s 的 3.7 倍相符。

88.2 kHz 以上的频带承载约 35% 的比特，其中包含实际噪声，并非空数据。

### 10.5 整数 MDCT 的无损开销估算

**方法。**整数 MDCT 的每个系数都精确编码。每 16 个系数为一组，按 zig-zag 顺序映射。选择使该组编码长度最短的 Rice 参数 $k \in \lbrace 0, \ldots, 23 \rbrace$，并为每组的 $k$ 计入 5 位。不使用上下文建模。

| 母带采样率 | L/R（bit/sample） | M/S（bit/sample） | FLAC 等级 8 实测值（bit/sample） |
|---|---|---|---|
| 352.8 kHz DXD | 9.673 | 9.679 | 9.237 |
| 176.4 kHz | 10.235 | 10.254 | 9.905 |

在 DXD 录音上，该估算值比等级 8 的 FLAC 高 4.7%。在此估算中，对完整信号使用 M/S 没有带来收益。

### 10.6 逐位精确原型（差分模型）

在七段 DXD 录音中的一段（40 秒立体声）上运行了该原型。它包含三个部分：

- **CD16。**CD 层，采用 FLAC 编码。
- **位深残差。**残差 $r = b - 256c$，使用整数 MDCT 编码，且每个系数均精确。
- **差分层。**母带减去 CD 路径。CD 路径使用整数 Q31 半带系数表升采样，边缘采用镜像处理（第 6.6 节）。

解码输出的每个样本均与母带相同。

**精确系数的编码。**精确系数使用为有损等级开发的自适应范围编码器编码。量化步长设为 1，从而确保每个系数均精确，并按每组 32 条谱线进行编码。

**变体。**

1. L/R，保留未使用的低位。
2. 在变体 1 的基础上，移除未使用的低位，并对差分应用整数 M/S。移除未使用位意味着在母带的 4 的倍数网格上重建，并将差分右移 2 位（第 6.4 节）。
3. 在变体 2 的基础上，采用 32 阶时域线性预测器和每分区拉普拉斯熵对差分层进行开销估算。该变体是估算值，未计入边信息。

参考值是母带的一个 FLAC 编码文件，大小为 21,996,137 字节，记录为压缩等级 12（参见第 10 节开头关于 FLAC 参考值的说明）。

**表 10.6 —— 原型变体大小，单位为字节。**

| 变体 | CD16（FLAC） | 位深残差 | 差分层 | 总计 | 占 FLAC 参考值的比例 |
|---|---|---|---|---|---|
| 1 | 1,887,683 | 3,695,740 | 24,641,414 | 30,224,837 | 137.4% |
| 2 | 1,887,683 | 3,695,740 | 18,674,558 | 24,257,981 | 110.3% |
| 3（估算） | 1,887,683 | 3,695,740 | 约 17,236,531 | 约 22,820,000 | 约 103.7% |

变体 2 结合了两项改动：移除未使用位和使用 M/S。两项改动各自的贡献没有分别测量。

**解读。**变体 2 与变体 3 之间的差距来自整数 MDCT 的舍入噪声，每个系数约 1.3 LSB。这种噪声与这些母带极低的超声波噪声底处于相近量级。时域预测没有这种舍入误差。

该原型使用全采样率差分层，而非设计中的临界采样倍频程层（第 6.2 节）。

### 10.7 容器封装

开发期间的一项测试将扩展负载分别封装到 FLAC 文件和 WAV 块中。FLAC 文件增加了 5,000,008 字节。结果如下：

- 在两种容器中，封装前后 CD 层的音频 MD5 均相同；
- 负载往返后保持完整。

## 11 待定事项

**编码**

- **C1** —— 最终编码选项： (a) 整数 MDCT、(b) 时域残差，或按层组合使用（第 7.6 节）。
- **C2** —— 所选方案的熵编码器与上下文设计；测量时计入边信息。
- **C3** —— 更强的预测，目标是比 FLAC 小 3–6%。这是单独的研究事项。
- **C4** —— 立体声去相关：按层固定，还是按块自适应。

**位深层**

- **D1** —— 18 位和 20 位级别采用截断还是舍入（第 5.2 节）。
- **D2** —— 位平面组 P1 中 CD 路径预测 $p$ 的准确形式，包括是否使用抖动补偿（第 5.3 节）。
- **D3** —— 当 $b$ 超出 24 位范围时，对基础采样率 24 位级别的输出进行限幅（第 4.3 节）。

**倍频程层**

- **O1** —— 临界采样倍频程层的整数实现，要求每种部分重建都保持精确（第 6.7 节）。
- **O2** —— 中间采样率级别（例如 88.2 kHz / 24 位）的参考信号（第 3.5 和 6.7 节）。
- **O3** —— 倍频程层分帧：时间分段、未使用低位的信令、按位深细分倍频程列，以及保持倍频程层独立于位深平面组（第 3.2、3.4、6.4 和 6.7 节）。

**类别**

- **K1** —— B、C、D 类与位深范围的映射，以及频带块的大小。
- **K2** —— 类别编码器的全定义机制，例如转义编码。

**容器**

- **F1** —— FLAC APPLICATION 块布局、应用程序 ID、分块方式及索引。
- **F2** —— RIFF 块 ID 和等级/版本字段：共用块还是单独的块。
- **F3** —— 整条音轨的哈希算法及其覆盖范围。
- **F4** —— 对网格小型子集采用 CD-Extra 封装。
- **F5** —— `.lae` 文件布局，与 LAE Lossy 共用。

**范围**

- **S1** —— 立体声以外的声道配置。
- **S2** —— 是否接纳仅具有位深轴、采样率为基础采样率的母带。

**规范**

- **N1** —— 规范性规范、一致性测试向量和参考解码器。

## 12 与 LAE Lossy 的关系

| 方面 | LAE Lossy（LAEY） | LAE Lossless（LAES） |
|---|---|---|
| CD 层 | 通过整数半带抽取和自适应带种子 TPDF 抖动生成，或使用独立 CD | 相同（[SPEC.md](../lossy/SPEC.md) 第 10 和 11.2 节） |
| 分层 | 基础采样率下的位深层；母带采样率下的频率层 | 基础采样率下的位深层；按采样率比划分倍频程层 |
| 位深层 | $\mathrm{LP}_{f_c}(b - v)$ 的编码近似值，并进行泄漏补偿；采用精度规则 1 和 3 | 在固定位位置的 P1/P2/P3 位平面组中精确表示 $b$ |
| 高采样率层 | 母带采样率下的一个 MDCT；按倍频程划分谱线片段；起点为检测到的 CD 截止频率以下 1 kHz | 临界采样倍频程层 $B \cdot 2^{k-1} \ldots B \cdot 2^k$，均精确；实现和分帧尚待确定（O1–O3 项） |
| 编码 | 带死区量化器、精度等级、重建偏移量、可选零级、范围编码器 | 精确编码；选项 (a) 或 (b) 尚待选择 |
| A/B/C/D 类 | 决定解码结果的精度等级 | 仅作为编码等级；解码结果不受类别影响 |
| 方案和模式 | 2 种方案 × 6 种模式 | 不存在影响解码结果的模式 |
| 层内部分精度 | 精度随块峰值变化 | 无；层要么完整存在，要么不存在 |
| 解码器算术 | 整数滤波器；按固定顺序执行 IEEE-754 binary64 逆 MDCT，并进行启动自检 | 所有候选方案都只使用整数运算 |
| 立体声 | 频率层使用 M/S；位深层使用 L/R | 可使用整数 M/S；具体选择尚待决定 |
| 分析工具 | 噪声底、持续音和瞬态检测器、闭环 | 使用相同工具；只能用于引导类别和分段 |
| 容器 | RIFF 块 `LAE `（v5）；计划支持 FLAC | FLAC APPLICATION 块或 RIFF 块；布局尚待决定 |
| 完整性 | 对扩展块计算 CRC-32 | 对整条音轨计算一个哈希 |
| 标记 | 始终标记为有损，绝不称为无损 | 无损；每一层均精确 |

LAE Lossy 中仅用于管理量化误差的工具在无损等级中没有作用，包括：

- 精度规则和 16 位下限保障；
- 死区和重建偏移量；
- 可选零级；
- 泄漏补偿；
- 由模式驱动的降级。

由此形成两种解码路径：

- **LAE Lossy。**确定性浮点逆变换，最后输出时舍入一次。
- **LAE Lossless。**整数可逆逆变换，舍入误差完全抵消。

两个等级可以放在同一容器中。
