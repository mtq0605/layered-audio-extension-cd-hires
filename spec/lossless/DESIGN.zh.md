## 1 范围与状态

### 1.1 目的

本文档是 **LAE Lossless**（简称 **LAES**）的公开设计说明。LAES 是格式系列 **LAE**（Layered Audio Extension）的无损等级。

本文档的撰写目标是使熟练的实现者能够理解设计的每一个要素。为此，本文档说明：

- 分层结构；
- 位位置；
- 采样率；
- 候选编码方法及其测量结果；
- 设计空间内的各种变体。

### 1.2 在格式系列中的位置

LAE 有两个等级。二者共享一种分层模型和一套容器原则。

| 等级 | 简称 | 特性 |
|---|---|---|
| LAE Lossy | LAEY | 扩展层采用量化编码。误差有界，且为解码器所知。 |
| LAE Lossless | LAES | 每一层均精确编码。持有全部层的解码器可逐位重现母带。 |

从本质上说，LAE Lossless 是为实现精确性而调整和优化的 LAE Lossy。它保留 LAE Lossy 的以下要素：

- CD 层；
- 划分为基础采样率下的位深层和更高采样率下的各层（在 LAE Lossless 中，以临界采样的倍频程层取代单一频率层；第 12 节）；
- 容器原则；
- 编码器的分析工具。

主要变化在于扩展层的编码方式：由量化编码改为精确编码；其他差异列于第 12 节。

与 LAE Lossy 共用的部分此处不再重复，而是引用 LAE Lossy 规范 SPEC.md。这尤其适用于：

- 半带滤波器系数表及其算术（SPEC.md 第 10 节）；
- 抖动生成器及其种子（SPEC.md 第 11.2 节）；
- 整数 M/S 提升变换（SPEC.md 第 11.4 节）。

### 1.3 范围

**范围内：**

- 至多含 24 个有效位的立体声整数 PCM 母带；
- 母带采样率 $R = R_0 \cdot 2^n$，其中 $R_0 \in \{44.1, 48\}$ kHz，$n \in \{1, 2, 3\}$，即 88.2、176.4 和 352.8 kHz，或 96、192 和 384 kHz。

**范围外：**

- 有效位数超过 24 位的母带；
- 两个采样率系列之间的有理数比例采样率转换。

与 LAE Lossy 相同，48 kHz 系列母带具有 48 kHz 基础层。

### 1.4 符号

符号遵循 SPEC.md 和 LAE Lossy 工作论文。

| 符号 | 含义 |
|---|---|
| $R_0$ | 基础采样率，44.1 kHz 或 48 kHz。$B = R_0/2$ 为基础奈奎斯特频率。 |
| $R = R_0 2^n$ | 母带采样率。 |
| $x$ | 采样率为 $R$ 的母带信号，以 24 位整数表示。 |
| $\mathcal{D}$, $\mathcal{U}$ | 以 $2^n$ 为因子的整数半带抽取与插值（SPEC.md 第 10 节）。 |
| $b = \mathcal{D}(x)$ | 采样率为 $R_0$ 的未限幅基础字，以 24 位单位表示；其值可能超出 24 位范围（第 4.3 节）。 |
| $c$ | 16 位 CD 样本（CD16，Level 0）。 |
| $d$ | 再生成的 TPDF 抖动；仅在带标志的块中非零。 |
| $v$ | 以 24 位单位表示的 CD 路径，定义见 SPEC.md。每个解码器仅凭 $c$ 和抖动标志即可计算该值。 |
| $w$ | 母带未使用的低位数，即所有样本共有的尾随零位数。 |
| $\lfloor\cdot\rfloor$ | 向下取整。对整数而言，以算术右移实现。 |

位位置均指 24 位字。第 23 位为最高有效位，第 0 位为最低有效位。CD LSB 为第 8 位，其权重为 256。

## 2 目标

### 2.1 逐位精确的分层

LAES 的每一层均精确。各层为：

- CD 层（CD16）；
- 位深层，在基础采样率下将位深由 16 位提升至 24 位；
- 倍频程层，将采样率提升至基础采样率的 ×2、×4 和 ×8。

持有全部层的解码器可在每个样本上重现母带。

任何层都不会被部分解码：一层要么存在且完整，要么不存在。因此，无损等级不需要层内可截断的位平面。

### 2.2 旧式播放

基础层是 44.1 kHz 或 48 kHz 系列中纯净的 16 位 PCM CD 层（Level 0），所有播放器均可播放。

CD 层具有以下特性：

- 无折叠；
- 无叠加；
- PCM 内不含数据。

所有扩展层均承载于 PCM 之外。旧式播放器仅播放 CD 层。

### 2.3 以一个文件取代多个版本

发行方若提供多个音质等级，否则必须分别存储每一个等级，例如：

- CD 16 位；
- 基础采样率下的 24 位；
- 88.2 或 96 kHz 下的 24 位；
- 完整母带。

一个分层无损文件可在单一文件中逐位精确地保存上述全部等级。这是该等级的主要价值。

### 2.4 对文件大小的现实预期

**LAES 不可能比 FLAC 小很多。**分层对母带的压缩效果不会显著优于 FLAC：

- 在已测量的母带上，可实现无损码率的频谱下界仅比压缩等级 8 的 FLAC 低约 4–9 %（第 10 节）；
- FLAC 已会剥除未使用的低位。

**预期文件大小。**作者的评估如下。

| 存储方式 | 大小占母带 FLAC 文件的百分比 |
|---|---|
| 一个包含所有音质等级的分层文件 | 约 96–100 % |
| 将相同音质等级分别存储为多个版本 | 约 175 % |

迄今测量的原型尚未达到此评估（第 10.6 节）。

**存储介质。**完整的无损高解析度文件无法放入 CD：其大小约为 CD 音频原始大小的 3.7 倍。预期介质为蓝光数据光盘和文件。

### 2.5 标记

有损文件始终标记为有损，绝不称为无损。只有全部层均精确的文件才可称为 LAE Lossless。

## 3 分层模型

### 3.1 两个轴

扩展构成一个二维网格。采样率轴每一步使采样率翻倍；位深轴在固定位位置上添加位平面组。

**位深轴（基础采样率）。**该轴始于 16 位 CD 层，即 16 位级别。CD LSB 以下固定位位置的位平面组对其进行细化：

- P1 = 位平面 1–2（18 位级别）；
- P2 = 位平面 3–4（20 位级别）；
- P3 = 位平面 5–8（24 位级别）。

**采样率轴。**基础频带 $0 \ldots B$ 之上为各倍频程层：

- O1 = $B \ldots 2B$（采样率 ×2）；
- O2 = $2B \ldots 4B$（采样率 ×4）；
- O3 = $4B \ldots 8B$（采样率 ×8）。

倍频程按采样率比定义，因此同一算法适用于两个系列。

### 3.2 网格

```
                base band       octave O1        octave O2        octave O3
                0 .. B          B .. 2B          2B .. 4B         4B .. 8B
                (rate R0)       (rate 2*R0)      (rate 4*R0)      (rate 8*R0)

  P3 (planes 5-8, -> 24 bit)   [0,P3]   [O1,P3]   [O2,P3]   [O3,P3]
  P2 (planes 3-4, -> 20 bit)   [0,P2]   [O1,P2]   [O2,P2]   [O3,P2]
  P1 (planes 1-2, -> 18 bit)   [0,P1]   [O1,P1]   [O2,P1]   [O3,P1]
  CD (16 bit, Level 0)         [0,CD]   [O1,CD]   [O2,CD]   [O3,CD]
```

基础频带列 $[0,\cdot]$ 由 CD 层和位深层构成，定义见第 4 节和第 5 节。倍频程列定义见第 6 节。

倍频程列本身是否再细分为位深行，属于待定的倍频程层分帧（第 11 节 O3 项）。在最简单的变体中，每个倍频程列是一个完整位深的单元。

### 3.3 嵌套

各层沿每个轴嵌套。

- **位深。**一个位平面组依赖其上方的所有位平面组以及 CD 层。P1 细化 CD 级别，P2 细化 P1 级别，P3 细化 P2 级别。
- **采样率。**倍频程层 $O_k$ 依赖 $O_1, \ldots, O_{k-1}$ 以及 CD 层。

### 3.4 子集

用户或发行方可保留网格中任何符合嵌套关系的子集，例如：

- CD + 基础采样率下的 24 位（CD、P1、P2、P3）；
- CD + 88.2 kHz（44.1 kHz 系列）或 96 kHz（48 kHz 系列）（CD、O1）；
- 完整网格。

从文件中移除层只会删除数据；不会重新编码任何内容。

示例"CD + 88.2/96 kHz"的前提是两个轴可以独立保留，即倍频程层可在没有位深平面组的情况下解码。第 6.2 节陈述了这一要求。

### 3.5 精确性所保证的内容

以下保证成立：

1. **完整网格。**全部层存在时，每个样本的输出均等于 $x$。
2. **基础采样率前缀。**存在 CD 层以及直至 $P_k$ 的位平面组时，输出等于相应级别的基础字 $b$：$b_{18}$、$b_{20}$ 或 $b$（第 5.2 节）。
3. **其他子集。**存在的每一层均精确解码。中间采样率点（如 88.2 kHz / 24 位）的参考信号作为倍频程层分帧的一部分加以定义（待定，O2 项）。自然的候选是经 SPEC.md 的整数半带滤波链降采样后的母带。

编码器没有任何会影响解码结果的精度、噪声或模式选择。其选择仅影响：

- 文件大小；
- 输出哪些层。

## 4 CD 层

### 4.1 派生 CD（与 LAE Lossy 共用）

默认情况下，CD 层的派生方式与 LAE Lossy 完全相同，分四步：

1. $n$ 级级联整数半带抽取产生未限幅的基础字 $b$。滤波器采用 Q31 系数表、64 位累加、镜像边界，且每个输出样本舍入一次。
2. 添加带种子的 TPDF 抖动，但仅限录音自身噪声低于 0.5 LSB16 的块。数字静音绝不添加抖动。
3. 将结果舍入到 16 位。
4. 将结果限幅到 16 位范围。

**规范性引用。**滤波器系数表、算术、抖动生成器、种子以及逐块抖动标志均为 SPEC.md 中所规定者（第 10 节和第 11.2 节）。

**抖动再生成。**解码器根据固定种子和标志再生成抖动；不传送任何抖动值。因此，每个解码器都精确知道 CD 路径 $v$。

### 4.2 独立 CD

作为替代，可提供现有的 CD 母带，其逐位成为 CD 层。与 LAE Lossy 相同，适用以下条件：

- **格式。**CD 必须采用母带所属系列的基础采样率。
- **对齐。**CD 必须与母带逐样本对齐，且长度相同。
- **抖动。**不添加抖动，因此所有抖动标志均为 0。

此时，无损扩展精确编码母带减去 CD 路径之差。CD 的选择不影响无损性，但会影响位深层的大小：所提供的 CD 与 $b$ 偏离越大（例如由于单独的限幅、均衡或电平调整），位深层越大。

倍频程层仅承载各自的倍频程（第 6 节），因此不受 CD 选择的影响。

### 4.3 未限幅的基础字

基础字 $b$ 未限幅，而 CD 路径经过限幅。因此，位深层精确承载满量程以上的带限过冲。

由于 $b$ 可能超出 24 位范围，基础采样率 24 位级别的输出在写为 24 位 PCM 时必须加以限制。LAE Lossy 为此应用最终硬限幅。LAES 是否在该级别作相同处理，尚待决定（D3 项）。

完整母带的内部重建始终使用未限幅的 $b$。

## 5 位深层

### 5.1 精确位位置上的位平面组

位深层在基础采样率下细化 CD 层。它由 24 位基础字中固定位位置上的三个嵌套位平面组构成。

| 位平面组 | CD LSB 以下的位平面 | 24 位字中的位位置 | 所得级别 |
|---|---|---|---|
| CD（Level 0） | — | （经舍入、加抖动的 16 位值；见第 5.3 节） | 16 位 |
| P1 | 1–2 | 第 7、6 位 | 18 位 |
| P2 | 3–4 | 第 5、4 位 | 20 位 |
| P3 | 5–8 | 第 3、2、1、0 位 | 24 位 |

### 5.2 级别

在本设计概要中，中间级别通过清除边界以下的位平面来定义：

$$b_{18} = 2^{6}\left\lfloor b / 2^{6} \right\rfloor, \qquad b_{20} = 2^{4}\left\lfloor b / 2^{4} \right\rfloor, \qquad b_{24} = b .$$

规范性规范在 18 位和 20 位级别采用此截断还是某种舍入约定，尚待决定（D1 项）。任何此类约定均保持相同的位位置和相同的精确性。

### 5.3 精确重建

CD 级别并非 $b$ 的截断，因为 CD 值经过舍入、加抖动和限幅。因此，第一个位平面组将 CD 路径与 18 位级别相联系。下面两个位平面组则逐位位置地扩展字长。

**各组的内容。**

- **P1** 承载精确整数增量 $e_1 = b_{18}/64 - p(c, d)$，其中 $p$ 是 $\lfloor b/64 \rfloor$ 的整数预测值，由 CD 样本以及（在带标志的块中）再生成的抖动计算得到。
  - 除削波、过冲（第 4.3 节）或采用独立 CD 的情况外，$e_1$ 很小。
  - $p$ 的确切形式（是否进行抖动补偿及其舍入方式）尚待决定（D2 项）。
  - 基线为 $p = 4c$，对应于第 10.6 节原型中使用的残差 $b - 256c$。
- **P2** 承载 $e_2 = (b_{20} - b_{18})/16 \in \{0, 1, 2, 3\}$。
- **P3** 承载 $e_3 = b - b_{20} \in \{0, \ldots, 15\}$。

**解码。**解码器按如下方式重建各级别：

$$b_{18} = 64\,(p + e_1), \qquad b_{20} = b_{18} + 16\,e_2, \qquad b = b_{20} + e_3 .$$

每一步均为精确整数运算。因此，各位平面组的内容完全由母带和 CD 路径确定；只有其熵编码属于设计选择。

在录音素材中，位平面组 P2 和 P3 接近随机。除以下方面外，其编码没有可利用的结构：

- 低位的一般统计特性；
- 存在时的未使用低位。

### 5.4 与 LAE Lossy 位深层的差异

| 方面 | LAE Lossy | LAE Lossless |
|---|---|---|
| 目标 | $T = \mathrm{LP}_{f_c}(b - v)$，减去泄漏补偿项 | 精确的 $b$，不经低通 |
| 精度 | 精度规则（B18/C20/D24，keep20 为 B20/C22/D24） | 固定位平面组 P1/P2/P3，每组均精确 |
| 部分精度 | 安静块相对于块峰值编码 | 无；位平面组要么完整，要么不存在 |
| 泄漏补偿 | 必需，因为量化噪声会泄漏到 CD 频带 | 不适用；不存在量化噪声 |

### 5.5 测得的开销

在测量集合（第 10 节）的一条音轨上，完整的 16 位至 24 位位深层开销约为 0.68 Mb/s。同一音轨的 CD16 层开销约为 0.52 Mb/s。

## 6 倍频程层

### 6.1 频带与比例

| 层 | 频带 | 添加该层后的采样率 | 44.1 kHz 系列 | 48 kHz 系列 | 每秒每声道编码值数 |
|---|---|---|---|---|---|
| 基础层（CD + 位深） | $0 \ldots B$ | $R_0$ | 0–22.05 kHz，44.1 kHz | 0–24 kHz，48 kHz | $R_0$ |
| O1 | $B \ldots 2B$ | $2R_0$ | 22.05–44.1 kHz，88.2 kHz | 24–48 kHz，96 kHz | $R_0$ |
| O2 | $2B \ldots 4B$ | $4R_0$ | 44.1–88.2 kHz，176.4 kHz | 48–96 kHz，192 kHz | $2R_0$ |
| O3 | $4B \ldots 8B$ | $8R_0$ | 88.2–176.4 kHz，352.8 kHz | 96–192 kHz，384 kHz | $4R_0$ |

采样率为 $R_0 2^n$ 的母带具有倍频程层 $O_1, \ldots, O_n$。边界由采样率比固定，两个系列的算法相同。

### 6.2 临界采样

倍频程层采用临界采样。每个倍频程层仅承载其自身的倍频程：第 $k$ 个倍频程每声道每秒承载 $R_0 2^{k-1}$ 个值。

在每个采样率点，基础层与各倍频程层每秒承载的值数之和恰好等于相应的采样率。对于 352.8 kHz 母带，即

$$44.1 + 44.1 + 88.2 + 176.4 = 352.8 \text{ kHz.}$$

倍频程层*不是*"全采样率减去插值后的基础层"形式的残差。此类残差会在 $R_0$ 个基础值之上再次承载完整采样率 $R$；对于 ×8 母带，这比母带本身多出八分之一的值。它还会在基础频带中承载插值残差。

第 6.6 节说明这一曾在逐位精确原型中使用的替代方案及其测量结果。

**独立于位深细化。**倍频程层由母带本身计算，仅承载其倍频程。因此，它不受基础频带位深细化的约束。正是这种独立性使"CD + 88.2/96 kHz"之类的子集成为可能（第 3.4 节）。

### 6.3 倍频程层的内容

测得的 352.8 kHz 母带超声波倍频程具有以下内容：

- **从不为空。**88.2 kHz 以上的频带从不为空。它们由录音中的真实噪声构成，约占完整无损文件比特数的 35 %。
- **测得的开销。**在一条音轨上，各超声波层合计开销约为 4.0 Mb/s。

由于编码是精确的，这些噪声与其他任何内容一样被编码。无损等级没有噪声选项。

### 6.4 未使用的低位

母带的有效位数常少于其字长。主集合（表 10.1）的全部七段录音均有 22 个有效位，因此 $w = 2$。FLAC 会剥除此类位。无损分层必须同样处理，否则将为不承载信息的零付出开销。

原型（第 10.6 节）采用以下机制：

1. **检测。**将 $w$ 检测为该音轨所有样本共有的尾随零位数。
2. **网格舍入。**将由较低层导出的预测值以四舍五入（中点向上）方式舍入到母带的 $2^w$ 倍数网格上：
$$u' = 2^w \left\lfloor \left(u + 2^{w-1}\right) / 2^w \right\rfloor .$$
   当 $w = 0$ 时无需舍入：$u' = u$。
3. **移位。**此时残差 $x - u'$ 为 $2^w$ 的倍数，编码前将其右移 $w$ 位。
4. **重建。**解码器计算 $u' + 2^w \cdot (\text{decoded residual})$。

$w$ 如何以信令表示，以及按音轨还是按块适用，属于待定的分层分帧（O3 项）。

### 6.5 立体声

SPEC.md 第 11.4 节的整数 M/S 提升变换可用于每一层：

$$S = L - R, \qquad M = R + \lfloor S/2 \rfloor ;$$

$$R = M - \lfloor S/2 \rfloor, \qquad L = R + S .$$

该映射完全可逆。原型将其应用于全采样率差分层。立体声去相关是按层固定（M/S 或 L/R）还是按块自适应选择，尚待决定（C4 项）。

### 6.6 已测量的替代方案：差分模型

逐位精确原型以全采样率差分层取代临界采样的倍频程层。其步骤为：

1. **基础字。**由 CD16 和精确的位深残差 $r = b - 256c$ 精确重建基础字。
2. **升采样。**使用整数半带插值器将基础字升采样至母带采样率；该插值器采用 SPEC.md 的 Q31 系数表，并在信号边缘进行镜像。
   - 每一级中，偶数输出样本复制输入：$y[2i] = x[i]$。
   - 奇数输出样本为
     $$y[2i+1] = \left\lfloor \left( \sum_t h_t \left(x[i-t] + x[i+1+t]\right) + 2^{29} \right) / 2^{30} \right\rfloor ,$$
     其中 $h_t$ 为存储的奇数抽头。除数 $2^{30}$ 实现 2 倍插值增益。
   - 信号范围外的索引按镜像处理：$i < 0$ 时取 $-i$，$i \ge L$ 时取 $2(L-1) - i$。（在此步骤中，$x$ 表示该级的输入，$L$ 表示其长度。）
3. **差分。**在母带网格上形成与母带之差，并移除未使用的位（第 6.4 节）。
4. **立体声。**将差分映射为整数 M/S。
5. **编码。**对差分进行精确编码。

解码输出在每个样本上均等于母带。第 10.6 节给出各项大小。

原型确立了这整条整数运算链的精确性：确定性插值、网格舍入、移位和整数 M/S，在编码器和解码器中完全相同。在本设计中，第 6.2 节的临界采样倍频程层取代此模型。

### 6.7 分帧（待定）

以下问题共同构成待定的倍频程层分帧（第 11 节 O1 至 O3 项）：

- 如何以整数实现倍频程划分，使每个倍频程层均为临界采样，且每种部分重建均精确；
- 时间上的分段；
- 中间采样率点的参考信号；
- 倍频程列是否按位深细分。

候选实现为第 7 节所列者：

- 整数可逆变换的谱线分段，类似于 LAE Lossy 中"倍频程 = 谱线分段"的组织方式；
- 时域编码；
- 整数小波倍频程分解，已因测得的编码增益而被否决。

## 7 编码选项

### 7.1 所有选项的共同要求

每个编码选项必须满足五项要求：

1. **可逆性。**对该层值域内的每一个输入（包括满量程极端信号）均完全可逆。
2. **整数算术。**仅使用整数算术。所研究的全部候选方案均为整数方案，采用 32 位数值和 64 位累加器。因此，与 LAE Lossy 的 binary64 逆 MDCT 不同，LAE Lossless 解码无需浮点运算。
3. **确定性。**具有确定性：编码器与解码器按相同顺序执行相同运算。
4. **无损熵编码。**与无损熵编码器结合使用。
5. **不依赖分类。**其正确性不依赖任何分类（第 8 节）。

### 7.2 选项 (a)：整数 MDCT

**结构。**

| 参数 | 值 |
|---|---|
| 每块系数数（跳长） | $N = 512$ |
| 窗 | 正弦窗，长度 $2N$ |
| 构建模块 | 仅使用完全可逆的整数提升步骤 |

**正变换。**正变换分两个阶段。

1. **时域混叠折叠。**在每个重叠中心 $C$，对 $j = 0, \ldots, N/2 - 1$，将每个样本对 $(y[C-1-j],\, y[C+j])$ 旋转 $\alpha_j + \pi/2$，其中
   $$\alpha_j = \frac{\pi}{4} + \frac{\pi\,(j + 1/2)}{2N} .$$
   该旋转以一次精确的四分之一周旋转加一次角度为 $\alpha_j$ 的提升旋转实现。相应的实数映射为
   $$(l, r) \mapsto (-\sin\alpha_j\, l - \cos\alpha_j\, r,\; \cos\alpha_j\, l - \sin\alpha_j\, r).$$
2. **逐块 DCT-IV。**将一个块的 $N$ 个折叠样本排列为 $u[n] = y[C + N - 1 - n]$ 和 $u[N/2 + n] = y[C + N/2 - 1 - n]$，并以基于酉 FFT 分解构建的整数 DCT-IV 进行变换（图 7.1）。

**图 7.1 — 整数 DCT-IV 程序（酉 FFT 分解）。**

1. **打包。**构造复数对 $z_n = (u[2n],\, u[N-1-2n])$，$n = 0, \ldots, N/2 - 1$。
2. **前置旋转。**将每个 $z_n$ 旋转 $-\pi(4n+1)/(4N)$。
3. **置换。**执行位反转置换（成对交换）。
4. **蝶形运算。**执行基 2 蝶形运算。在每个长度为 `len` 的阶段：
   - 将第二个操作数旋转 $-2\pi k/\mathrm{len}$；
   - 然后对实部和虚部构造 $((a+b)/\sqrt2,\ (a-b)/\sqrt2)$，实现方式为对 $b$ 取反后旋转 $\pi/4$。
5. **后置旋转。**将每个输出对旋转 $-\pi k/N$。
6. **取反。**对虚部取反。
7. **解包。**写入 $X[2k] = \mathrm{Re}$ 和 $X[N-1-2k] = \mathrm{Im}$。

**以提升步骤实现旋转。**每个满足 $|\theta| \le \pi/2$ 的角度为 $\theta$ 的旋转由三个提升步骤构成，采用 Q30 系数 $c_1 = \tan(\theta/2)$ 和 $c_2 = \sin\theta$：

$$x \leftarrow x - r(c_1 y), \qquad y \leftarrow y + r(c_2 x), \qquad x \leftarrow x - r(c_1 y),$$

舍入为

$$r(v) = \left\lfloor (v + 2^{29}) / 2^{30} \right\rfloor .$$

超出 $\pm\pi/2$ 的旋转先通过一次精确的四分之一周旋转化简：$(A, B) \mapsto (-B, A)$ 或 $(B, -A)$。

完整的 DCT-IV 程序对每个 512 系数块执行 6193 个基本操作：提升三步组、四分之一周旋转、取反和交换。

**逆变换。**逆变换按相反顺序执行同一程序，并对每一步取逆，从而对每个输入均逐位精确。

**测量结果**（第 10.4 节）：

- **可逆性。**在六种满量程 24 位极端测试信号和真实音频上均逐位精确，不匹配样本数为 0。
- **精度。**与浮点正交 MDCT 的偏差为提升步骤的舍入噪声：

  | 母带 | RMS 偏差 | 最大偏差 |
  |---|---|---|
  | 352.8 kHz | 1.32 LSB | 6.1 LSB |
  | 176.4 kHz | 1.31 LSB | 6.5 LSB |

- **率失真。**在这些测试中至少与浮点 MDCT 相当（第 10.4 节）。
- **速度。**对 40 s 的 352.8 kHz 立体声，正变换 0.7 s，逆变换 0.6 s，约为实时的 60 倍。
- **无损开销估算。**该估算对 16 系数组采用自适应 Rice 编码，未使用上下文建模（第 10.5 节）。

  | 母带 | 整数 MDCT（bit/sample） | FLAC 等级 8（bit/sample） |
  |---|---|---|
  | 352.8 kHz | 9.67 | 9.24（整数 MDCT +4.7 %） |
  | 176.4 kHz | 10.24 | 9.91 |

- **逐位精确原型。**以精确整数 MDCT 系数编码的全采样率差分层达到母带 FLAC 大小的 110.3 %（第 10.6 节）。

**评估。**整数 MDCT 精确且快速，并对频谱着色的内容保留了 MDCT 的编码增益。其舍入噪声约为每个系数 1.3 LSB，会进入编码系数。在已测量的母带上，这一舍入噪声与母带极低的超声波噪声底处于同一量级，在无损编码中会造成可观的比特开销。

### 7.3 选项 (b)：时域无损残差编码

**结构。**每一层按 FLAC 的方式编码：

- 采用量化整数系数的线性预测器由先前样本预测每个样本；
- 对整数残差（样本减预测值）进行熵编码，例如采用分区 Rice 编码；
- 解码器将残差加到完全相同的整数预测值上。

预测循环除预测器的确定性整数计算外不涉及任何舍入，因此残差中不会引入变换舍入噪声。

**测量结果**（估算；第 10.6 节）。对逐位精确原型的全采样率差分层应用了 32 阶时域线性预测器，并以每分区的拉普拉斯熵估算残差开销，未计入边信息。所得整个文件（CD16、位深残差和差分层）的估算值约为母带 FLAC 大小的 103.7 %，而以选项 (a) 编码差分层时为 110.3 %（表 10.6，变体 3 和 2；两者的位深残差均以整数 MDCT 编码）。

**评估。**这是最简单的选项，完全类似 FLAC。可采用与 FLAC 相同的子帧和残差编码结构实现。

### 7.4 选项 (c)：整数提升小波

**结构。**在倍频程分解中评估了 5/3 和 13/7 整数提升小波，两者均完全可逆。

**测量结果**（第 10.4 节）：

- **可逆性。**在六种满量程 24 位极端信号以及 352.8 和 176.4 kHz 的真实音频上均完美重建，不匹配样本数为 0。
- **率失真。**衡量编码增益的率失真比较是在有损等级的量化器下，针对 22.05 kHz 以上的高频层进行的。两种小波均明显劣于 512 线 MDCT（第 10.4 节）（已被取代设计的历史测量，未重复）。

**评估。**已否决。

### 7.5 汇总

| 选项 | 精确 | 整数 | 测得的无损开销 | 编码增益 | 状态 |
|---|---|---|---|---|---|
| (a) 整数 MDCT，N = 512 | 是 | 是 | 母带 FLAC 的 110.3 %（原型）；Rice 估算比 FLAC 等级 8 高 4.7 % | 在这些测试中至少与浮点 MDCT 相当（第 10.4 节） | 候选 |
| (b) 时域 LPC 残差 | 是 | 是 | 约 103.7 %（估算，未计入边信息） | — | 候选；最简单 |
| (c) 整数提升小波 5/3、13/7 | 是 | 是 | — | 明显劣于 MDCT（第 10.4 节） | 已否决 |

### 7.6 选择标准与状态

编码选项的最终选择尚**待定**（C1 项）。标准为：

1. **大小。**相对于母带 FLAC 文件的大小，测量时计入边信息。
2. **简单性。**简单且接近 FLAC；选项 (b) 最简单。
3. **分帧。**与临界采样的倍频程层分帧兼容（O3 项）。
4. **解码速度。**

更强的预测是单独的研究事项（C3 项），目标大小比 FLAC 低 3–6 %。

在同一容器内，无损等级可采用不同于有损等级的编码路径。设计空间内的一种变体是对不同层采用不同选项，例如：

- 位深平面组采用时域编码；
- 倍频程层采用变换。

## 8 块类别及其约束

### 8.1 类别代码

层的每个频带块可带有一个 2 位类别。频带块是一个频带在一个时间段上的块。

| 类别 | 含义 | 编码数据 |
|---|---|---|
| A | 0 位：数字静音；块内每个值都精确为零 | 无 |
| B | 样本位深等级，最低 | 数值，以 B 的模型集编码 |
| C | 样本位深等级，中间 | 数值，以 C 的模型集编码 |
| D | 样本位深等级，最高 | 数值，以 D 的模型集编码 |

B、C、D 与具体位深范围的对应关系尚待决定（K1 项）。

### 8.2 作用

类别可用于引导：

- 将一层分割为块；
- 将数值分组为熵编码组，即选择模型或参数集。

编码器可使用 LAE Lossy 的分析工具（即噪声底估计以及持续音和瞬态检测器）来建议类别。

### 8.3 约束

1. **分类绝不影响无损性。**类别仅选择如何对精确数值进行编码，绝不决定重建哪些数值。每种类别都解码为精确数值。
2. **每个类别编码器都是全定义的。**B、C、D 类编码器接受该层中可能出现的每一个数值，且每个此类数值均可精确往返。超出其等级典型范围的数值会消耗更多比特，但绝不损失精度。其机制（例如转义编码）尚待决定（K2 项）。
3. **A 类仅允许用于精确零。**编码器仅可将 A 类分配给所有值均精确为零的块。
4. **通过试编码选择。**一种可能的编码器策略是通过试编码选择块的类别，采用开销最低的类别。无论编码器选择何种类别，选择不当只会多耗费字节（约束 1）。

### 8.4 与 LAE Lossy 的比较

在 LAE Lossy 中，类别 A、B、C、D 是*精度*等级：类别设定量化步长，从而决定解码结果。

在 LAE Lossless 中，类别仅是*编码*等级：对任何允许的类别分配，解码结果均相同。

## 9 容器

### 9.1 原则（与 LAE Lossy 共用）

两个等级共享以下容器原则：

- CD 层是文件的音频，不作任何改动地存储。
- 所有扩展数据位于 PCM 之外，存放在旧式播放器会忽略的结构中。
- 一个文件承载所有保留的层。移除层即删除其数据。

### 9.2 FLAC

FLAC 数据流的音频帧以普通 16 位 FLAC 数据流承载 CD 层。扩展承载于 FLAC APPLICATION 元数据块中。相关的 FLAC 规则为：

- **块布局。**APPLICATION 块由 32 位应用程序 ID 及其后的数据组成。
- **块大小。**元数据块的 24 位长度字段将每个块限制为至多 $2^{24} - 1$ 字节。因此，大型扩展需拆分到多个块中。
- **位置。**元数据块位于音频帧之前，因此所有扩展数据在文件中均位于 CD 音频之前。
- **音频 MD5。**STREAMINFO 中的音频 MD5 仅覆盖解码后的 CD 音频，不因扩展而改变。

块布局和应用程序 ID 尚待决定（F1 项）。这包括各层在块上的拆分与排序，以及任何使得只需读取所需层的索引。第 10.7 节给出测得的封装结果。

### 9.3 RIFF/WAV

`data` 块以 16 位 PCM 承载 CD 层。扩展承载于单独的 RIFF 块中，播放器将其作为未知块忽略。

LAE Lossy（容器版本 5）使用块 ID `LAE ` 和魔数 `LAE1`（SPEC.md 第 3–5 节）。LAES 是使用同一块并以等级和容器版本加以区分，还是使用单独的块 ID，尚待决定（F2 项）。

### 9.4 旧式行为

旧式播放器的行为如下：

- FLAC 解码器跳过未知的 APPLICATION 块。
- WAV 播放器忽略未知块。
- 两者均逐位播放 CD 层。

容器版本 5 的 LAE Lossy 解码器拒绝 5 以外的任何容器版本（SPEC.md）。因此，未来的 LAES 容器版本不会被误读为有损格式。

### 9.5 完整性

完整性由**覆盖整条音轨的一个哈希**保护。不存在：

- 逐帧哈希；
- 文件头及其后的入口点表和指纹。

哈希算法尚待决定（F3 项），其覆盖范围亦然：解码后的母带 PCM、每个保留的采样率点和位深点，或扩展字节。

设计空间内的一种变体是对解码后的全解析度母带计算哈希，类似于 FLAC 音频 MD5，解码器借此可端到端确认逐位精确性。

### 9.6 等级标识

每个文件都声明其等级。

- 有损扩展始终标记为有损。
- 仅当文件所含的每一层均精确时，该文件才被标识为 LAE Lossless。

承载等级的字段尚待决定（F2 项）。

### 9.7 介质

完整无损网格约为 CD 音频原始大小的 3.7 倍，因此无法放入 CD。预期载体为蓝光数据光盘和文件。

是否为网格的小型子集提供 CD-Extra 承载，尚待决定（F4 项）。此类子集的一个示例是 CD + 位深层，其中 CD 层位于音频区段，扩展位于数据区段。

除标明为估算者外，所有数据均为测量值。大小相对于母带的 FLAC 编码给出。在来源注明 FLAC 压缩等级之处，予以注明。

| 材料 | 用途 |
|---|---|

| 另一段 352.8 kHz / 24 位 DXD 录音，无未使用的低位 | 变换测试（第 10.4 和 10.5 节） |

### 10.2 各采样率点和位深点的大小

下表给出七段 DXD 录音的大小，以占母带 FLAC 文件的百分比表示。

| 版本 | 大小 |
|---|---|
| CD 44.1 kHz / 16 位（加抖动） | 约 10 % |
| 44.1 kHz / 24 位 | 约 23–28 % |

### 10.3 分层开销

七条音轨之一的分层开销为：

| 层 | 开销 |
|---|---|
| CD16 | 约 0.52 Mb/s |
| 16 → 24 位位深层 | 约 0.68 Mb/s |
| 超声波倍频程层 | 约 4.0 Mb/s |

总和约 5.2 Mb/s，与完整无损文件约为 CD 音频原始码率 1.41 Mb/s 的 3.7 倍相符。

88.2 kHz 以上的频带承载约 35 % 的比特。它们由真实噪声构成，从不为空。

### 10.5 整数 MDCT 的无损开销估算

**方法。**整数 MDCT 的每个系数均精确编码。每组 16 个系数先作 zig-zag 映射，选取使该组码长最短的 Rice 参数 $k \in \{0, \ldots, 23\}$，并为每组的 $k$ 计入 5 位。不使用上下文建模。

| 母带 | L/R（bit/sample） | M/S（bit/sample） | FLAC 等级 8，实测（bit/sample） |
|---|---|---|---|
| 352.8 kHz DXD | 9.673 | 9.679 | 9.237 |
| 176.4 kHz | 10.235 | 10.254 | 9.905 |

在 DXD 录音上，该估算比 FLAC 高 4.7 %。在此估算中，M/S 对完整信号未带来增益。

### 10.6 逐位精确原型（差分模型）

原型在七段 DXD 录音之一上运行，40 s 立体声。它包含三个部分：

- **CD16。**CD 层，以 FLAC 编码。
- **位深残差。**残差 $r = b - 256c$，以整数 MDCT 编码，每个系数均精确。
- **差分层。**母带减去 CD 路径，CD 路径以整数 Q31 半带系数表升采样，边缘作镜像处理。*历史注释：*第 6.6 节将升采样的信号描述为由 CD16 和位深残差重建的基础字；原型不属于本仓库，其遵循的是两种描述中的哪一种，已无法核实。

解码输出在每个样本上均等于母带。

**精确系数的编码。**精确系数以有损等级原型的范围编码器编码，配置为量化步长 1，使每个系数均精确，按每组 32 条谱线进行。

**变体。**

1. L/R，保留未使用的低位。
2. 同 1，但移除未使用的低位，并对差分应用整数 M/S。移除未使用的位意味着在母带的 4 的倍数网格上重建，并将差分右移 2 位（第 6.4 节）。
3. 同 2，但差分层的开销以 32 阶时域线性预测器和每分区拉普拉斯熵估算。该变体为估算，未计入其边信息。

参考为母带的 FLAC 文件，21,996,137 字节，原型笔记中记录为"compression level 12"（未记录编码器；参考 `flac` 工具的等级为 0–8）（已被取代设计的历史测量，未重复）。

**表 10.6 — 原型各变体的大小，单位为字节。**

| 变体 | CD16（FLAC） | 位深残差 | 差分层 | 总计 | 占母带 FLAC 的 % |
|---|---|---|---|---|---|
| 1 | 1,887,683 | 3,695,740 | 24,641,414 | 30,224,837 | 137.4 % |
| 2 | 1,887,683 | 3,695,740 | 18,674,558 | 24,257,981 | 110.3 % |
| 3（估算） | 1,887,683 | 3,695,740 | 约 17,236,531 | 约 22,820,000 | 约 103.7 % |

变体 2 结合了两项改动，即移除未使用的位和 M/S；两者各自的贡献未作区分。

**解读。**变体 2 与变体 3 之间的差距至少部分来自整数 MDCT 的舍入噪声（变体 3 也未计入边信息），约为每个系数 1.3 LSB。该噪声与这些母带极低的超声波噪声底处于同一量级。时域预测不存在此类舍入。

原型采用全采样率差分层，而非本设计中的临界采样倍频程层（第 6.2 节）。

### 10.7 容器封装

在 LAE Lossy 的 CD 层测试中，将一个扩展有效载荷分别封装到 FLAC 文件和 WAV 块中（仅为封装测试；LAE Lossy 未规定 FLAC 承载）。FLAC 文件增加了 5,000,008 字节。结果为：

- 在两种容器中，CD 层的音频 MD5 在封装前后完全相同；
- 有效载荷往返后保持完整。

## 11 待定事项

**编码**

- **C1** — 最终编码选项：(a) 整数 MDCT 或 (b) 时域残差，或按层组合（第 7.6 节）。

- **C3** — 更强的预测，目标比 FLAC 低 3–6 %。这是单独的研究事项。
- **C4** — 立体声去相关：按层固定，或按块自适应。

**位深层**

- **D1** — 18 位和 20 位级别采用截断还是舍入（第 5.2 节）。
- **D2** — 位平面组 P1 中 CD 路径预测 $p$ 的确切形式，包括是否采用抖动补偿（第 5.3 节）。

**倍频程层**

- **O1** — 临界采样倍频程层的整数实现，使每种部分重建均保持精确。
- **O2** — 中间采样率点的参考信号，例如 88.2 kHz / 24 位。
- **O3** — 倍频程层分帧：时间分段、未使用低位的信令、倍频程列按位深细分，以及分帧如何保持倍频程层独立于位深平面组（第 6.2 节）。

**类别**

- **K1** — B、C、D 类与位深范围的对应关系，以及频带块的大小。
- **K2** — 类别编码器的全定义机制，例如转义编码。

**容器**

- **F1** — FLAC APPLICATION 块布局、应用程序 ID、在块上的拆分以及任何索引。
- **F2** — RIFF 块 ID 和等级/版本字段：共用块或单独的块。
- **F3** — 整条音轨哈希的算法和覆盖范围。
- **F4** — 网格小型子集的 CD-Extra 承载。
- **F5** — `.lae` 文件布局，与 LAE Lossy 共用。

**范围**

- **S1** — 立体声以外的声道配置。
- **S2** — 接纳基础采样率下仅具有位深轴的母带。

**规范**

- **N1** — 规范性规范、一致性测试向量和参考解码器。

## 12 与 LAE Lossy 的关系

| 方面 | LAE Lossy（LAEY） | LAE Lossless（LAES） |
|---|---|---|
| CD 层 | 通过整数半带抽取和自适应带种子 TPDF 抖动派生，或采用独立 CD | 相同（SPEC.md 第 10 和 11.2 节） |
| 层划分 | 基础采样率下的位深层；母带采样率下的频率层 | 基础采样率下的位深层；按采样率比划分的倍频程层 |
| 位深层 | $\mathrm{LP}_{f_c}(b - v)$ 的编码近似，带泄漏补偿；精度规则 1 和 3 | 精确的 $b$，位于固定位位置的位平面组 P1/P2/P3 中 |
| 高采样率层 | 母带采样率下的一个 MDCT，按倍频程划分谱线分段，起点为检测到的 CD 截止频率以下 1 kHz | 临界采样倍频程层 $B \cdot 2^{k-1} \ldots B \cdot 2^k$，精确；分帧待定 |
| 编码 | 死区量化器、精度等级、重建偏移量、可选零级、范围编码器 | 精确编码；选项 (a) 或 (b) 待定 |
| 类别 A/B/C/D | 决定解码结果的精度等级 | 仅为编码等级；解码结果与类别无关 |
| 方案与模式 | 2 种方案 × 6 种模式 | 无影响结果者 |
| 层内部分精度 | 精度随块峰值变化 | 无；层要么完整，要么不存在 |
| 解码器算术 | 整数滤波器；按固定顺序执行 IEEE-754 binary64 逆 MDCT，带启动自检 | 所有候选选项均仅使用整数 |
| 立体声 | M/S（频率层），L/R（位深层） | 可用整数 M/S；选择待定 |
| 分析工具 | 噪声底、音调和瞬态检测器、闭环 | 相同工具；仅可引导类别和分段 |
| 容器 | RIFF 块 `LAE `（容器版本 5）；计划支持 FLAC | FLAC APPLICATION 块或 RIFF 块；布局待定 |
| 完整性 | 对扩展块计算 CRC-32；仅整条音轨 | 一个整条音轨哈希 |
| 标记 | 始终标记为有损；绝不称为无损 | 无损；每一层均精确 |

LAE Lossy 中仅为管理量化误差而存在的工具在无损等级中不起作用。这些工具为：

- 精度规则和 16 位兜底；
- 死区和重建偏移量；
- 可选零级；
- 泄漏补偿；
- 由模式驱动的降级。

由此形成两条解码器路径：

- **LAE Lossy。**确定性浮点逆变换，在输出处舍入一次。
- **LAE Lossless。**整数可逆逆变换，其舍入完全抵消。

两个等级可承载于同一容器中。
