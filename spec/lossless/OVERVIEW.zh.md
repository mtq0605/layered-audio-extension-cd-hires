# LAES 简介

[English](OVERVIEW.md) | **中文**

**LAES**（LAE 无损，ID `LAE2`）把一个**核心母带**和多个**无损母带**装进一个普通的 FLAC 或 WAV 文件。不装 LAE 软件的播放器播放核心母带；支持 LAE 的播放器还能播放其他母带，每个母带先核对 SHA-256 再播。全程无损，每个母带都能逐位还原。

- **核心母带**本身就是一个无损母带：整数 PCM，44.1 或 48 kHz，16、24 或 32 位。用 16 位时可以是 CD 兼容的；24 位、32 位或 FLAC 形式的核心母带，CD 播放器读不了。
- **其他母带**是基础采样率的 1、2、4 或 8 倍（最高 352.8 / 384 kHz），16、24 或 32 位。每个母带存成和文件里已有信号（核心母带或更早的母带）的差值，或者完整存储，取小的那种。
- **派生 16 位母带：** 没有自己的 16 位母带的采样率，都有一个派生的 16 位母带。它相对自己的定义是无损的：每个解码器都逐位得到同样的结果。它相对所取自的母带不是无损的：那个母带用 TPDF 抖动重新量化到 16 位，无法从它还原。它是派生母带，不是原始母带。

规范：[SPEC.zh.md](SPEC.zh.md)。不装 LAE 时哪些软件能播什么：[COMPATIBILITY.zh.md](../COMPATIBILITY.zh.md)。

## 和 FLAC、WAV 比较

2026-11-05 实测，用两个 10 秒片段（2L 02 和 05）。每个片段有核心母带和三个母带：352.8 kHz / 32 位、352.8 kHz / 24 位、176.4 kHz / 24 位。分开的 FLAC 文件用 FFmpeg、压缩级别 8 编码。

| 同样四个版本，存成 | 片段 02 | 片段 05 |
|---|---|---|
| 一个 LAES 文件，FLAC 形式（24 位核心母带） | **13.9 MB** | **15.2 MB** |
| 四个 FLAC 文件（24 位核心母带 + 三个母带） | 24.8 MB | 28.7 MB |
| 一个 LAES 文件，WAV 形式（16 位核心母带） | 16.6 MB | 17.5 MB |
| 四个 WAV 文件（16 位核心母带 + 三个母带） | 61.7 MB | 61.7 MB |
| 作为参考：只有核心母带的 FLAC | 1.1 MB | 1.5 MB |

这些数字适用于像本次测试这样、来自同一个源的母带。如果各母带的混音、电平或剪辑不同，彼此相同的部分很少，编码器就会把它们基本完整地存下来。

## 优点

- **一个文件，所有版本。** 发行方只发一个文件。听的人自己选版本，或者由播放器在听的人设的上限内自动选。
- **比分开存小。** 上面的测试里，LAES 比同样的版本分别存成 FLAC 小 44～47%；它的 WAV 形式比分别存成 WAV 小 72～73%。
- **不装 LAE 也能播。** 文件就是标准的 FLAC 或 WAV，任何完整的 FLAC / WAV 解码器都能播核心母带。实测：libFLAC、FFmpeg、Kodi、VLC、foobar2000、Android 自带的解码器。
- **无损，并且有校验。** 每个母带都带 SHA-256，播放器要等它完整解码、核对相符之后才使用。
- **标签和图片：** FLAC 形式里放在母带前面（Vorbis comment、PICTURE），WAV 形式里写成 RIFF INFO 加 ID3v2.4，都用 UTF-8。改标签（`laes tag`）不动音频。
- **周边工具：** `laes_export` 把任意一个版本导出成普通 FLAC，给流媒体服务器用；`laes_disc.ps1` 把一张专辑做成数据光盘映像。

## 缺点和限制

- **其他母带要 LAE 软件才能播。** 没装时只能播核心母带。
- **FLAC 形式的母带放在前面。** FLAC 规定所有元数据都在音频帧前面，因此：
  - Windows 自带的解码器（Media Foundation、资源管理器）不认这种文件；
  - 通过网络直接读这个文件的播放器，要先把母带读完才出声；
  - 没有跳转表，某些播放器里跳转比普通 FLAC 慢。
- **WAV 形式超过 4 GiB 要写成 RF64。** 很多 WAV 读取器打不开 RF64，Android 的就是其中之一。
- **32 位的核心母带**在很多解码器里播不了：Windows 和 Android 都不解码 32 位 FLAC。所以参考编码器默认核心母带最多用 24 位，除非另外指定。
- **编码要时间、内存和临时磁盘。** 30 分钟、12 个母带，约需 36 分钟、1.4 GB 内存、约 28 GB 临时空间（2026-11-05）。
- **文件比只有核心母带时大得多**，因为它装着所有母带。

## 用哪种形式

- **FLAC 形式**（`.flac`，或 `.lae` 加 `--form=flac`）：最小；核心母带可以是 24 位；标签和普通 FLAC 一样。不适合 Windows 自带的播放器。
- **WAV 形式**（`.wav`，或 `.lae` 加 `--form=wav`）：`data` 块里是 16 位核心母带，可以是 CD 兼容的。Windows 资源管理器能读出时长（实测）；Windows 自带播放器能否播放没有测。文件更大，超过 4 GiB 时是 RF64。
- **做流媒体时**，请用 `laes_export` 导出普通 FLAC 来提供，不要直接提供 LAES 文件本身。
