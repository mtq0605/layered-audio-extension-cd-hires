## 1. 范围与合格性

### 1.1 LAES 是什么

LAES 在一个文件或一张光盘里存放：

* **核心**：双声道整数 PCM，**基础采样率** 44 100 Hz 或 48 000 Hz，16、24 或 32 位。普通播放器可以直接播放核心；
* 1 到 16 个**母带**：双声道整数 PCM，16、24 或 32 位，采样率为基础采样率的 1、2、4 或 8 倍。母带之间互相独立，可以来自不同的制作（例如同一首曲子的 16 位 / 88.2 kHz 母带和 24 位 / 352.8 kHz 母带）。

每个母带都**逐位**还原。解码器还能由每个母带得到它的**采样率级别**：用第 3 节的提升，把母带降到 1/2、1/4、1/8 直到基础采样率。采样率级别是精确定义的整数信号，不单独存储。

LAES 全程无损，载荷里没有任何近似。每个母带存成对文件里已有信号（核心或更早的母带）的差值，或者完整存储，由编码器选更小的一种（第 6.4 节）。

### 1.2 载体

| 载体 | 核心 | LAES 载荷 | 节 |
|---|---|---|---|
| **WAV 形式** | RIFF/WAVE 文件的 `data` 块 | 同一文件里的 `LAE ` 块（末尾带一个空格） | 7 |
| **FLAC 形式** | FLAC 文件的音频帧 | 一个或多个 ID 为 `LAE2` 的 APPLICATION 元数据块 | 8 |
| **CD-Extra** | 会话 1 的音轨（16 位，44 100 Hz） | 会话 2（数据会话）里每轨一个扩展文件 | 9 |

三种载体存放同一种载荷（第 6 节），只有核心的位置不同。

### 1.3 合格性

合格的解码器：

1. 必须按第 6.7 节检查载荷，按第 7 到 9 节检查载体；
2. 必须按第 6.6 节精确还原每个母带；
3. 必须用每个母带的 SHA-256（第 6.5 节）核对还原结果；哈希不符的母带不得当作该母带提供；
4. 载荷缺失、损坏或检查不通过时，必须照常播放核心（"只播核心"）；
5. 可以提供第 10 节的任何输出。

合格的编码器写出的载荷，合格的解码器能够接受，并且逐位还原编码器的输入母带。留给编码器自己决定的事项见第 11 节。

### 1.4 术语

| 术语 | 含义 |
|---|---|
| 基础采样率 | 44 100 Hz（CD 族）或 48 000 Hz（DVD 族） |
| 核心 | 普通播放器播放的信号（第 1.1 节）。在 CD 或 DVD 上就是 LAE Lossy 所说的 CD 层；在 FLAC 形式里也可以是 24 或 32 位 |
| 级数 | 采样率为基础 × 2^S 的母带，其级数为 S（0 到 3） |
| 第 k 级 | 级数为 S 的母带在基础 × 2^k 采样率上的信号，0 ≤ k ≤ S。第 S 级就是母带本身（去掉未用低位后，第 6.3 节）；第 0 级是它的**基础级别** |
| 倍频程层 k | 第 k 级拆成第 k − 1 级时得到的细节信号（第 3 节） |
| 参照档 | 母带对之存差值的信号：核心，或载荷里更早的一个母带 |
| T | 母带相对参照档的**时间位置**，单位为基础采样率的样点，分整数部分和以 2^−32 个基础采样率样点为单位的小数部分 |
| w | 母带每个样点都为 0 的低位个数（"未用低位"）；全部样点为 0 时 w = 0 |

### 1.5 设计特点（说明性）

* 载荷及其载体里任何地方都没有索引、seek 表、cue 表或层偏移表；时间位置只能通过解码得到。
* 载荷整块存放，不与核心交错。
* 每个母带在整个长度上只有一个存法和一个参照档，不存任何权重或增益。
* 两个声道始终分开编码：母带的左声道只由左声道信号还原，右声道只由右声道信号还原。

## 2. 记号与运算

### 2.1 整数

* `int64`、`uint64` 表示 64 位二进制补码有符号数和无符号数；8、16、32 位同理。
* 载荷、WAV 块和 CD-Extra 尾部记录里的多字节数一律**小端**。FLAC 结构按 RFC 9639（大端位序）。
* 有符号数的 `a >> s` 为算术右移（除以 2^s 向下取整）。
* **精确求和。**本文凡写乘积之和，都必须精确求和。第 3、4 节的所有求和，128 位二进制补码累加器都足够。
* **回绕。**第 3、4.2、5.1、6.6 节得出的每个值（预测、还原的样点、提升的输出、参照值、`x << w`）都按 int64 取模 2^64（二进制补码）。正确的载荷不会需要更宽的值；需要更宽值的载荷只会在 SHA-256 核对时失败。
* **取整。**对精确整数 A 和 s ≥ 1，`round_s(A) = (A + 2^(s−1)) >> s`，在精确值上计算。即 A / 2^s 取最近整数，恰好一半时向 +∞。
* **对称延拓。**长度 n ≥ 1 的信号 x，任意整数下标 i：
  n = 1 时 `m(i, n) = 0`；否则令 p = 2(n − 1)，`j = i mod p`（0 ≤ j < p），j < n 时 `m(i, n) = j`，否则 `p − j`。
  `x[m(i, n)]` 是 x 按整样点镜像延拓后在 i 处的值。下标为 64 位。
* `levLen(n, k)`：把 n 减半 k 次，每次向上取整（`n = (n + 1) / 2`，做 k 次）。

### 2.2 浮点（只用于第 4.1 节）

参照抽头用 IEEE-754 binary64 计算。每个 `+ − × ÷` 和 `sqrt` 都必须单独取整（就近、偶数优先），并按书写顺序计算。不得用融合乘加、扩展精度中间值或改变运算顺序；除 `sqrt` 和 `floor` 外不得用库函数。*说明：*MSVC 用 `/fp:strict`，GCC/Clang 用 `-ffp-contract=off` 且不用 `-ffast-math`。

## 3. 采样率级别：提升 L

### 3.1 一级

一级把长度为 n 的信号 x 拆成低频部分 s（长度 ⌈n/2⌉，即下一级）和细节 d（长度 ⌊n/2⌋，即倍频程层）：

```
xe[i] = x[2i]          0 ≤ i < ⌈n/2⌉
xo[i] = x[2i + 1]      0 ≤ i < ⌊n/2⌋
d[i]  = xo[i] − P(xe, i)
s[i]  = xe[i] + U(d, i)

P(xe, i) = round_30( Σ_{t=0..39} H0[t] · ( xe[m(i − t, ne)] + xe[m(i + 1 + t, ne)] ) )          ne = ⌈n/2⌉
U(d, i)  = round_31( Σ_{t=0..59} U0[t] · ( d[m(i − 1 − t, no)] + d[m(i + t, no)] ) )            no = ⌊n/2⌋；no = 0 时 U = 0
```

H0 是表 `kHalf0`，U0 是表 `kU0`（附录 A）。每个乘积单独计算，求和精确（第 2.1 节）。

已知 s、d 和 n，逆运算为：

```
xe[i]     = s[i] − U(d, i)
x[2i]     = xe[i]
x[2i + 1] = d[i] + P(xe, i)
```

它精确还原 x。

### 3.2 母带的全部级别

级数为 S 的母带，去掉未用低位后（第 6.3 节），第 S 级就是母带。从 k = S 到 1，对第 k 级做一级拆分，得到第 k − 1 级和倍频程层 k。所以：

* 第 k 级每声道有 `levLen(F, S − k)` 个样点，F 是母带的帧数；
* 倍频程层 k 每声道有 `⌊levLen(F, S − k) / 2⌋` 个样点。

## 4. 参照：时间位置与字长

母带（或它的某一级）存成对**参照**的差值。参照就是参照档信号移到母带的时间位置、缩放到母带的字长。

### 4.1 参照抽头

对样点的小数 f ∈ [0, 1)（以无符号 32 位数 F 给出，f = F / 2^32），256 个参照抽头 h[q]（q = −127 … 128）按下面的步骤计算（binary64，第 2.2 节）：

```
PI    = 3.141592653589793115997963468544185161590576171875       （最接近 π 的 binary64 值）
sin(x)（|x| ≤ π/2）：y = x·x；s = 1；k 从 15 到 1：s = 1 − s·y / ((2k)·(2k + 1))；结果为 x·s
I0(x)：               y = x·x / 4；term = 1；s = 1；k 从 1 到 80：term = term·y / (k·k)；s = s + term；结果为 s

g   = f（f ≤ 0.5 时），否则 1 − f
sf  = sin(PI·g)
i0b = I0(14)
q 从 −127 到 128：
    u = f − q
    sinc = 1（u = 0 时），否则 (q 为偶数 ? +1 : −1) · sf / (PI·u)
    r = u / 128
    w = I0(14 · sqrt(1 − r·r)) / i0b（−1 < r < 1 时），否则 0
    h[q] = floor(sinc · w · 2^31 + 0.5)                              （int64）
c = |u| 最小的 q 中最小的那个（q 从小到大扫描，严格比较；f = 0.5 时有关）
h[c] = h[c] + 2^31 − Σ_q h[q]
```

抽头都是整数，总和恰好为 2^31。f = 0 时 h[0] = 2^31，其余抽头都为 0。

### 4.2 参照值

设 `src` 为参照档在相应级别上的信号（长度 n），`W` 和 F 为时间位置的整数部分和小数部分（都以该级别的样点为单位），`up` 为位差（第 6.6 节）。参照的长度等于母带在该级别上的信号长度（`nOut` 个值）：

```
A_i     = Σ_{q=−127..128} h[q] · src[m(i + W + q, n)]          精确
ref[i]  = round_{31−up}(A_i)            31 − up > 0 时
ref[i]  = A_i · 2^(up−31)               31 − up ≤ 0 时（按 int64 取模 2^64）
```

*说明：*`up` 是母带比参照档多出的有效位数。母带位数更少时 up 为负，参照就把参照档按母带字长取整。

### 4.3 第 j 级上的时间位置

时间位置 T = W + F / 2^32 个基础采样率样点，在第 j 级（采样率为基础采样率 × 2^j）上是 T · 2^j 个该级样点：

```
W_j = W · 2^j + (F >> (32 − j))        j ≥ 1；W_0 = W
F_j = (F · 2^j) mod 2^32
```

## 5. 层编码器

每个存储的信号（基础级别、某级差值或倍频程层，一次一个声道）都由层编码器编成一串字节。位从高到低写。一个 n 个样点的**层**是一串长度为 B 的**块**（最后一块取剩下的），块与块紧接着写，中间不按字节对齐；层末尾用 0 补到字节边界。

### 5.1 块

| 字段 | 位数 | 含义 |
|---|---|---|
| 类型 | 2 | 0 = 常数，1 = 原样，2 = 固定预测，3 = LPC |
| W | 6 | 常数、原样值和预热样点的存储宽度（W 位二进制补码）；1 ≤ W ≤ 62。编码器选 W 使块中每个样点都放得下；解码器不按 W 检查解出的样点 |

接着按类型，对 n 个样点 x[0 … n−1]：

* **常数：**一个 W 位值 v；x[i] = v。
* **原样：**n 个 W 位值。
* **固定预测：**阶数 o（3 位，0 ≤ o ≤ 4，o < n）；o 个预热样点（各 W 位）；n − o 个残差。只在 W ≤ 58 时允许。预测（同 FLAC）：o = 0：0；1：x[i−1]；2：2x[i−1] − x[i−2]；3：3x[i−1] − 3x[i−2] + x[i−3]；4：4x[i−1] − 6x[i−2] + 4x[i−3] − x[i−4]。
* **LPC：**阶数 − 1（5 位；阶数 o = 1 … 32，o < n）；精度 − 1（4 位；p = 1 … 16）；移位（5 位；0 … 31）；o 个系数 c[0 … o−1]（各 p 位二进制补码）；o 个预热样点（各 W 位）；n − o 个残差。只在 W ≤ 44 时允许。预测：`pred_i = floor( Σ_{j=0..o−1} c[j] · x[i−1−j] / 2^移位 )`，求和精确（移位为 0 时就是和本身）。

还原：i ≥ o 时 x[i] = 残差[i] + pred_i。

### 5.2 残差

| 字段 | 位数 | 含义 |
|---|---|---|
| 分区阶 po | 4 | 0 ≤ po ≤ 8，2^po ≤ m（m 为残差个数） |

m 个值分成 2^po 个分区：第 0 … 2^po − 2 个分区各 ⌊m / 2^po⌋ 个值，最后一个分区 m − (2^po − 1) · ⌊m / 2^po⌋ 个。每个分区有：

* 6 位参数 k。k = 0 … 62 时用 Rice 码：v ≥ 0 时 u = 2v，v < 0 时 u = −2v − 1；商 q = u >> k 写成 q 个 0 后跟一个 1，再写 u 的低 k 位。u 必须在 64 位以内。
* k = 63 为转义：后跟 6 位宽度 r（1 … 63），然后每个值写成 r 位二进制补码。

附加信息全部定长。

### 5.3 块长

| 信号 | 块长 B |
|---|---|
| 基础级别（存法 1）和基础级别差值（存法 0） | 4096 |
| 第 j 级差值（存法 2） | 4096 · 2^j |
| 倍频程层 k | 4096 · 2^(k−1) |

### 5.4 检查

字段超出上面的范围、某种预测用于超过其上限的 W、阶数不小于块长、或数据提前结束时，解码器必须拒绝该层（第 6.7 节）。层长度里最后一块之后的字节和补位不检查，解码器必须忽略。

## 6. LAES 载荷

载荷是一串字节，后跟它的 CRC-32（4 字节）。CRC-32 为 IEEE 802.3 CRC（反射多项式 0xEDB88320，初值和末尾异或都为 0xFFFFFFFF），覆盖它前面的全部载荷字节。

### 6.1 头部（64 字节）

| 偏移 | 长度 | 字段 | 值 |
|---|---|---|---|
| 0 | 4 | 魔数 | `LAE2` |
| 4 | 2 | 版本 | 1 |
| 6 | 2 | 头长 | 64 |
| 8 | 4 | 基础采样率 | 44 100 或 48 000 |
| 12 | 1 | 核心位深 | 16、24 或 32 |
| 13 | 1 | 声道数 | 2 |
| 14 | 1 | 母带数 M | 1 … 16 |
| 15 | 1 | 核心方式 | 0 = 核心在 WAV `data` 块或 CD 音轨里；1 = 核心在 FLAC 音频帧里 |
| 16 | 8 | 核心帧数 | 核心每声道的样点数 |
| 24 | 32 | 核心 SHA-256 | 第 6.5 节 |
| 56 | 8 | 保留 | 0 |

### 6.2 母带记录（72 字节），其后是它的各层

| 偏移 | 长度 | 字段 | 值 |
|---|---|---|---|
| 0 | 1 | 位深 | 16、24 或 32 |
| 1 | 1 | 级数 S | 0 … 3（采样率 = 基础 × 2^S） |
| 2 | 1 | w | 未用低位，w < 位深 |
| 3 | 1 | 存法 | 0、1 或 2（第 6.4 节） |
| 4 | 1 | 参照档 | 0 = 核心；k = 本载荷的第 k 个母带（从 1 起数） |
| 5 | 3 | 保留 | 0 |
| 8 | 4 | 采样率 | 基础 × 2^S |
| 12 | 4 | 保留 | 0 |
| 16 | 8 | 帧数 F | 每声道样点数，≥ 1 |
| 24 | 8 | T 整数部分 | int64，T 的整数部分（基础采样率的样点，相对参照档） |
| 32 | 4 | T 小数部分 | uint32，单位 2^−32 个基础采样率样点 |
| 36 | 4 | 保留 | 0 |
| 40 | 32 | 母带 SHA-256 | 第 6.5 节 |

母带按载荷顺序依次排列：母带 1 的记录、它的各层，母带 2 的记录、它的各层，依此类推。最后一个母带的各层之后是 CRC-32。母带的参照档必须是核心或载荷中更早的母带。

### 6.3 母带的各层

存法 0、1 时 j = 0；存法 2 时 j = min(S, S_t)，S_t 是参照母带的级数。每个声道（先左后右）：

1. 一个 uint32 字节长度，加上以下信号的层编码（第 5 节）：
   * 存法 0 或 2：第 j 级的**差值**，`levLen(F, S − j)` 个值：母带的第 j 级减去参照（第 6.6 节）；
   * 存法 1：母带的基础级别本身，`levLen(F, S)` 个值；
2. 每个 k = j + 1 … S：一个 uint32 字节长度，加上倍频程层 k 的层编码。

母带的样点要**先去掉未用低位**：`x = 样点 >> w`。第 3 节的各级和倍频程层都由 x 计算。

### 6.4 存法

| 存法 | 参照档 | 存在哪一级 | 含义 |
|---|---|---|---|
| 0 | 核心或任一更早的母带 | j = 0 | 在基础级别上对参照档的差值 |
| 1 | 0（无） | j = 0 | 完整存储基础级别 |
| 2 | 更早的母带 | j = min(S, S_t) | 在两者共有的最高一级上对参照母带的差值；只存 j 以上的倍频程层 |

### 6.5 哈希

* **母带 SHA-256：**按文件顺序 L、R、L、R …，每个样点取其 int32 二进制补码值，4 字节小端。
* **核心 SHA-256：**16 位核心按 int16 小端，L、R、L、R …（即 16 位 `data` 块的字节内容）；24 或 32 位核心与母带相同（int32 小端）。

### 6.6 还原

按载荷顺序对每个母带 m、每个声道分别做：

```
j  = 0（存法 0、1）或 min(S, S_t)（存法 2）
x_j = 解出的第一层                                       （levLen(F, S − j) 个值）
存法 ≠ 1 时：
    参照档信号 src = 核心的该声道（参照档 0），或参照母带 t 的第 j 级（参照档 t ≥ 1）
    up  = (位深 − w) − 核心位深                           参照档 0
          (位深 − w) − (位深_t − w_t)                      参照母带 t
    (W_j, F_j) = T 在第 j 级上的值（第 4.3 节）
    x_j = x_j + 参照(src, W_j, F_j, up)                     （第 4.2 节，nOut = levLen(F, S − j)）
k = j + 1 … S：
    x_k = 逆运算(x_{k−1}, 倍频程层 k, levLen(F, S − k))
母带样点 = x_S << w
```

参照母带 t 的第 j 级由它还原出的样点得到：x_t = 样点 >> w_t 是它的第 S_t 级，按第 3.1 节逐级拆分得到更低的各级。

### 6.7 检查

出现下列任一情况时，解码器必须拒绝载荷（只播核心）：

* CRC-32 不符；
* 魔数、版本（1）或头长（64）不对；基础采样率不是 44 100 或 48 000，或与载体中核心的采样率不一致；核心位深与载体中的核心不一致；声道数 ≠ 2；核心方式 > 1；M 不在 1 … 16；
* 核心帧数与载体中的核心长度不一致，或核心 SHA-256 不符；
* 某个母带：位深不是 16、24、32；S > 3；w ≥ 位深；存法 > 2；采样率 ≠ 基础 × 2^S；F < 1；`levLen(F, S)` > 核心帧数 + 2^24；|T 整数部分| ≥ 2^40。核心帧数和 F 都是 uint64，比较时不得截断；放不下 F 个样点的解码器必须拒绝载荷，而不是截断；
* 存法 0 或 2 的参照档不是载荷中更早的；存法 2 的参照档为 0；存法 1 的参照档不为 0；
* 某层不符合第 5.4 节，或载荷提前结束；
* 最后一个母带的各层与 CRC-32 之间还有多余字节。

还原结果与 SHA-256 不符的母带不得当作该母带提供，它的采样率级别也不得提供。核心和其他母带不受影响，但参照链上包含它的母带除外：它们的 SHA-256 也会不符。

保留字段：写入方必须写 0，读取方必须忽略。核心方式不与载体比较。

## 7. WAV 形式

LAES WAV 文件是 RIFF/WAVE 文件：

* `fmt `：整数 PCM（格式标记 1，或 0xFFFE 加 PCM 子格式），2 声道，基础采样率，16、24 或 32 位；
* `data`：核心；
* `LAE `：LAES 载荷加 CRC-32（第 6 节），核心方式 0。

文件必须恰好有一个 `data` 块，最多一个 `LAE ` 块。*说明：*参考读取器各取最后一个，块长超出文件末尾时截到文件末尾。

任何 WAV 播放器都播放核心。块的前 4 个字节标明格式：`LAE1` = LAEY（LAE 有损），`LAE2` = LAES（本规范）。读取方应当告诉用户识别出的是哪种格式；LAEY 解码器遇到 `LAE2` 时报告"这是 LAES 文件"并且不解码，播放器则播放核心。单个 `data` 块超过 4 GiB 的 WAV 文件不在第 1 版范围内。

---

## 8. FLAC 形式

LAES FLAC 文件是一个 FLAC 流（RFC 9639）：

```
"fLaC" | STREAMINFO | ID 为 "LAE2" 的 APPLICATION 块（k ≥ 1 个）| 其他元数据块（可选）| 音频帧 = 核心
```

* STREAMINFO：2 声道，基础采样率，16、24 或 32 位，核心的样点数（不得为 0），核心的 MD5（必须给出且正确）。解码器发现 MD5 缺失或不符时不得使用载荷（核心不是载荷对应的那个）；是否仍播放核心由播放器决定。
* LAES 载荷（含 CRC-32，核心方式 1）切成每段最多 2^24 − 5 字节，每段作为一个 APPLICATION 块的数据，块的 4 字节 ID 为 `LAE2`（0x4C 0x41 0x45 0x32）。写入方把这些块紧接着放在 STREAMINFO 之后；读取方把所有 ID 为 `LAE2` 的 APPLICATION 块按文件顺序拼起来，不论它们在元数据块中的位置。
* 音频帧存放核心。核心可以用任何合法的 FLAC 编码。
* 不写 SEEKTABLE 和 CUESHEET 块。

任何 FLAC 解码器都播放核心，跳过 APPLICATION 块。

*说明：*参考写入器（`src/laes_flac.h`）用固定块长 4096、两个声道分开编码、LPC 阶数最多 12、精度最多 15、Rice 分区阶最多 8。在 44.1 / 48 kHz 下这属于 FLAC 的可流式子集。很多旧播放器不播放 32 位 FLAC，所以参考编码器默认用 24 位核心（第 11.1 节）。参考读取器只解码两个声道分开编码的核心。APPLICATION ID `LAE2` 在向 IANA 登记之前是暂定的（RFC 9639 第 12.2 节）。

## 9. CD-Extra

用 LAE CD-Extra 封装（`spec/cdx/SPEC.md`）制作的 CD-Extra 光盘上，每轨的扩展文件（`.LAX`）为：

```
LAES 载荷加 CRC-32（核心方式 0）| 80 字节尾部记录
```

尾部记录就是 `spec/cdx/SPEC.md` 第 3.2 节的尾部记录，**扩展块类型为 2**。类型 2 时扩展块的前 4 个字节必须是 `LAE2`（类型 1 时为 `LAE1`），否则读取方必须拒绝扩展、只播 CD 音轨。CD-Extra 规范的其余规则（整轨 MD5、滑动校验和、抓轨偏移搜索、检查顺序）照常适用。核心就是 CD 音轨（16 位，44 100 Hz）。

## 10. 解码输出

解码器对每个文件提供：

| 输出 | 无损 | 定义 |
|---|---|---|
| 核心 | 是 | 原样 |
| 每个母带 | 是 | 第 6.6 节 |
| 每个母带的每个采样率级别 | 是 | 第 k 级（第 3.2 节），样点为 `x_k << w`，按母带字长输出；超出该字长的值在输出时限定在该字长内 |
| 推导 16 位 | **否** | 第 10.1 节 |

### 10.1 推导 16 位

某个采样率上文件没有 16 位输出时，解码器可以由该采样率上位数最多的输出（b 位，b > 16，s = b − 16）推导一个 16 位版本。计入的输出是：核心、SHA-256 相符的每个母带、以及它们的采样率级别（限定之后）。位数相同时按下面的顺序取第一个：核心；然后按载荷顺序，每个母带本身及其采样率级别（从高采样率到低）。

```
每个声道一个 xorshift64 生成器，状态 st = 20261029 + 0x9E3779B97F4A7C15 · (声道 + 1)（取模 2^64；声道 0 = 左）
next()：st ^= st << 13；st ^= st >> 7；st ^= st << 17；返回 st >> (64 − s)
按顺序对每个样点 v：r1 = next()；r2 = next()；y = clamp((v + r1 − r2 + 2^(s−1)) >> s, −32768, 32767)
```

结果是一个新的 16 位母带（±1 LSB 的 TPDF 抖动），相对源**有损**。解码器提供它时，必须在任何出现它的地方标明是推导的、有损的。每次运行、每个平台的结果都相同。

## 11. 编码器（说明性）

### 11.1 核心

核心可以直接给出（例如已发行的 CD 或 DVD），也可以由某个母带的基础级别按选定的字长推导。参考编码器在 WAV 形式用 16 位；在 FLAC 形式用母带中最高的字长，最高 24 位。来源母带是字长与核心相同的那个（这时它的基础级别就是核心），否则是字长最长的那个，用 TPDF 抖动降位。

### 11.2 存法、参照档与顺序

参考编码器对每个母带都试：存法 1；存法 0（对核心和每个更早的母带）；存法 2（对每个更早的母带，前提是两者都有高于基础级别的级）。每个母带取最小的一种，只选一次。母带在文件中的顺序也试两种，取小的：字长长的在前、同字长采样率高的在前；或者，核心是由某个不在第一位的母带推导出来时，把那个母带放第一位，其余照前一种排。母带只能参照更早的母带，而短字长对长字长的差值很小。

### 11.3 时间位置

与核心来自同一制作的母带 T = 0。核心是独立制作的（已发行的 CD）时，参考工具 `laes align` 用 LAE Lossy 编码器的自动搜索，把测到的位置连同小数存为 T，母带本身从不移动。对齐误差在 −60 dB 以内直接通过；否则显示误差，由用户决定继续还是结束。整张专辑由 LAE Lossy 的规划器（`lae_enc plan … laes`）按 CD 的分轨切开，每轨的母带原样写出，带各自的 T。

### 11.4 实测体积

在 10 秒片段上测得：2L 的两段 352.8 kHz 测试录音（02、05），另有一段 192 kHz 录音用于 48 kHz 族。都与 `flac -8` 对比。

| 内容 | LAES FLAC 形式，对比对象 |
|---|---|
| 一个 24 位母带及其全部采样率级别 | 只存该母带的 FLAC 的 93.5–98.4 % |
| 同一混音的 16、24、32 位母带（352.8 kHz），各带全部四个采样率级别（共 12 个版本） | 只存 32 位母带的 FLAC 的 99.6–99.8 % |
| 同样 12 个版本 | 12 个单独 FLAC 文件的约 30 % |
